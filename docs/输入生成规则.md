# 自定义输入格式

界面的“数据模板”适合常见格式；“编辑生成规则”允许调整每一个步骤；
更复杂的约束可使用 Python 脚本。没有预期答案时，自动生成只能帮助观察输出，不能证明程序正确；正确性比较需手动答案或参考程序。


生成规则是 JSON 对象，包含顺序执行的 `steps` 数组。变量由前面的步骤定义，后面的步骤引用。整数表达式支持变量、整数常量、`+ - * /`、括号，除法向零取整；不执行任意代码。

## 数组

```json
{
  "steps": [
    {"type":"int", "name":"n", "min":1, "max":8},
    {"type":"array", "count":"n", "min":-10, "max":10}
  ]
}
```

第一步随机生成并输出一行 n，第二步输出一行 n 个整数。若只定义变量而不输出，可设置 `"emit":false`。

## 一行多个参数，随后生成图

```json
{
  "steps": [
    {"type":"line", "items":[
      {"name":"n", "min":2, "max":8},
      {"name":"m", "min":"n-1", "max":"n*(n-1)/2"}
    ]},
    {"type":"graph", "nodes":"n", "edges":"m", "directed":false, "weighted":true, "min":1, "max":20}
  ]
}
```

`line.items` 中的对象定义随机整数；整数常量或字符串表达式直接输出值。例如 `["n", "m", 1]` 输出一行 n、m、1。这里的图是无自环、无重边的简单图，点从 1 编号；不承诺连通。需连通图等复杂约束时请使用 Python/CYaRon。

## 多组测试

```json
{
  "steps": [
    {"type":"int", "name":"T", "min":1, "max":3},
    {"type":"repeat", "count":"T", "steps":[
      {"type":"int", "name":"n", "min":1, "max":8},
      {"type":"array", "count":"n", "min":0, "max":100}
    ]}
  ]
}
```

`repeat` 内的 `i` 为从 1 开始的当前循环编号；变量修改在后续步骤可见，嵌套 repeat 会改写 i。外层“测试组数”指启动程序多少次；JSON 内的 T 指单次 stdin 包含多少组数据，两者不同。

## 支持的步骤

| type    | 字段                                            | 输出                               |
| ------- | ----------------------------------------------- | ---------------------------------- |
| int     | min / max / name（可选）/ emit（默认 true）     | 一个整数和换行                     |
| line    | items：整数、表达式或随机整数对象               | 一行若干整数                       |
| array   | count / min / max                               | 一行 count 个整数                  |
| matrix  | rows / cols / min / max                         | rows 行、每行 cols 个整数          |
| string  | length / alphabet                               | 一行随机字符串，字符集为可见 ASCII |
| tree    | nodes / weighted / min / max                    | n−1 条边，不自动输出 n            |
| graph   | nodes / edges / directed / weighted / min / max | m 条边，不自动输出 n m             |
| repeat  | count / steps                                   | 重复执行子步骤                     |
| literal | text                                            | 原样输出文本，需自行写 `\n`      |

`tree` 从编号 2 到 n，每个点随机连接一个编号更小的点，保证连通无环；不是所有标号树的均匀采样。带权边的 min/max 仅控制权值。

整数值与表达式中间值在 ±10^12 内；单组输入上限 1 MiB；数组和矩阵最多 100000 元素；树最多 10000 点，简单图最多 1000 点和 100000 边；嵌套最多 12 层；步骤与重复次数总量最多 100000，图候选边累计最多 2000000。超过限制会明确报错，适合个人小规模验证。手动模式最多 200 组，自动模式最多 1000 组。

随机策略为：random 随机；min/max 选择整数下界/上界；boundary 按测试序号循环下界、上界、随机。字符串与拓扑仍随机生成。这些策略不保证覆盖题目的全部边界。

## Python 与 CYaRon

切换到“Python / CYaRon 脚本”。每次启动生成器时传入两个参数：`sys.argv[1]` 是种子，`sys.argv[2]` 是从 0 开始的测试序号。stdout 作为本次 stdin，stderr 可用于出错诊断；不需要写输入文件。

```python
import random
import sys

seed, index = map(int, sys.argv[1:3])
rng = random.Random(seed + index)
n = rng.randint(1, 8)
print(n)
print(*[rng.randint(-10, 10) for _ in range(n)])
```

[CYaRon](https://github.com/luogu-dev/cyaron) 提供树、图、向量等生成工具；JudgeBox 通过 Python 生成器接入。完整离线安装包已内置 CYaRon 0.7.0。仅使用开发版或自行选择其他 Python 时，需要在该 Python 环境中安装：

```powershell
python -m pip install cyaron
```

然后可以使用：

```python
import random
import sys
from cyaron import Graph

seed, index = map(int, sys.argv[1:3])
random.seed(seed + index)
n = random.randint(2, 8)
print(n)
print(Graph.tree(n))
```

Python 生成器限制为每组 5 秒、256 MiB、总输出 1 MiB。自定义脚本需自行设置随机种子才能复现；第三方库版本变化也可能改变结果，重要反例请直接下载保存。
