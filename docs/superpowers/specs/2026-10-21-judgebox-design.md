# JudgeBox 本地判题机

用户已明确要求直接实现，取代旧交接文档中暂不开发 GUI 的安排。沿用 Windows、C++20、CMake、现有 GCC。

## 使用目标

双击 JudgeBox.exe 打开本机浏览器界面，粘贴待测源码。手动模式添加多组 stdin 和预期 stdout；生成模式按规则生成小数据，留空答案时显示运行完成（不能声称 AC）；对拍模式另贴参考程序，自动生成数据并比较两者输出，首个反例可查看、下载和复现。

## 实现决定（由实现者选择）

- C++ 本地 HTTP 服务仅绑定 127.0.0.1，随机端口；每次启动随机会话凭据，限制 Host/Origin，浏览器无需联网。
- 原生 HTML/CSS/JS，不引入前端构建链；nlohmann/json 3.12.0 随仓库附带，保留 MIT 许可。
- 支持 C++20、Python、Java；检查本机仓颉工具链后接入。编译器路径可在界面配置，不经 shell 执行源码或命令。
- Windows CreateProcessW + 受限句柄继承，stdin 写入和 stdout/stderr 读取并发。挂起创建、加入 Job Object 后恢复；时间/输出/取消终止整个作业。Job 提交内存硬上限与完成端口通知判定 MLE，内存显示为作业峰值提交量。
- 每次编译、每个测试点独立目录。编译一次，参考程序失败明确标记为参考程序错误。状态 AC/WA/TLE/MLE/RE/CE/OLE/JE，取消为 CANCELLED，无答案为 RUN。
- Token/严格/浮点比较，浮点容差可配置；显示首个不同 token。
- 生成规则由顺序步骤组成：整数、多字段行、数组、矩阵、字符串、树、简单图、重复和原文。变量与受限整数表达式引用前序变量；固定随机种子。内置常见模板、可视参数和 JSON 专家编辑。
- 高级 Python 生成器每次接收 seed 与 case index 参数，stdout 即输入；可选安装 CYaRon 后 import。无须为了基本功能安装 Python 包。
- 异步任务、进度、停止、自动保存草稿、JSON 导入导出和反例下载。运行记录存入 runs，无数据库。

只用于本机可信代码；Job Object 不构成安全沙箱。Java JVM 原生开销使低内存限制可能阻止启动，文档说明。浏览器关闭后服务由窗口 Ctrl+C 或界面退出停止。

## 验收

真实构建并运行：AC、WA、CE、TLE、MLE、RE、OLE、无答案、参考错误、取消、双流大输出、大 stdin、空输入、中文空格路径、进程树清理；生成器合法性/复现/边界/拒绝非法表达式；浏览器两条路线与反例导出；本机语言编译冒烟。
