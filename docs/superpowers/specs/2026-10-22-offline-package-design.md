# JudgeBox 离线工具链与 Windows 安装包

用户要求先验证各语言工具链，再将编译工具整合，交付单个 exe 或安装包。实现者选择单文件离线安装包，支持 Windows 11 x64；不将本机测试称为全部程序或全部机器验证。

保留现有简洁黑白红界面。工具链 C++20/GCC、Python、Java/JDK、仓颉 SDK 与应用一起安装，通过 exe 所在目录的 runtimes 路径优先定位，不使用开发机绝对路径作为发布依赖。缺少内置工具时明确报错，不在发布验证中跳过语言。Python 使用官方嵌入式发行版；保留标准库，并内置 CYaRon 及依赖。JDK 与仓颉复制完整可重定位发行文件，GCC 按 MSYS2 包清单及传递依赖提取，保留头文件、链接器、运行库、许可证和版本清单。

判题记录默认放当前用户可写的数据目录，支持安装目录只读；已有 --data-dir 显式指定仍有效。提供工具链自检入口和可保存的测试报告。测试矩阵覆盖四语言 stdin/stdout、Unicode、标准库、CE、RE、TLE、OLE，多组数据和生成器；搬迁发布目录、受控环境变量、Python 隔离和 PE 依赖扫描验证不依赖开发机路径。不能运行干净 Windows VM 时明确记录验证边界，附上可直接执行的干净机器自检步骤。

安装包仅离线解压随包组件并创建当前用户快捷方式，不下载远程依赖，不要求改环境变量。卸载保留用户数据。附带第三方许可与源代码来源信息、哈希清单和打包脚本。
