# JudgeBox v1.4.0 更新报告（2026-11-14）

## 这次加了什么

**题目系统**：从"只能调试一段代码"变成"能出题、做题、提交、判分"。

- **题单页**：按难度、标签、状态（未做 / 尝试过 / 已满分）筛选；显示每题总分、历史最佳、尝试次数、最近一次结果。
- **做题页**：左侧双语题面（Markdown + 离线 MathJax 公式）与样例，右侧 C++ / 仓颉编辑器（函数题自动带 starter、函数签名和包名提示）。
- **判题**：`io`（交完整程序）与 `function`（只交函数，题包提供 driver）两种模式；每个用例单独起进程，时间 / 内存 / 输出都有硬限制；按组计分，组内全 AC 才拿分，满分 100。
- **checker**：题包可带 `checker.cpp`（testlib 风格 SPJ，自己读输入判定）；不带就按内置 token 比较判，空白差异不算错。
- **揭榜动画**：提交后按 ICPC 榜单浮现，只有自己一个选手，和本题历史最佳对比。
- **留痕**：每次提交的代码、结果、用时都落在 exe 同级的 `.cache/`，可在界面清空。

## 题包格式变了（重要）

交付物从"一个 `problem.json`"变成**一个 zip**：

```
<id>.zip
  problem.json            # 只放元数据
  <caseId>.in / .ans      # 全部测试数据，平铺、文件名 ASCII
  checker.cpp             # 可选：SPJ
  main.cj / main.cpp      # function 模式的 driver
  starter.cj / .cpp       # 与 main 成对
  solution.cj / .cpp      # 参考解（多文件用 solution_1.*、solution_2.*…）
```

- 取消内嵌 `tests` / `testsZipPath`；导入接口只接受 `{"zipPath": 绝对路径}` 或 `{"zip": base64}`（网页导入会选 `.zip` 并自动编码）。
- 样例 `samples` 只做展示，**不参与判分**；`sample` 组仍然是真实判分组，它的用例来自 zip。
- 同一 `id` 重复导入会覆盖旧题，返回 `"replaced": true`；导入失败不写盘，旧版本保留。
- 包内文件名必须是 ASCII（平台用系统 `tar.exe` 解压）；题面等内容中文没问题。

出题资料在仓库 `CreateProblemGuide/`：出题指南、可直接导入的 `完整示例.zip`、能跑的 `模板/`。

## 升级说明

- 安装包会覆盖旧版本；`.cache/` 里的提交历史按 exe 目录保存，卸载重装会丢，题目在数据目录里不受影响。
- 旧格式的题包（把 `checker`/`solution`/`tests` 写进 `problem.json`）**不能再导入**，需要按新格式重新打成 zip。

## 已知限制

- 判题是单任务：已有提交在判时再提交返回 409；调试任务在跑时提交也会 409。
- 导入是同步的，首次要编译 checker 和 driver（约 5–20 秒）；失败时逐条返回 `details`。
- 每题最多保留 50 条提交，单条记录不超过 256 KB（超出会截断源码并标记）。
- 中文**文件名**的题包 zip 无法解压（内容里的中文不受影响）。
