# JudgeBox v1.3.0 更新报告

发布日期：2026-11-12  
适用平台：Windows 11 x64  
安装包：`JudgeBox-Setup-1.3.0-x64.exe`（约 427 MB）

## 一、这次更新解决了什么

v1.3.0 针对三个实际使用问题做了完整修复：

1. **双击后直接出现 JudgeBox 窗口**
   - 不再弹出命令行窗口。
   - 不再依赖“先启动本地服务，再手动打开浏览器”。
   - 关闭窗口或点击界面右上角「退出」，本地引擎会一起结束。

2. **图标和快捷方式补齐**
   - `JudgeBox.exe`、安装包、卸载程序、窗口标题栏、任务栏统一使用 JudgeBox 图标。
   - 安装时默认创建桌面快捷方式，开始菜单快捷方式保留。
   - 程序内写入 1.3.0 版本信息，资源管理器里不再是通用空白图标。

3. **工具链真正随安装包内置**
   - C++（GCC 16.1.0）、Python（3.14.9）、Java（Temurin 21.0.11）、仓颉（1.2.0）全部随包分发。
   - 启动后自动检测并锁定安装目录内的工具链，不需要用户手动选择。
   - 旧草稿里残留的空路径、失效路径不会再覆盖内置工具链。
   - 「工具链设置」页改为只读展示，并明确标注「内置」，避免误解为还需要配置。

## 二、使用方式的变化

### 安装后

从桌面或开始菜单双击 **JudgeBox**，直接进入原生窗口。

窗口特性：

- 单实例：重复双击只会激活已有窗口，不会启动第二套服务。
- 原生窗口：基于系统自带的 Microsoft Edge WebView2。
- 关闭窗口 = 退出程序，不会留下后台端口或命令行进程。
- 界面内的「退出」按钮同样会结束本地引擎。

### 升级

直接运行 `JudgeBox-Setup-1.3.0-x64.exe` 覆盖安装即可。默认安装目录与 1.2.0 相同，用户数据目录 `%LOCALAPPDATA%\JudgeBox\runs` 会保留。

### 卸载

Windows「设置 → 应用 → JudgeBox → 卸载」，或运行安装目录里的 `unins000.exe`。卸载默认保留用户数据。

## 三、工具链说明

| 语言 | 内置工具 | 版本 |
| --- | --- | --- |
| C++ | `runtimes/gcc/bin/g++.exe` | GCC 16.1.0 |
| Python | `runtimes/python/python.exe` | CPython 3.14.9 |
| Java | `runtimes/jdk/bin/javac.exe`、`java.exe` | Temurin 21.0.11 |
| 仓颉 | `runtimes/cangjie/bin/cjc.exe` | Cangjie 1.2.0 |

这些工具链会占用约 1.7 GB 安装空间，属于离线安装包的正常体积。

即使电脑从未安装过 GCC、Python、JDK 或仓颉，也可以直接判题。程序启动时优先使用安装目录内的工具链；只有内置文件缺失时，才允许在设置页填写自定义路径。

旧版本草稿中的 `tools` 字段仍然可以读取，但不会覆盖仍然存在的内置工具链。因此升级后不需要清理草稿。

## 四、界面与交互

- 主界面保持 v1.2.0 的红色主题、编辑器、测试点、生成测试和随机对拍布局。
- 工具链设置页现在显示：
  - 五项内置工具路径；
  - 每项右侧的「内置」标签；
  - 「已检测到全部内置工具链，判题无需额外配置」的状态提示。
- 如果安装文件被误删，缺失项会变为可编辑，并提示重新安装或填写路径。
- 使用说明里的“关闭浏览器不会结束引擎”已改为窗口模式的真实行为。

## 七、已知限制

1. **安装包未做代码签名**  
   Windows SmartScreen 可能提示“未知发布者”。这是签名问题，不是安装包损坏；校验 SHA-256 后再运行即可。要彻底消除提示，需要购买代码签名证书并对安装包签名。

2. **安装器限定 Windows 11 x64**  
   与 v1.2.0 保持一致，安装器最低要求 Windows 11（`10.0.22000`）。开发版仍可在满足构建环境的 Windows 10/11 上编译。

3. **WebView2 依赖系统组件**  
   Windows 11 已内置 Microsoft Edge WebView2 Runtime。若系统被精简导致运行库缺失，程序会尝试使用 Edge 应用窗口作为后备；也可以在设置页提示的微软官方地址安装 WebView2 Runtime。

4. **离线工具链体积较大**  
   安装后约 1.7 GB，这是把四套编译器完整封装进去的代价。安装包本身约 427 MB。

## 八、升级建议

- 关闭正在运行的 JudgeBox 后再运行新安装包。
- 安装完成后从桌面快捷方式启动，确认窗口直接出现。
- 打开「设置 → 工具链设置」，应看到五项均为「内置」，状态为“判题无需额外配置”。
- 如果之前手工填过工具链路径，不需要清空；内置路径优先，失效路径会被自动忽略。
- 如遇到异常，先运行开始菜单里的 **Check Toolchains**，它会输出 24 项语言/编译器自检结果，并生成 `toolchain-self-test.json`。
