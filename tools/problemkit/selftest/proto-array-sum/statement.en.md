# Array Sum Prototype

Given $n$ integers, print their sum.

### Input

The first line contains an integer $n$ ($1 \le n \le 10^5$).

The second line contains $n$ integers $a_i$ ($|a_i| \le 10^9$).

### Output

One integer: $\sum a_i$.

### Two submission styles

A complete program does its own I/O; the function style only implements `solve`.
