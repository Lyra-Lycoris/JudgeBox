# Multi Case Square Prototype

The first line contains an integer $T$ — the number of cases. Each of the next $T$ lines contains one integer $n$.

For each case print $n^2$.

### Constraints

$1 \le T \le 100$, $1 \le n \le 10^6$.

### Two submission styles

A complete program does its own I/O; the function style only implements `solve`.
