# Words Equal Prototype

Given $k$ lowercase strings, decide whether they are all identical.

### Input

The first line contains an integer $k$ ($1 \le k \le 10^5$), the second line contains $k$ strings.

### Output

Print `YES` if all strings are equal, otherwise `NO`.

### Two submission styles

A complete program does its own I/O; the function style returns a boolean and the driver prints YES/NO.
