# 棋盘放国王

一个 $n$ 行 $m$ 列的棋盘。你要在棋盘上放置**若干枚国王**（国王攻击它周围八个格子，即上下左右和四个斜方向，不越出棋盘）。

要求任意两枚国王都不在同一格，且互不攻击。求不同的放置方案数。允许一枚国王都不放（棋盘全空也算一种方案）。

### 输入

一行两个整数 $n$ 和 $m$，表示棋盘的行数和列数。

### 输出

一个整数，表示满足条件的放置方案数。

### 数据范围

- $1 \le n, m \le 11$
- 最大答案（$11 \times 11$ 棋盘）为 $60711713670028729$，64 位整数可以存下
- 时间限制 2000 ms，空间限制 256 MB

### 样例

**输入**

```
3 3
```

**输出**

```
35
```

### 样例说明

$3 \times 3$ 的棋盘上：

- 放 $0$ 枚国王：$1$ 种方案；
- 放 $1$ 枚国王：$9$ 种方案；
- 放 $2$ 枚国王：$16$ 种方案（选出两个互不攻击的格子）；
- 放 $3$ 枚国王：$8$ 种方案；
- 放 $4$ 枚国王：$1$ 种方案（四个角）；
- 放 $5$ 枚及以上：不可能。

总方案数为 $1 + 9 + 16 + 8 + 1 = 35$。
