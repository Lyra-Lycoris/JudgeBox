# 树的最大权独立集

给定一棵 $n$ 个节点的有根树，节点编号 $1 \sim n$，根是 $1$ 号节点。第 $i$ 个节点有权值 $w_i$（可以为负）。

一个节点集合称为**独立集**，如果集合中任意两个节点都不直接相连（没有边）。求一个独立集，使其中节点的权值和最大。允许取空集（此时权值和为 $0$）。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $w_1, w_2, \dots, w_n$。

第三行 $n-1$ 个整数 $p_2, p_3, \dots, p_n$，其中 $p_i$ 表示节点 $i$ 的父亲，保证 $1 \le p_i < i$。当 $n=1$ 时这一行为空（不需要读入任何数）。

### 输出

一个整数，表示最大权值和。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $|w_i| \le 10^9$
- 对每个 $2 \le i \le n$，$1 \le p_i < i$（因此 $1$ 号节点是根，输入一定构成一棵树）
- 答案不超过 $2 \times 10^{14}$，64 位整数可以存下
- 时间限制 2000 ms，空间限制 256 MB

### 样例

**输入**

```
6
3 -2 5 4 -1 2
1 1 2 2 4
```

**输出**

```
9
```

### 样例说明

这棵树的结构是：$1$ 的儿子是 $2, 3$；$2$ 的儿子是 $4, 5$；$4$ 的儿子是 $6$。

各节点权值：$w_1=3$，$w_2=-2$，$w_3=5$，$w_4=4$，$w_5=-1$，$w_6=2$。

- 取 $\{3, 4\}$：$5 + 4 = 9$，且 $3$ 与 $4$ 不相邻，可行；
- 取 $\{1, 4\}$：$3 + 4 = 7$；
- 取 $\{3, 6\}$：$5 + 2 = 7$；
- 取全部正权点 $\{1, 3, 4, 6\}$ 不可行，因为 $1$ 与 $3$、$4$ 与 $6$ 分别相连。

最大权值和为 $9$。
