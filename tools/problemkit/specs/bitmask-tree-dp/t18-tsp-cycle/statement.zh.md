# TSP 最短环路

有 $n$ 座城市，编号 $0 \sim n-1$。城市 $i$ 到城市 $j$ 之间可能有一条**单向**航线，费用为 $w_{i,j}$；若 $w_{i,j} = -1$ 则表示这条航线不存在。保证 $w_{i,i} = 0$。

你从城市 $0$ 出发，要求**恰好经过每座城市一次**，最后回到城市 $0$（即走一条经过所有城市的回路）。求最小总费用。如果不存在这样的回路，输出 $-1$。

### 输入

第一行一个整数 $n$。

接下来 $n$ 行，每行 $n$ 个整数，第 $i$ 行第 $j$ 个数为 $w_{i,j}$（行、列都从 $1$ 开始编号，对应城市 $i-1$ 与城市 $j-1$）。

### 输出

一个整数，表示最小总费用；不存在合法回路时输出 $-1$。$n=1$ 时不需要移动，答案为 $0$。

### 数据范围

- $1 \le n \le 18$
- $w_{i,j} = -1$（航线不存在）或 $0 \le w_{i,j} \le 10^9$
- $w_{i,i} = 0$
- 答案不超过 $1.8 \times 10^{10}$，64 位整数可以存下
- 时间限制 2000 ms，空间限制 256 MB

### 样例

**输入**

```
4
0 5 -1 9
7 0 4 -1
-1 6 0 3
2 -1 8 0
```

**输出**

```
14
```

### 样例说明

存在的航线为：$0 \to 1$（$5$）、$0 \to 3$（$9$）、$1 \to 0$（$7$）、$1 \to 2$（$4$）、$2 \to 1$（$6$）、$2 \to 3$（$3$）、$3 \to 0$（$2$）、$3 \to 2$（$8$）。

可行的回路：

- $0 \to 1 \to 2 \to 3 \to 0$：$5 + 4 + 3 + 2 = 14$；
- $0 \to 3 \to 2 \to 1 \to 0$：$9 + 8 + 6 + 7 = 30$。

其他顺序都会用到不存在的航线（例如 $0 \to 2$、$1 \to 3$），所以最小总费用为 $14$。
