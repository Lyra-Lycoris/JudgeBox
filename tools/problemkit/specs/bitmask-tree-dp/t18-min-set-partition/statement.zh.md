# 集合划分最小代价

有 $n$ 个物品，编号 $0 \sim n-1$。你要把它们划分成若干个**非空**的组（每个物品恰好属于一组，组的顺序不计）。

如果一组装下的物品集合是 $S$，就要支付 $c_S$ 的代价。集合 $S$ 用一个 $n$ 位二进制数表示：从低位数第 $i$ 位（$0 \le i < n$）为 $1$ 表示物品 $i$ 在这一组里。给定所有 $2^n$ 个 $c_S$，求把所有物品分完的最小总代价。

### 输入

第一行一个整数 $n$。

第二行一个整数 $k$，表示代价表的大小，满足 $k = 2^n$。

第三行 $k$ 个整数，依次为 $c_0, c_1, \dots, c_{k-1}$。其中 $c_0 = 0$ 无实际含义（空集不会被使用）。

### 输出

一个整数，表示最小总代价。

### 数据范围

- $1 \le n \le 15$，$k = 2^n$
- $0 \le c_S \le 10^9$，$c_0 = 0$
- 答案不超过 $1.5 \times 10^{10}$，64 位整数可以存下
- 时间限制 2000 ms，空间限制 256 MB

### 样例

**输入**

```
3
8
0 5 6 4 7 3 9 10
```

**输出**

```
9
```

### 样例说明

$n=3$，代价表为：

| 集合 $S$ | 二进制 | 含义 | $c_S$ |
|---|---|---|---|
| 1 | 001 | $\{0\}$ | 5 |
| 2 | 010 | $\{1\}$ | 6 |
| 3 | 011 | $\{0,1\}$ | 4 |
| 4 | 100 | $\{2\}$ | 7 |
| 5 | 101 | $\{0,2\}$ | 3 |
| 6 | 110 | $\{1,2\}$ | 9 |
| 7 | 111 | $\{0,1,2\}$ | 10 |

可能的划分及其代价：

- $\{0,1,2\}$：$10$；
- $\{0\},\{1,2\}$：$5 + 9 = 14$；
- $\{1\},\{0,2\}$：$6 + 3 = 9$；
- $\{2\},\{0,1\}$：$7 + 4 = 11$；
- $\{0\},\{1\},\{2\}$：$5 + 6 + 7 = 18$。

最小总代价为 $9$。
