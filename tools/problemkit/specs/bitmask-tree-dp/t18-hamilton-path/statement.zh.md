# 最短哈密顿路

有 $n$ 座城市，编号 $0 \sim n-1$。任意两座城市之间都有直达航班，从城市 $i$ 飞往城市 $j$ 的费用为 $w_{i,j}$，保证 $w_{i,i}=0$。

你从城市 $0$ 出发，到城市 $n-1$ 结束，要求**每座城市恰好经过一次**（即经过一条哈密顿路），求最小的总费用。

### 输入

第一行一个整数 $n$。

接下来 $n$ 行，每行 $n$ 个整数，第 $i$ 行第 $j$ 个数为 $w_{i,j}$（行、列都从 $1$ 开始编号，对应城市 $i-1$ 与城市 $j-1$）。

### 输出

一个整数，表示从 $0$ 号城市出发、到 $n-1$ 号城市结束、恰好经过每座城市一次的最小总费用。若 $n=1$，答案为 $0$。

### 数据范围

- $1 \le n \le 18$
- $0 \le w_{i,j} \le 10^9$，且 $w_{i,i}=0$
- 任意哈密顿路的总费用不超过 $1.7 \times 10^{10}$，64 位整数可以存下
- 时间限制 2000 ms，空间限制 256 MB

### 样例

**输入**

```
4
0 3 9 2
3 0 4 8
9 4 0 1
2 8 1 0
```

**输出**

```
8
```

### 样例说明

必须从城市 $0$ 出发、在城市 $3$ 结束，并把城市 $1,2$ 各走一次。

- 路线 $0 \to 1 \to 2 \to 3$：费用 $3 + 4 + 1 = 8$；
- 路线 $0 \to 2 \to 1 \to 3$：费用 $9 + 4 + 8 = 21$。

最小费用为 $8$。
