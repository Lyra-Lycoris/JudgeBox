# 树的最小点覆盖

给定一棵 $n$ 个节点的有根树，节点编号 $1 \sim n$，根是 $1$ 号节点。

一个节点集合称为**点覆盖**，如果每条边都至少有一个端点在集合中。求最小的点覆盖大小（即最少选多少个点）。

### 输入

第一行一个整数 $n$。

第二行 $n-1$ 个整数 $p_2, p_3, \dots, p_n$，其中 $p_i$ 表示节点 $i$ 的父亲，保证 $1 \le p_i < i$。当 $n=1$ 时这一行为空（不需要读入任何数）。

### 输出

一个整数，表示最小点覆盖的大小。$n=1$ 时没有边，答案为 $0$。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- 对每个 $2 \le i \le n$，$1 \le p_i < i$（因此 $1$ 号节点是根，输入一定构成一棵树）
- 时间限制 2000 ms，空间限制 256 MB

### 样例

**输入**

```
5
1 1 3 3
```

**输出**

```
2
```

### 样例说明

这棵树有 $4$ 条边：$(1,2)$、$(1,3)$、$(3,4)$、$(3,5)$。

- 选 $\{1, 3\}$：$4$ 条边的两个端点里都至少有一个被选中，是合法点覆盖，大小为 $2$；
- 只选 $1$ 个点无法覆盖所有边：选 $1$ 漏掉 $(3,4)$，选 $3$ 漏掉 $(1,2)$，选其他点漏得更多。

所以最小点覆盖大小为 $2$。
