# 换根求每个点的距离和

给定一棵 $n$ 个节点的树，节点编号 $1 \sim n$，根是 $1$ 号节点。每条边的长度都是 $1$。

对每个节点 $v$，定义 $f(v) = \sum_{u=1}^{n} \operatorname{dist}(v, u)$，即 $v$ 到所有节点（包括它自己，距离为 $0$）的距离之和。求出 $f(1), f(2), \dots, f(n)$。

### 输入

第一行一个整数 $n$。

第二行 $n-1$ 个整数 $p_2, p_3, \dots, p_n$，其中 $p_i$ 表示节点 $i$ 的父亲，保证 $1 \le p_i < i$。当 $n=1$ 时这一行为空（不需要读入任何数）。

### 输出

一行 $n$ 个整数，第 $i$ 个数为 $f(i)$，数与数之间用一个空格分隔。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- 对每个 $2 \le i \le n$，$1 \le p_i < i$（因此 $1$ 号节点是根，输入一定构成一棵树）
- 每个 $f(v)$ 都不超过 $\frac{n(n-1)}{2} = 2 \times 10^{10}$，64 位整数可以存下
- 时间限制 2000 ms，空间限制 256 MB

### 样例

**输入**

```
5
1 1 3 3
```

**输出**

```
6 9 5 8 8
```

### 样例说明

树的结构：$1$ 的儿子是 $2, 3$；$3$ 的儿子是 $4, 5$。

- $f(1) = 1 + 1 + 2 + 2 = 6$（分别到 $2,3,4,5$）；
- $f(2) = 1 + 2 + 3 + 3 = 9$；
- $f(3) = 1 + 2 + 1 + 1 = 5$；
- $f(4) = 2 + 3 + 1 + 2 = 8$；
- $f(5) = 2 + 3 + 1 + 2 = 8$。

如果已经求出父亲的 $f$，可以用**换根**推出儿子的值：设以 $v$ 为根的子树大小为 $s_v$，则

$$f(\text{son}) = f(v) + n - 2 s_{\text{son}}$$

例如 $f(3) = f(1) + 5 - 2 \times 3 = 6 - 1 = 5$。
