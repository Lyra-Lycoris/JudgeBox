# 删除相邻重复字符

给定一个只由小写字母组成的字符串 $s$ 和一个整数 $k$（$k \ge 2$）。

重复执行下面的操作，直到字符串中不存在连续 $k$ 个相同的字符为止：

- 找到任意一处连续的 $k$ 个相同字符，把它们全部删除，剩下的部分拼接在一起。

删除之后左右两边的字符可能会变得相邻，从而产生新的可删除段。可以证明，无论按什么顺序删除，最终剩下的字符串都是唯一的。请输出这个最终字符串。

### 输入格式

- 第一行一个整数 $k$；
- 第二行一个字符串 $s$，由小写字母组成，不含空白字符。

### 输出格式

一行一个字符串，表示最终剩下的字符串。如果所有字符都被删掉，请输出一个空行。

### 数据范围

- $2 \le k \le 200000$；
- $1 \le |s| \le 200000$；
- $s$ 只包含小写字母 `a` 到 `z`。

提示：逐次模拟删除过程最坏是 $O(|s|^2)$ 的，无法通过最大数据。

### 样例说明

样例 1：$s = $ `abbaca`，$k = 2$。

- 删除中间的两个 `b`，得到 `aaca`；
- 删除开头的两个 `a`，得到 `ca`；
- 此时没有相邻的相同字符，最终结果是 `ca`。

样例 2：$s = $ `aaabb`，$k = 3$。

- 删除开头三个 `a`，得到 `bb`；
- `bb` 只有两个字符，不足 $k = 3$ 个，不能删除，最终结果是 `bb`。
