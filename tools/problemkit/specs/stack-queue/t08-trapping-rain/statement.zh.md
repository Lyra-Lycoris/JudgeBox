# 接雨水

有 $n$ 根宽度为 $1$ 的柱子排成一排，第 $i$ 根柱子的高度为 $h_i$，柱子之间没有缝隙，底面都在高度 $0$ 的地面上。下雨后，凹凸不平的缝隙里会积起水来。

请计算这些柱子一共能接住多少单位的雨水。水面不会漫过两侧柱子中较矮的一根，柱子本身不吸水。

形式化地说：位置 $i$ 上方能积水的深度是

$$\min\left(\max_{0 \le j \le i} h_j,\ \max_{i \le j < n} h_j\right) - h_i$$

但结果不会为负（取 $\max(0, \cdot)$）。答案为所有位置积水深度之和。

### 输入格式

- 第一行一个整数 $n$；
- 第二行 $n$ 个整数 $h_0, h_1, \dots, h_{n-1}$，相邻两个用一个空格隔开。

### 输出格式

一行一个整数，表示能接住的雨水总量。

### 数据范围

- $1 \le n \le 200000$；
- $0 \le h_i \le 10^9$。

答案最大可能达到 $2 \times 10^{14}$，请使用 64 位整数。

### 样例说明

样例 1：高度为 $0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1$。各个位置能积的水依次是 $0, 0, 1, 0, 1, 2, 1, 0, 0, 1, 0, 0$，总和为 $6$。

样例 2：高度为 $4, 2, 0, 3, 2, 5$。各位置积水深度为 $0, 2, 4, 1, 2, 0$，总和为 $9$。
