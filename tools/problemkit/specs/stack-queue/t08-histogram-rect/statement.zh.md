# 直方图最大矩形

在一个水平面上并排放着 $n$ 根宽度都为 $1$ 的柱子，第 $i$ 根柱子的高度为 $h_i$，底面都贴在高度为 $0$ 的地面上，柱子之间没有空隙。

请在这个直方图内部找出一个面积最大的矩形。矩形的四条边必须与坐标轴平行，整个矩形必须被柱子覆盖（可以贴地，也可以顶部留空）。

### 输入格式

- 第一行一个整数 $n$；
- 第二行 $n$ 个整数 $h_0, h_1, \dots, h_{n-1}$，相邻两个用一个空格隔开。

### 输出格式

一行一个整数，表示最大矩形的面积。

### 数据范围

- $1 \le n \le 200000$；
- $0 \le h_i \le 10^9$。

答案最大可能达到 $2 \times 10^{14}$，请使用 64 位整数。

### 样例说明

样例 1：高度为 $2, 1, 5, 6, 2, 3$。取第 $3$、$4$ 根柱子（编号从 $0$ 开始是 $h_2 = 5$ 与 $h_3 = 6$），矩形高度取两者较小值 $5$、宽度取 $2$，面积为 $5 \times 2 = 10$；取全部 $6$ 根柱子时高度只有 $1$，面积是 $6$。最大面积为 $10$。

样例 2：所有柱子高度都是 $7$，取全部 $5$ 根柱子，面积 $7 \times 5 = 35$。
