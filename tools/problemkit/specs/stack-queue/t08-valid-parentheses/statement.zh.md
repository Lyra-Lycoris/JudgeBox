# 括号序列合法性

给定一个只由 `(`、`)`、`[`、`]`、`{`、`}` 六种字符组成的字符串 $s$，判断它是不是一个合法的括号序列。

合法括号序列的定义：

- 空串是合法的；
- 如果 $A$ 是合法的，那么 `(` $A$ `)`、`[` $A$ `]`、`{` $A$ `}` 都是合法的；
- 如果 $A$ 与 $B$ 都是合法的，那么 $AB$ 也是合法的。

### 输入格式

一行一个字符串 $s$，只包含上述六种括号字符。

### 输出格式

如果 $s$ 是合法括号序列，输出一行 `YES`；否则输出一行 `NO`。

### 数据范围

- $1 \le |s| \le 200000$；
- $s$ 中只可能出现 `(`、`)`、`[`、`]`、`{`、`}`。

### 样例说明

样例 1：`()[]{}` 可以看作 `()`、`[]`、`{}` 三个合法串依次相连，因此合法，输出 `YES`。

样例 2：`([)]` 中左括号 `[` 与右括号 `)` 相遇，嵌套关系交叉，因此不合法，输出 `NO`。
