# 下一个更大元素

给定长度为 $n$ 的整数数组 $a_0, a_1, \dots, a_{n-1}$。对每个位置 $i$，求它右边第一个严格大于 $a_i$ 的元素，即最小的 $j > i$ 满足 $a_j > a_i$。

如果这样的 $j$ 不存在，答案记为 $-1$。

### 输入格式

- 第一行一个整数 $n$；
- 第二行 $n$ 个整数 $a_0, a_1, \dots, a_{n-1}$，相邻两个用一个空格隔开。

### 输出格式

一行 $n$ 个整数，第 $i$ 个数表示位置 $i$ 的答案（$a_j$ 的值，不存在时为 $-1$），相邻两个用一个空格隔开。

### 数据范围

- $1 \le n \le 200000$；
- $|a_i| \le 10^9$。

### 样例说明

样例 1：数组为 $2, 1, 3, 5, 4$。

- $a_0 = 2$，右边第一个比它大的是 $a_2 = 3$；
- $a_1 = 1$，右边第一个比它大的是 $a_2 = 3$；
- $a_2 = 3$，右边第一个比它大的是 $a_3 = 5$；
- $a_3 = 5$ 与 $a_4 = 4$ 右边都没有更大的数，答案为 $-1$。

所以输出 `3 3 5 -1 -1`。

样例 2：数组为 $4, 4, 3, 5$。注意要求的是**严格**大于：$a_0 = a_1 = 4$ 虽然右边有相等的 $4$，但相等的数不算更大，要一直跳到 $a_3 = 5$；$a_2 = 3$ 的右边第一个更大值同样是 $5$；$a_3 = 5$ 右边没有元素，答案为 $-1$。输出 `5 5 5 -1`。
