# 逆波兰表达式求值

逆波兰表达式（后缀表达式）把运算符写在两个操作数之后。例如中缀表达式 $(3 + 4) \times 2$ 对应的逆波兰表达式是 `3 4 + 2 *`。

给定一个合法的逆波兰表达式，请计算它的值。表达式中的 token 只有两类：

- 一个整数（可能带负号，例如 `-7`）；
- 一个运算符，是 `+`、`-`、`*`、`/` 之一。

其中 `/` 表示整数除法，**向零取整**（例如 `-7 / 2 = -3`，`6 / -4 = -1`）。

### 输入格式

- 第一行一个整数 $k$，表示 token 的个数；
- 接下来 $k$ 个 token，相邻两个之间用空白字符（空格或换行）分隔。

### 输出格式

一行一个整数，表示表达式的值。

### 数据范围

- $1 \le k \le 200000$，且 $k$ 是奇数；
- 每个整数的绝对值不超过 $10^9$；
- 保证表达式合法：任何时刻运算符都有足够的操作数，除法不会除以 $0$；
- 保证任意中间结果与最终答案的绝对值都不超过 $10^9$。

### 样例说明

样例 1：token 为 `3`、`4`、`+`、`2`、`*`。先算 `3 + 4 = 7`，再算 `7 * 2 = 14`，输出 `14`。

样例 2：token 为 `-7`、`2`、`/`。整数除法向零取整，$-7 / 2 = -3.5$ 取整后是 $-3$，输出 `-3`。
