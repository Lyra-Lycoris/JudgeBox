# 最小栈的查询结果

请维护一个支持以下操作的栈：

- 把整数 $v$ 压入栈顶；
- 弹出栈顶元素；
- 查询当前栈中所有元素的最小值。

为了便于输入，我们用整数给操作编码：第 $i$ 个操作用 `op[i]` 表示，$1$ 表示压入 `val[i]`，$2$ 表示弹出栈顶，$3$ 表示查询最小值。当 `op[i]` 不是 $1$ 时，`val[i]` 一定是 $0$，可以忽略。

请按顺序执行这 $m$ 个操作，并把每次查询得到的答案按发生顺序输出。

### 输入格式

- 第一行一个整数 $m$，表示操作个数；
- 第二行 $m$ 个整数 `op[0], op[1], ..., op[m-1]`，相邻两个用一个空格隔开；
- 第三行 $m$ 个整数 `val[0], val[1], ..., val[m-1]`，相邻两个用一个空格隔开。

### 输出格式

一行 $q$ 个整数，相邻两个用一个空格隔开，依次是每次查询（`op[i] = 3`）时栈中元素的最小值，其中 $q$ 是查询操作的次数（$q \ge 1$）。

### 数据范围

- $1 \le m \le 200000$；
- `op[i]` 只能是 $1$、$2$、$3$；
- 当 `op[i] = 1` 时 $|val[i]| \le 10^9$，否则 `val[i] = 0`；
- 保证操作合法：每次弹出与查询时栈都非空；
- 保证至少有一次查询（$q \ge 1$）。

### 样例说明

样例 1：操作依次是

1. `push 5`，栈为 $[5]$；
2. `push -3`，栈为 $[5, -3]$；
3. `getMin`，最小值为 $-3$；
4. `pop`，弹出 $-3$，栈为 $[5]$；
5. `getMin`，最小值为 $5$；
6. `getMin`，最小值仍为 $5$。

共 $3$ 次查询，答案依次是 $-3, 5, 5$，因此输出 `-3 5 5`。

样例 2：压入两个 $2$，查询得到 $2$，再弹出栈顶（只弹出一个 $2$）。共 $1$ 次查询，输出 `2`。
