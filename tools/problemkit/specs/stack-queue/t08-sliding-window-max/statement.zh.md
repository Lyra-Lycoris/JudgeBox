# 滑动窗口最大值

给定长度为 $n$ 的整数数组 $a_0, a_1, \dots, a_{n-1}$ 和一个整数 $k$。

一个大小为 $k$ 的窗口从数组最左端开始，每次向右滑动一格。窗口覆盖的下标依次是 $[0, k-1]$、$[1, k]$、……、$[n-k, n-1]$，共 $n-k+1$ 个窗口。请输出每个窗口内的最大值。

### 输入格式

- 第一行两个整数 $n, k$，用一个空格隔开；
- 第二行 $n$ 个整数 $a_0, a_1, \dots, a_{n-1}$，相邻两个用一个空格隔开。

### 输出格式

一行 $n-k+1$ 个整数，依次表示每个窗口的最大值，相邻两个用一个空格隔开。

### 数据范围

- $1 \le k \le n \le 200000$；
- $|a_i| \le 10^9$。

### 样例说明

样例 1：$n = 8$，$k = 3$。

- 窗口 $[0,2]$：$1, 3, -1$，最大值 $3$；
- 窗口 $[1,3]$：$3, -1, -3$，最大值 $3$；
- 窗口 $[2,4]$：$-1, -3, 5$，最大值 $5$；
- 窗口 $[3,5]$：$-3, 5, 3$，最大值 $5$；
- 窗口 $[4,6]$：$5, 3, 6$，最大值 $6$；
- 窗口 $[5,7]$：$3, 6, 7$，最大值 $7$。

输出 `3 3 5 5 6 7`。

样例 2：$k = 1$，每个窗口只含一个元素，答案就是原数组。
