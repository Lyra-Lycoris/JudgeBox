# 字典序最小循环移位

给定一个长度为 $n$ 的小写字符串 $s$。对每个下标 $i$（$0 \le i < n$），把 $s$ 循环左移 $i$ 位得到的字符串记作 $r_i$，即

$$r_i = s[i..n-1] + s[0..i-1].$$

例如 $s = \text{baca}$ 时：

- $r_0 = \text{baca}$
- $r_1 = \text{acab}$
- $r_2 = \text{caba}$
- $r_3 = \text{abac}$

请找出字典序最小的 $r_i$，输出对应的下标 $i$。如果多个下标对应的字符串完全相同，输出其中**最小**的下标。

### 输入格式

- 第一行一个整数 $n$，表示字符串长度。
- 第二行一个长度为 $n$ 的小写字符串 $s$。

### 输出格式

输出一行一个整数 $i$（$0 \le i < n$），表示字典序最小的循环移位的起始下标；若有并列，输出最小的下标。

### 数据范围

- $1 \le n \le 2 \times 10^5$。
- $s$ 只含小写英文字母 `a` 到 `z`，长度恰好为 $n$。

提示：枚举全部 $n$ 个循环移位逐一比较是 $O(n^2)$ 的，无法通过本题；需要 $O(n)$ 或 $O(n \log n)$ 的算法。

### 样例说明

样例 1：$n = 4$，$s = \text{baca}$。四个循环移位分别是 $\text{baca}$、$\text{acab}$、$\text{caba}$、$\text{abac}$，字典序最小的是 $\text{abac}$，它对应下标 $3$，所以输出 `3`。
