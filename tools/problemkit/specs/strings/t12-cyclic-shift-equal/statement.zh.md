# 循环移位相等判定

给定两个长度均为 $n$ 的小写英文字符串 $s$ 与 $t$。

一次**循环移位**是指把字符串的第一个字符搬到末尾（左移一位），当然也可以理解为把最后一个字符搬到开头。你可以执行任意多次（包括 $0$ 次）循环移位。

请判断：$t$ 能否由 $s$ 经过若干次循环移位得到？

例如 $s = \text{abcde}$，左移 $2$ 次后得到 $\text{cdeab}$，所以当 $t = \text{cdeab}$ 时答案是 `YES`；而 $t = \text{abced}$ 虽然与 $s$ 字符集合相同，但不是 $s$ 的循环移位，答案是 `NO`。

### 输入格式

- 第一行一个整数 $n$，表示字符串长度。
- 第二行一个长度为 $n$ 的小写字符串 $s$。
- 第三行一个长度为 $n$ 的小写字符串 $t$。

### 输出格式

输出一行：如果 $t$ 是 $s$ 的某个循环移位，输出 `YES`，否则输出 `NO`。

### 数据范围

- $1 \le n \le 2 \times 10^5$。
- $s$ 与 $t$ 只含小写英文字母 `a` 到 `z`，且长度都恰好为 $n$。

### 样例说明

样例 1：$n = 5$，$s = \text{abcde}$，$t = \text{cdeab}$。把 $s$ 左移 $2$ 个位置恰好得到 $\text{cdeab}$，所以输出 `YES`。
