# 回文子串判定

给定一个长度为 $n$、只含小写英文字母的字符串 $s$，以及 $q$ 个询问。每个询问给出两个整数 $l, r$（$1 \le l \le r \le n$），问：子串 $s[l..r]$ 是否是**回文串**？

回文串指正着读和倒着读完全相同的字符串，例如 `abcba`、`aa`、`z` 都是回文串，而 `ab` 不是。

### 输入格式

- 第一行一个整数 $n$。
- 第二行一个长度为 $n$ 的小写字符串 $s$。
- 第三行一个整数 $q$。
- 接下来 $q$ 行，每行两个整数 $l, r$，表示一个询问。

### 输出格式

输出一行 $q$ 个整数，用空格分隔。第 $j$ 个整数为 `1` 表示第 $j$ 个询问对应的子串是回文串，为 `0` 表示不是。

### 数据范围

- $1 \le n \le 2 \times 10^5$，$1 \le q \le 2 \times 10^5$。
- $1 \le l \le r \le n$。
- $s$ 只含小写英文字母 `a` 到 `z`。

### 样例说明

样例 1：$n = 5$，$s = \text{abcba}$，$q = 3$。

- 询问 $[1,5]$：子串 `abcba` 正反相同，是回文串，答案为 `1`；
- 询问 $[1,3]$：子串 `abc` 不是回文串，答案为 `0`；
- 询问 $[2,4]$：子串 `bcb` 是回文串，答案为 `1`。

所以输出 `1 0 1`。
