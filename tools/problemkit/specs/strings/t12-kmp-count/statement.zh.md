# 模式串出现次数

给定一个长度为 $n$ 的文本串 $s$ 和一个长度为 $m$ 的模式串 $p$，两者都只含小写英文字母。

请统计 $p$ 在 $s$ 中作为**连续子串**出现的次数。注意匹配可以**重叠**：只要存在起点 $i$（$1 \le i \le n - m + 1$）使得 $s[i..i+m-1] = p$，就算一次出现，不同的起点分别计数。

例如 $s = \text{ababababa}$、$p = \text{aba}$ 时，匹配的起点分别是 $1, 3, 5, 7$（从 $1$ 开始计数），共 $4$ 次。

### 输入格式

- 第一行一个整数 $n$，表示文本串长度。
- 第二行一个长度为 $n$ 的小写字符串 $s$。
- 第三行一个整数 $m$，表示模式串长度。
- 第四行一个长度为 $m$ 的小写字符串 $p$。

### 输出格式

输出一行一个整数，表示 $p$ 在 $s$ 中出现的次数（重叠的匹配分别计数）。

### 数据范围

- $1 \le m \le n \le 2 \times 10^5$。
- $s$ 与 $p$ 只含小写英文字母 `a` 到 `z`，且长度分别恰好为 $n$、$m$。

### 样例说明

样例 1：$n = 9$，$s = \text{ababababa}$，$m = 3$，$p = \text{aba}$。

依次检查每个起点（从 $1$ 开始）：

| 起点 | 子串 | 是否等于 $p$ |
| --- | --- | --- |
| 1 | aba | 是 |
| 2 | bab | 否 |
| 3 | aba | 是 |
| 4 | bab | 否 |
| 5 | aba | 是 |
| 6 | bab | 否 |
| 7 | aba | 是 |

共 $4$ 次，所以输出 `4`。
