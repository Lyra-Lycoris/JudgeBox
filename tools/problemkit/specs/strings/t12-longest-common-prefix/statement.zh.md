# 最长公共前缀长度

给定 $k$ 个非空小写字符串 $w_1, w_2, \ldots, w_k$。

求它们的最长公共前缀的长度，即最大的整数 $L$，使得所有字符串的前 $L$ 个字符都完全相同：

$$w_1[1..L] = w_2[1..L] = \cdots = w_k[1..L].$$

例如 `flower`、`flow`、`flight` 的最长公共前缀是 `fl`，长度为 $2$。

### 输入格式

- 第一行一个整数 $k$，表示字符串个数。
- 第二行 $k$ 个由空格分隔的小写字符串，依次是 $w_1, w_2, \ldots, w_k$。

### 输出格式

输出一行一个整数，表示最长公共前缀的长度。若连第一个字符都不完全相同，输出 `0`。

### 数据范围

- $1 \le k \le 2 \times 10^5$。
- 每个字符串非空，只含小写英文字母 `a` 到 `z`。
- 所有字符串的长度之和不超过 $2 \times 10^5$。

### 样例说明

样例 1：$k = 3$，三个字符串分别是 `flower`、`flow`、`flight`。

- 第 $1$ 个字符都是 `f`，可以继续；
- 第 $2$ 个字符都是 `l`，可以继续；
- 第 $3$ 个字符依次是 `o`、`o`、`i`，不完全相同，必须停止。

所以最长公共前缀是 `fl`，长度为 $2$，输出 `2`。
