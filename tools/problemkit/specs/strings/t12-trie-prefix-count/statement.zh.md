# Trie 前缀计数

给定 $n$ 个非空小写字符串（单词）$w_1, w_2, \ldots, w_n$，以及 $q$ 个非空小写字符串（询问）$t_1, t_2, \ldots, t_q$。

对每个询问 $t_j$，求有多少个单词以它作为前缀，即统计满足

$$|w_i| \ge |t_j| \quad\text{且}\quad w_i[1..|t_j|] = t_j$$

的下标 $i$ 的个数。

### 输入格式

- 第一行一个整数 $n$。
- 第二行 $n$ 个由空格分隔的小写字符串 $w_1, \ldots, w_n$。
- 第三行一个整数 $q$。
- 第四行 $q$ 个由空格分隔的小写字符串 $t_1, \ldots, t_q$。

### 输出格式

输出一行 $q$ 个整数，用空格分隔。第 $j$ 个整数表示以 $t_j$ 为前缀的单词个数。

### 数据范围

- $1 \le n, q \le 2 \times 10^5$。
- 每个单词和每个询问都非空，只含小写英文字母 `a` 到 `z`。
- 所有单词的长度之和不超过 $2 \times 10^5$；所有询问的长度之和不超过 $2 \times 10^5$。

### 样例说明

样例 1：$n = 4$，单词为 `a`、`ab`、`abc`、`b`；$q = 3$，询问为 `a`、`ab`、`d`。

- 询问 `a`：`a`、`ab`、`abc` 都以它为前缀，共 $3$ 个；
- 询问 `ab`：`ab`、`abc` 以它为前缀，共 $2$ 个；
- 询问 `d`：没有单词以 `d` 开头，共 $0$ 个。

所以输出 `3 2 0`。
