# 游程编码压缩长度查询

游程编码（Run-Length Encoding，RLE）是一种最朴素的压缩方式：把字符串中连续相同的字符看成一段（run），每段写作「该字符 + 该段的长度」。

本题采用如下精确规则：对字符串中的每一段（极大连续相同字符段），设其长度为 $c$，

- 若 $c = 1$，编码中只写这一个字符，占 $1$ 个字符位置；
- 若 $c \ge 2$，编码中写「该字符 + $c$ 的十进制表示」，占 $1 + \operatorname{digits}(c)$ 个字符位置，其中 $\operatorname{digits}(c)$ 表示 $c$ 的十进制位数（例如 $\operatorname{digits}(9)=1$，$\operatorname{digits}(10)=2$，$\operatorname{digits}(200000)=6$）。

例如 `aaabbc` 分成 `aaa`、`bb`、`c` 三段，长度分别为 $3, 2, 1$，编码为 `a3b2c`，总长度为 $2 + 2 + 1 = 5$。

现在给定长度为 $n$ 的字符串 $s$ 和 $q$ 个询问，每个询问给出 $l, r$（$1 \le l \le r \le n$），请计算**子串 $s[l..r]$ 的游程编码长度**。注意只看这个子串本身：两端的段可能被截断，必须按截断后的实际长度重新计算。

### 输入格式

- 第一行一个整数 $n$。
- 第二行一个长度为 $n$ 的小写字符串 $s$。
- 第三行一个整数 $q$。
- 接下来 $q$ 行，每行两个整数 $l, r$，表示一个询问。

### 输出格式

输出一行 $q$ 个整数，用空格分隔，依次为每个询问的答案。

### 数据范围

- $1 \le n \le 2 \times 10^5$，$1 \le q \le 2 \times 10^5$。
- $1 \le l \le r \le n$。
- $s$ 只含小写英文字母 `a` 到 `z`。

### 样例说明

样例 1：$n = 6$，$s = \text{aaabbc}$，$q = 4$。

- 询问 $[1,6]$：子串 `aaabbc`，编码 `a3b2c`，长度 $2+2+1 = 5$；
- 询问 $[1,3]$：子串 `aaa`，编码 `a3`，长度 $2$；
- 询问 $[4,6]$：子串 `bbc`，编码 `b2c`，长度 $2+1 = 3$；
- 询问 $[1,1]$：子串 `a`，只有一个字符，编码 `a`，长度 $1$。

所以输出 `5 2 3 1`。
