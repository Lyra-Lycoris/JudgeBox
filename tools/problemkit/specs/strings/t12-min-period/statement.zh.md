# 最小循环节长度

给定一个长度为 $n$ 的小写英文字符串 $s$。

如果存在一个长度 $d$（$1 \le d \le n$，且 $d$ 整除 $n$），使得 $s$ 恰好由 $\frac{n}{d}$ 个相同的长度为 $d$ 的串首尾拼接而成，即

$$s[1..d] = s[d+1..2d] = \cdots = s[n-d+1..n],$$

就称 $d$ 是 $s$ 的一个**循环节长度**。请输出 $s$ 的最小循环节长度。

例如 $s = \text{abcabcabc}$ 的循环节长度可以是 $3$（三个 `abc`）或 $9$（它自己），最小的是 $3$。

### 输入格式

- 第一行一个整数 $n$，表示字符串长度。
- 第二行一个长度为 $n$ 的小写字符串 $s$。

### 输出格式

输出一行一个整数，表示 $s$ 的最小循环节长度。

### 数据范围

- $1 \le n \le 2 \times 10^5$。
- $s$ 只含小写英文字母 `a` 到 `z`，长度恰好为 $n$。

### 样例说明

样例 1：$n = 9$，$s = \text{abcabcabc}$。

- $d = 1$：$1$ 不整除 $9$，不合法。
- $d = 2$：$2$ 不整除 $9$，不合法。
- $d = 3$：$s = \text{abc}\,\text{abc}\,\text{abc}$，合法。

所以最小循环节长度是 $3$，输出 `3`。
