# 快速幂取模

给定三个整数 $a, b, m$，求 $a^b \bmod m$ 的值。本题约定 $0^0 = 1$。

由于 $b$ 可能非常大（最大 $10^{18}$），直接连乘 $b$ 次一定会超时，请使用快速幂：把 $b$ 写成二进制，逐位平方并累乘，单次询问只需要 $O(\log b)$ 次乘法。

### 输入格式

一行三个整数 $a, b, m$，相邻两个数用一个空格隔开。

### 输出格式

一行一个整数，表示 $a^b \bmod m$ 的值，取值范围是 $[0, m-1]$。

### 数据范围

$0 \le a \le 10^9$，$0 \le b \le 10^{18}$，$1 \le m \le 10^9$。

答案以及计算过程中的中间乘积都不超过 $10^{18}$，可以用 64 位整数保存。

### 样例说明

$a = 2$，$b = 10$，$m = 1000$：$2^{10} = 1024$，$1024 \bmod 1000 = 24$，所以输出 `24`。
