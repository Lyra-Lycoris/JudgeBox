# 因数个数

给定正整数 $n$，求 $n$ 的正因数（能整除 $n$ 的正整数）共有多少个。

例如 $12$ 的正因数有 $1, 2, 3, 4, 6, 12$，共 $6$ 个。

$n$ 最大可以到 $10^{12}$，从 $1$ 枚举到 $n$ 会超时。注意到因数总是成对出现：若 $d$ 是 $n$ 的因数，则 $n/d$ 也是；因此只需要枚举 $1 \le d \le \lfloor\sqrt{n}\rfloor$，每找到一个 $d$ 就贡献两个因数，当 $d = n/d$（即 $n$ 是完全平方数）时只贡献一个。时间复杂度 $O(\sqrt{n})$。

### 输入格式

一行一个整数 $n$。

### 输出格式

一行一个整数，表示 $n$ 的正因数个数。

### 数据范围

$1 \le n \le 10^{12}$。

### 样例说明

$n = 12$：枚举 $d = 1, 2, 3$，其中 $1, 2, 3$ 都能整除 $12$，并且 $1^2, 2^2, 3^2$ 都不等于 $12$，所以每个贡献两个因数，共 $2 \times 3 = 6$ 个。
