# 最大公约数与最小公倍数

给定 $T$ 组整数对 $(a, b)$，对每一组分别求出 $a$ 与 $b$ 的最大公约数 $\gcd(a, b)$ 和最小公倍数 $\operatorname{lcm}(a, b)$。

本题约定：

- $\gcd(0, x) = x$，特别地 $\gcd(0, 0) = 0$；
- 只要 $a$ 与 $b$ 中至少有一个是 $0$，就有 $\operatorname{lcm}(a, b) = 0$；
- 当 $a$ 与 $b$ 都为正整数时 $\operatorname{lcm}(a, b) = a \div \gcd(a, b) \times b$。

### 输入格式

第一行一个整数 $T$，表示数据组数。接下来 $T$ 行，每行两个整数 $a, b$，用一个空格隔开。

### 输出格式

输出 $T$ 行，每行两个整数，依次为 $\gcd(a, b)$ 与 $\operatorname{lcm}(a, b)$，两个整数之间用一个空格隔开。

### 数据范围

$1 \le T \le 1000$，$0 \le a, b \le 10^9$。答案保证不超过 $10^{18}$，可以用 64 位整数保存。

### 样例说明

样例共有 3 组：

- $\gcd(12, 18) = 6$，$\operatorname{lcm}(12, 18) = 12 \div 6 \times 18 = 36$；
- $7$ 与 $5$ 互质，所以最大公约数是 $1$，最小公倍数是 $35$；
- $10^9$ 与 $999999999$ 是相邻整数，必然互质，所以最小公倍数是 $10^9 \times 999999999 = 999999999000000000$。
