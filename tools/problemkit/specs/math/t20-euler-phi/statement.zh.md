# 欧拉函数

对正整数 $n$，欧拉函数 $\varphi(n)$ 表示 $1$ 到 $n$ 中与 $n$ 互质的整数个数（约定 $\varphi(1) = 1$）。

若 $n$ 的质因数分解为 $n = p_1^{e_1} p_2^{e_2} \cdots p_k^{e_k}$，则

$$\varphi(n) = n \prod_{i=1}^{k}\left(1 - \frac{1}{p_i}\right).$$

因为 $n \le 10^{12}$，可以只枚举 $2 \le p \le \sqrt{n}$ 试除：每找到一个质因子 $p$，就把 $n$ 中所有因子 $p$ 除干净，并令答案乘以 $(1 - 1/p)$。试除结束后若剩下的数大于 $1$，它本身就是一个质因子，需要再处理一次。复杂度 $O(\sqrt{n})$。

### 输入格式

一行一个整数 $n$。

### 输出格式

一行一个整数，表示 $\varphi(n)$。

### 数据范围

$1 \le n \le 10^{12}$。答案不超过 $10^{12}$，可以用 64 位整数保存。

### 样例说明

$n = 36 = 2^2 \times 3^2$，所以

$$\varphi(36) = 36 \times \left(1 - \frac{1}{2}\right) \times \left(1 - \frac{1}{3}\right) = 36 \times \frac{1}{2} \times \frac{2}{3} = 12.$$

$1$ 到 $36$ 中与 $36$ 互质的数共有 $12$ 个，例如 $1, 5, 7, 11, \dots$。
