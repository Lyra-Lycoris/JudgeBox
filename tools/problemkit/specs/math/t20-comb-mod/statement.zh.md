# 组合数取模

给定整数 $n, k$ 和一个质数 $p$，求

$$\binom{n}{k} \bmod p .$$

其中 $0 \le k \le n \le 10^6$ 且 $n < p$。

**做法**：由于 $n < p$，$1, 2, \dots, n$ 中没有 $p$ 的倍数，所以

$$\binom{n}{k} = \frac{n (n-1) \cdots (n-k+1)}{k!}$$

的分子与分母在模 $p$ 下都不为 $0$。分别累乘分子与分母，再用费马小定理把分母的逆元求出来：

$$x^{-1} \equiv x^{p-2} \pmod p .$$

于是 $\binom{n}{k} \equiv \text{分子} \times \text{分母}^{p-2} \pmod p$，时间复杂度 $O(k \log p)$。计算前先把 $k$ 换成 $\min(k, n-k)$ 可以少算一半。

### 输入格式

一行三个整数 $n, k, p$，用一个空格隔开。

### 输出格式

一行一个整数，表示 $\binom{n}{k} \bmod p$，取值范围是 $[0, p-1]$。

### 数据范围

$0 \le k \le n \le 10^6$，$p$ 是质数，$n < p \le 10^9+7$。

### 样例说明

$\binom{5}{2} = \dfrac{5 \times 4}{2 \times 1} = 10$，对 $10^9+7$ 取模后仍是 $10$，所以输出 `10`。
