# 素数筛计数

给定 $n$ 个正整数 $x_1, x_2, \dots, x_n$，对每个 $x_i$ 分别求：不超过 $x_i$ 的素数有多少个。

例如 $\le 10$ 的素数有 $2, 3, 5, 7$ 共 $4$ 个；$\le 100$ 的素数有 $25$ 个。

由于询问很多、$x_i$ 也很大，对每个询问单独试除会超时。正确做法是用埃氏筛（或线性筛）预处理出 $1$ 到 $\max x_i$ 中的所有素数，再对每个询问二分（或直接做前缀计数）回答。

### 输入格式

第一行一个整数 $n$，表示询问个数。

第二行 $n$ 个整数 $x_1, x_2, \dots, x_n$，相邻两个数用一个空格隔开（数据可能分多行给出，以空格或换行分隔均可）。

### 输出格式

一行 $n$ 个整数，第 $i$ 个数表示不超过 $x_i$ 的素数个数，相邻两个数用一个空格隔开。

### 数据范围

$1 \le n \le 200000$，$1 \le x_i \le 10^7$。

建议时间复杂度 $O(\max x_i \log\log \max x_i + n \log \max x_i)$。

### 样例说明

三个询问分别是 $10, 1, 100$：

- 不超过 $10$ 的素数是 $2, 3, 5, 7$，共 $4$ 个；
- 不超过 $1$ 的素数不存在，共 $0$ 个；
- 不超过 $100$ 的素数共 $25$ 个。

所以输出 `4 0 25`。
