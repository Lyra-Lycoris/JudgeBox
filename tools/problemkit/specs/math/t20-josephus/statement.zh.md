# 约瑟夫环最后剩下的人

$n$ 个人围成一圈，编号从 $1$ 到 $n$ 顺时针排列。从 $1$ 号开始，沿着顺时针方向报数，报到 $k$ 的人立刻离开圈子；下一个人重新从 $1$ 开始报数，如此反复，直到圈里只剩下一个人。求最后剩下的人的编号。

**朴素做法**：设 $f(i)$ 表示圈里剩 $i$ 个人（编号从 $0$ 开始）时最后剩下的人的下标，则有递推

$$f(1) = 0, \qquad f(i) = (f(i-1) + k) \bmod i .$$

答案为 $f(n) + 1$（换回从 $1$ 开始编号）。这个递推是 $O(n)$ 的，当 $n = 10^{18}$ 时无法运行。

**优化**：递推中很多步都不会发生取模。若当前人数为 $m$、当前值为 $f$，则接下来连续 $t$ 步满足 $f + j k < m + j$（即 $j(k-1) < m - f$）时可以直接跳过：

$$t = \left\lfloor \frac{m - f - 1}{k - 1} \right\rfloor .$$

于是可以一次把人数推进 $t$ 步（同时把 $f$ 加上 $t k$），只在真正发生取模时走一步。总复杂度 $O(k \log n)$。注意 $k = 1$ 时 $k - 1 = 0$，此时答案直接就是 $n$。

### 输入格式

一行两个整数 $n, k$，用一个空格隔开。

### 输出格式

一行一个整数，表示最后剩下的人的编号（从 $1$ 开始）。

### 数据范围

$1 \le n \le 10^{18}$，$1 \le k \le 10000$。

### 样例说明

$n = 5$，$k = 2$：出圈顺序是 $2, 4, 1, 5$（每轮报数 $1, 2$，报到 $2$ 的人离开），最后剩下 $3$ 号，所以输出 `3`。
