# 单源最短路（Dijkstra）

给定一张 $n$ 个点、$m$ 条边的**有向图**，每条边的长度都是非负整数。再给定起点 $s$，请计算 $s$ 到每个点的最短距离。

如果某个点 $t$ 从 $s$ 出发无法到达，则规定 $s$ 到 $t$ 的距离为 $-1$。

### 输入

第一行三个整数 $n$、$m$、$s$，用空格分隔。

接下来 $m$ 行，每行三个整数 $u$、$v$、$w$，表示一条从 $u$ 指向 $v$、长度为 $w$ 的有向边。

### 输出

输出一行 $n$ 个整数，第 $i$ 个整数表示 $s$ 到点 $i$ 的最短距离；若不可达则为 $-1$。

### 数据范围

- $1 \le n \le 200000$，$0 \le m \le 200000$
- $1 \le u, v, s \le n$
- $0 \le w \le 10^9$
- 图中允许重边与自环
- 起点到任意点的最短距离不超过 $2 \times 10^{14}$，在 64 位有符号整数范围内
- 时间限制 2000 ms，空间限制 256 MB

### 样例

**输入**

```
4 5 1
1 2 2
1 3 5
2 3 1
2 4 6
3 4 2
```

**输出**

```
0 2 3 5
```

### 样例说明

从 $1$ 号点出发：

- 到 $1$ 号点距离为 $0$；
- 到 $2$ 号点直接走 $1 \to 2$，距离 $2$；
- 到 $3$ 号点走 $1 \to 2 \to 3$，距离 $2 + 1 = 3$，比直接走 $1 \to 3$ 的 $5$ 更优；
- 到 $4$ 号点走 $1 \to 2 \to 3 \to 4$，距离 $2 + 1 + 2 = 5$，比 $1 \to 2 \to 4$ 的 $8$ 更优。

所以输出 `0 2 3 5`。
