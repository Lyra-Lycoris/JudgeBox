# 负环判定（Bellman-Ford）

给定一张 $n$ 个点、$m$ 条边的**有向图**，边权可以为负。再给定起点 $s$。

请判断：图中是否存在一个**从 $s$ 出发可以到达**的负权环（环上所有边的权值之和为负）？

注意，只有在 $s$ 出发能走到的负环才会影响最短路，因此**不可达**的负环不计入答案。

### 输入

第一行三个整数 $n$、$m$、$s$，用空格分隔。

接下来 $m$ 行，每行三个整数 $u$、$v$、$w$，表示一条从 $u$ 指向 $v$、权值为 $w$ 的有向边。

### 输出

如果存在从 $s$ 可达的负权环，输出 `YES`；否则输出 `NO`。

### 数据范围

- $1 \le n \le 500$，$0 \le m \le 2000$
- $1 \le u, v, s \le n$
- $|w| \le 10^9$
- 图中允许重边与自环（一条 $u \to u$ 且权值为负的边本身就是一个负环）
- 时间限制 2000 ms，空间限制 256 MB

### 样例

**输入**

```
4 4 1
1 2 1
2 3 -3
3 4 1
4 2 -1
```

**输出**

```
YES
```

### 样例说明

从 $1$ 出发走 $1 \to 2$ 后进入环 $2 \to 3 \to 4 \to 2$，该环的权值和为

$$(-3) + 1 + (-1) = -3 < 0$$

这是一个从 $s = 1$ 可达的负环，所以输出 `YES`。
