# 严格次短路

给定一张 $n$ 个点、$m$ 条边的**无向图**，每条边的权值都是正整数。点从 $1$ 到 $n$ 编号。

一条从 $1$ 到 $n$ 的**行走路线**可以重复经过同一个点或同一条边，它的长度是路上所有边权之和。

记所有从 $1$ 到 $n$ 的行走路线长度中最小者为 $d_1$。请找出**严格大于** $d_1$ 的最小长度 $d_2$，也就是「严格次短路」的长度。

### 输入

第一行两个整数 $n$、$m$，用空格分隔。

接下来 $m$ 行，每行三个整数 $u$、$v$、$w$，表示一条连接 $u$ 与 $v$、权值为 $w$ 的无向边。

### 输出

输出一行一个整数，表示严格次短路的长度。如果 $n$ 从 $1$ 不可达，或者不存在长度严格大于 $d_1$ 的行走路线，输出 $-1$。

### 数据范围

- $2 \le n \le 20000$，$1 \le m \le 100000$
- $1 \le u, v \le n$，$1 \le w \le 10^9$
- 图中允许重边与自环
- 答案不超过 $2.1 \times 10^{13}$，在 64 位有符号整数范围内
- 时间限制 2000 ms，空间限制 256 MB

### 样例

**输入**

```
4 4
1 2 1
2 4 3
1 3 2
3 4 4
```

**输出**

```
6
```

### 样例说明

从 $1$ 到 $4$ 的走法有：

- $1 \to 2 \to 4$，长度 $1 + 3 = 4$，这是最短路 $d_1 = 4$；
- $1 \to 3 \to 4$，长度 $2 + 4 = 6$；
- $1 \to 2 \to 1 \to 2 \to 4$，长度 $1 + 1 + 1 + 3 = 6$；
- 更长的走法长度都大于 $6$。

严格大于 $4$ 的最小长度是 $6$，所以输出 `6`。
