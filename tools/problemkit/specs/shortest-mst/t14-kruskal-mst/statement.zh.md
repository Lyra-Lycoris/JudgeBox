# 最小生成树（Kruskal）

给定一张 $n$ 个点、$m$ 条边的**无向连通图**，请计算它的最小生成树（MST）的总权重，即选出 $n-1$ 条边把所有点连通、且边权之和最小。

### 输入

第一行两个整数 $n$、$m$，用空格分隔。

接下来 $m$ 行，每行三个整数 $u$、$v$、$w$，表示一条连接 $u$ 与 $v$、权值为 $w$ 的无向边。

### 输出

输出一行一个整数，表示最小生成树的总权重。

### 数据范围

- $1 \le n \le 200000$，$0 \le m \le 200000$
- $1 \le u, v \le n$，$|w| \le 10^9$
- 当 $n \ge 2$ 时保证图连通；当 $n = 1$ 时没有边，答案为 $0$
- 图中允许重边与自环
- 答案不超过 $2 \times 10^{14}$，在 64 位有符号整数范围内
- 时间限制 2000 ms，空间限制 256 MB

### 样例

**输入**

```
4 5
1 2 1
1 3 4
2 3 2
2 4 5
3 4 3
```

**输出**

```
6
```

### 样例说明

选出边 $1-2$（$1$）、$2-3$（$2$）、$3-4$（$3$），它们把 $4$ 个点全部连通，总权重为

$$1 + 2 + 3 = 6.$$

任何其它连通方案的权重都不小于 $6$（例如换成 $2-4$（$5$）会得到 $1+2+5=8$），所以答案是 `6`。
