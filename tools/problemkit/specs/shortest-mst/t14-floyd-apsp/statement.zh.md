# 任意两点最短路（Floyd）

给定一张 $n$ 个点的**有向图**，用邻接矩阵给出：$w_{i,j}$ 表示从点 $i$ 到点 $j$ 的直接边权，$w_{i,j} = -1$ 表示这条边不存在。保证 $w_{i,i} = 0$。

求任意两点之间的最短距离，即对每一对 $(i, j)$ 求出 $i$ 到 $j$ 的最短路长度。

### 输入

第一行一个整数 $n$。

接下来 $n$ 行，每行 $n$ 个整数，表示矩阵 $w$。

### 输出

输出一行 $n^2$ 个整数，按**行优先**顺序给出 $d_{i,j}$：第 $i$ 行第 $j$ 列（从 $1$ 开始编号）的数是点 $i$ 到点 $j$ 的最短距离，若不可达则为 $-1$。

### 数据范围

- $1 \le n \le 300$
- $w_{i,i} = 0$
- 对于 $i \ne j$：$w_{i,j} = -1$ 表示没有直接边，否则 $0 \le w_{i,j} \le 10^9$
- 输入保证没有负权边，任意两点间的最短距离不超过 $3 \times 10^{11}$
- 时间限制 3000 ms，空间限制 256 MB

### 样例

**输入**

```
4
0 3 -1 7
-1 0 2 -1
-1 -1 0 1
-1 -1 -1 0
```

**输出**

```
0 3 5 6 -1 0 2 3 -1 -1 0 1 -1 -1 -1 0
```

### 样例说明

矩阵对应的边为：$1 \to 2$（$3$）、$1 \to 4$（$7$）、$2 \to 3$（$2$）、$3 \to 4$（$1$）。

- $1 \to 3$ 走 $1 \to 2 \to 3$，长度 $3 + 2 = 5$，比 $1 \to 4$ 再回走更短；
- $1 \to 4$ 走 $1 \to 2 \to 3 \to 4$，长度 $3 + 2 + 1 = 6$，优于直接边 $7$；
- $2 \to 4$ 长度为 $2 + 1 = 3$；
- 从 $4$ 号点出发没有任何出边，所以第 $4$ 行除 $d_{4,4} = 0$ 以外全是 $-1$。

按行优先输出即为样例给出的那一行。
