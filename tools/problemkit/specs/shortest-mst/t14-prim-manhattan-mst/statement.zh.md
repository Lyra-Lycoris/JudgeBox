# 曼哈顿距离最小生成树（Prim）

平面上有 $n$ 个点，第 $i$ 个点的坐标是 $(x_i, y_i)$。

把每个点看成一个顶点，任意两点 $i, j$ 之间都有一条权值为曼哈顿距离

$$d(i, j) = |x_i - x_j| + |y_i - y_j|$$

的无向边，于是得到一个有 $\frac{n(n-1)}{2}$ 条边的**完全图**。请计算这张完全图的最小生成树的总权重。

两个点重合时它们之间的距离为 $0$。

### 输入

第一行一个整数 $n$。

接下来 $n$ 行，每行两个整数 $x_i$、$y_i$，用空格分隔。

### 输出

输出一行一个整数，表示完全图最小生成树的总权重。

### 数据范围

- $1 \le n \le 1200$
- $|x_i|, |y_i| \le 10^9$
- 允许存在坐标相同的点
- 答案不超过 $4.8 \times 10^{12}$，在 64 位有符号整数范围内
- 时间限制 2000 ms，空间限制 256 MB

### 样例

**输入**

```
4
0 0
1 1
3 0
4 5
```

**输出**

```
11
```

### 样例说明

四个点之间的曼哈顿距离为：$d(1,2)=2$，$d(1,3)=3$，$d(1,4)=9$，$d(2,3)=3$，$d(2,4)=7$，$d(3,4)=6$。

取边 $1-2$（$2$）、$1-3$（$3$）、$3-4$（$6$），三棵子树合成一棵树，总权重

$$2 + 3 + 6 = 11.$$

不存在总权重更小的连通方案，所以输出 `11`。
