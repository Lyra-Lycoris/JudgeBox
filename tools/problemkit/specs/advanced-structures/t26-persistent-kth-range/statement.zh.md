# 静态区间第 k 小

给定一个长度为 $n$ 的整数数组 $a_1, a_2, \dots, a_n$，以及 $m$ 次询问。每次询问给出 $l, r, k$，要求输出子数组 $a_l, a_{l+1}, \dots, a_r$ 中第 $k$ 小的数（相同的数按出现次数分别计数）。

一种可行的做法是**可持久化线段树**：把数组的值离散化后，按前缀顺序插入每个位置，第 $i$ 个版本表示 $a_1 \dots a_i$ 的值域计数。询问 $[l, r]$ 时用第 $r$ 个版本减去第 $l-1$ 个版本，在值域线段树上走 $O(\log n)$ 步即可确定第 $k$ 小。也可以使用归并树 + 二分答案。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

第三行一个整数 $m$。

接下来 $m$ 行，每行三个整数 $l, r, k$，表示一次询问。

### 输出

一行，按询问顺序输出每次询问的答案，相邻两个整数之间用一个空格分隔。

### 数据范围

- $1 \le n, m \le 5 \times 10^4$
- $1 \le l \le r \le n$
- $1 \le k \le r - l + 1$
- $|a_i| \le 10^9$

### 样例说明

数组为 $3, 1, 4, 1, 5$，共 $3$ 次询问。

- $[1, 5]$ 排序后为 $1, 1, 3, 4, 5$，第 $1$ 小是 $1$；
- $[3, 5]$ 排序后为 $1, 4, 5$，第 $2$ 小是 $4$；
- $[2, 4]$ 排序后为 $1, 1, 4$，第 $2$ 小是 $1$。

所以输出为 `1 4 1`。
