# 树状数组上二分求第 k 小

有一个可重集合，其中的数取自 $1 \sim n$：数 $i$ 恰好出现 $a_i$ 次（$a_i$ 可以为 $0$，表示 $i$ 不出现）。把集合中的所有数按从小到大排成一列，第 $k$ 个数就称为第 $k$ 小。

初始时给出 $a_1, a_2, \dots, a_n$，随后有 $q$ 次操作，操作分为两种：

- `1 x v`：把 $a_x$ 改为 $v$；
- `2 k 0`：输出当前集合中第 $k$ 小的数。

保证每次询问时 $1 \le k \le$ 集合当前的元素总数（即 $\sum a_i$）。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

第三行一个整数 $q$。

接下来 $q$ 行，每行三个整数 $t, x, v$：

- $t = 1$ 时，$x$ 是下标、$v$ 是新的重数，即 $a_x \leftarrow v$；
- $t = 2$ 时，$x$ 就是 $k$，第三个整数恒为 $0$（不参与计算）。

保证至少有一次 $t = 2$ 的操作。

### 输出

一行，按操作出现的顺序输出每次询问的答案，相邻两个整数之间用一个空格分隔。

### 数据范围

- $1 \le n \le 1.5 \times 10^5$，$1 \le q \le 1.5 \times 10^5$
- $0 \le a_i, v \le 10^9$
- 每次询问保证 $1 \le k \le \sum_{i=1}^{n} a_i$

### 样例说明

初始 $a = (1, 0, 2, 1)$，集合为 $\{1, 3, 3, 4\}$。

`2 1 0` 询问第 $1$ 小，答案是 $1$。

`2 2 0` 询问第 $2$ 小，答案是 $3$。

`2 4 0` 询问第 $4$ 小，答案是 $4$。

`1 2 3` 把 $a_2$ 改为 $3$，集合变为 $\{1, 2, 2, 2, 3, 3, 4\}$。

`2 5 0` 询问第 $5$ 小，答案是 $3$。

所以输出为 `1 3 4 3`。
