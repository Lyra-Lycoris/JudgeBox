# 区间加与区间和（双树状数组）

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$，以及 $q$ 次操作，操作分为两种：

- `1 l r x`：把区间 $[l, r]$ 中的每个数都加上 $x$，即对 $l \le i \le r$ 执行 $a_i \leftarrow a_i + x$；
- `2 l r 0`：求区间和 $\sum_{i=l}^{r} a_i$。

请按顺序执行所有操作，并依次回答每一个 `2` 类操作。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

第三行一个整数 $q$。

接下来 $q$ 行，每行四个整数 $t, l, r, x$：

- $t = 1$ 表示把 $[l, r]$ 每个数加上 $x$；
- $t = 2$ 表示询问 $[l, r]$ 的和，此时第四个整数恒为 $0$，不参与计算。

保证至少有一次 $t = 2$ 的操作。

### 输出

一行，按操作出现的顺序输出每次区间求和的答案，相邻两个整数之间用一个空格分隔。

### 数据范围

- $1 \le n \le 2 \times 10^5$，$1 \le q \le 10^5$
- $1 \le l \le r \le n$
- $|a_i| \le 10^6$，$|x| \le 10^6$
- 任意时刻 $\sum_{i=1}^{n} |a_i| \le 10^{15}$，因此所有答案都在 $64$ 位整数范围内

### 样例说明

初始序列为 $1, 2, 3, 4, 5$。

`1 1 3 10` 把前三个数各加 $10$，序列变为 $11, 12, 13, 4, 5$。

`2 1 5 0` 询问整段之和，$11 + 12 + 13 + 4 + 5 = 45$。

`1 2 2 -5` 把第二个数减去 $5$，序列变为 $11, 7, 13, 4, 5$。

`2 2 4 0` 询问 $[2, 4]$ 之和，$7 + 13 + 4 = 24$。

所以输出为 `45 24`。
