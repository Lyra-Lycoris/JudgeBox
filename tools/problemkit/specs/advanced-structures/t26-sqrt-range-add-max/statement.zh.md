# 分块：区间加与区间最大值

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$，以及 $q$ 次操作，操作分为两种：

- `1 l r x`：把区间 $[l, r]$ 中的每个数都加上 $x$；
- `2 l r 0`：求区间最大值 $\max_{l \le i \le r} a_i$。

请按顺序执行所有操作，并依次回答每一个询问。

为了让每行的整数个数保持一致，两种操作都给出 $4$ 个整数：询问操作的第四个整数恒为 $0$，不参与计算。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

第三行一个整数 $q$。

接下来 $q$ 行，每行四个整数 $t, l, r, x$：

- $t = 1$ 表示把 $[l, r]$ 每个数加上 $x$；
- $t = 2$ 表示询问 $[l, r]$ 的最大值，此时 $x$ 恒为 $0$。

保证至少有一次 $t = 2$ 的操作。

### 输出

一行，按操作出现的顺序输出每次询问的答案，相邻两个整数之间用一个空格分隔。

### 数据范围

- $1 \le n \le 2 \times 10^5$，$1 \le q \le 2 \times 10^4$
- $1 \le l \le r \le n$
- $|a_i| \le 10^6$，$|x| \le 10^6$

### 样例说明

初始序列为 $1, 3, -2, 4, 5$。

`2 1 5 0` 询问整段最大值，为 $5$。

`1 2 4 10` 把第 $2 \sim 4$ 个数各加 $10$，序列变为 $1, 13, 8, 14, 5$。

`2 1 5 0` 询问整段最大值，为 $14$。

`2 2 3 0` 询问 $[2, 3]$ 的最大值，为 $\max(13, 8) = 13$。

`1 1 5 -20` 把每个数减去 $20$，序列变为 $-19, -7, -12, -6, -15$。

`2 1 5 0` 询问整段最大值，为 $-6$。

所以输出为 `5 14 13 -6`。
