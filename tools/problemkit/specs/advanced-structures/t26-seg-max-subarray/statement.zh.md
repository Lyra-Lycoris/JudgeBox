# 线段树维护区间最大子段和

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$，以及 $q$ 次询问。每次询问给出 $l, r$，要求

$$\max_{l \le i \le j \le r} \sum_{k=i}^{j} a_k,$$

即区间 $[l, r]$ 内所有**非空**连续子段的和的最大值。注意子段必须非空，因此答案至少是区间内的最大值之一。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

第三行一个整数 $q$。

接下来 $q$ 行，每行两个整数 $l, r$，表示一次询问。

### 输出

一行，按询问出现的顺序输出每次询问的答案，相邻两个整数之间用一个空格分隔。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $1 \le q \le 2 \times 10^4$
- $1 \le l \le r \le n$
- $|a_i| \le 10^9$

### 样例说明

初始序列为 $2, -3, 4, -1, 2, -5, 3$。

`1 7` 询问整段：取子段 $[3, 5]$ 得 $4 + (-1) + 2 = 5$，整段之和只有 $2$，所以答案是 $5$。

`3 5` 询问 $[3, 5]$，只有这一段可取，答案为 $4 + (-1) + 2 = 5$。

`1 2` 询问 $[1, 2]$，两个数 $2, -3$，取 $[1, 1]$ 得 $2$。

`2 6` 询问 $[-3, 4, -1, 2, -5]$，取子段 $[2, 5]$ 得 $4 + (-1) + 2 = 5$。

`4 4` 询问单点，答案为 $a_4 = -1$。

所以输出为 `5 5 2 5 -1`。
