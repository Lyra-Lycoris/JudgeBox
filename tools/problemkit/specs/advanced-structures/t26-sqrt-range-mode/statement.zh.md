# 区间众数（分块）

给定一个长度为 $n$ 的整数数组 $a_1, a_2, \dots, a_n$，以及 $q$ 次询问。每次询问给出两个整数 $l, r$，请找出子数组 $a_l, a_{l+1}, \dots, a_r$ 中的**众数**：出现次数最多的那个数。

如果区间内有多个数并列出现次数最多，输出其中**较小**的那个数。

一种可行的做法是分块：把数组分成大小约为 $\sqrt n$ 的块，预处理出任意两个整块之间区间的众数，询问时用整块的答案作为基准，再暴力检查两端不完整的块，并用每个数出现位置的有序表配合二分统计出现次数。预处理 $O(n\sqrt n)$，单次询问 $O(\sqrt n \log n)$。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

第三行一个整数 $q$。

接下来 $q$ 行，每行两个整数 $l, r$，表示一次询问。

### 输出

一行，按询问顺序输出每次询问的众数，相邻两个整数之间用一个空格分隔。

### 数据范围

- $1 \le n, q \le 5 \times 10^4$
- $1 \le l \le r \le n$
- $|a_i| \le 10^9$

### 样例说明

数组为 $1, 2, 2, 3, 1, 3$，共 $4$ 次询问。

- $[1, 6]$：$1, 2, 3$ 都出现 $2$ 次，并列最多，取较小的 $1$；
- $[2, 3]$：只有 $2, 2$，众数是 $2$；
- $[1, 3]$：$1$ 出现 $1$ 次，$2$ 出现 $2$ 次，众数是 $2$；
- $[4, 6]$：$3$ 出现 $2$ 次，$1$ 出现 $1$ 次，众数是 $3$。

所以输出为 `1 2 2 3`。
