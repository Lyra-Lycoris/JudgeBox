# 矩形面积并

给定 $n$ 个与坐标轴平行的矩形，每个矩形由左下角坐标 $(x_1, y_1)$ 和右上角坐标 $(x_2, y_2)$ 描述，满足 $x_1 < x_2$、$y_1 < y_2$。

求这些矩形覆盖的总面积，被多个矩形重复覆盖的部分只计算一次。

一种可行的做法是扫描线：把每个矩形拆成左右两条竖直边事件，按 $x$ 坐标排序后从左向右扫描；$y$ 方向离散化后用线段树维护当前被覆盖的总长度，每两个相邻事件之间用「被覆盖长度 × 水平距离」累加面积。

### 输入

第一行一个整数 $n$。

接下来 $n$ 行，每行四个整数 $x_1, y_1, x_2, y_2$，描述一个矩形。

### 输出

一行一个整数，表示所有矩形覆盖区域的总面积。

### 数据范围

- $1 \le n \le 2000$
- $-10^9 \le x_1 < x_2 \le 10^9$，$-10^9 \le y_1 < y_2 \le 10^9$
- 保证总面积不超过 $4 \times 10^{18}$，在 $64$ 位有符号整数范围内

### 样例说明

三个矩形分别是 $[0,2] \times [0,2]$、$[1,3] \times [1,3]$、$[2,4] \times [0,1]$。

前两个矩形面积各为 $4$，第三个面积为 $2$；前两个矩形重叠部分为 $[1,2] \times [1,2]$，面积为 $1$。第三个矩形与另外两个都只是边界相接，没有面积重叠。

所以总面积为 $4 + 4 + 2 - 1 = 9$。
