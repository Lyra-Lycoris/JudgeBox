# 异位词分组后的组数

如果两个字符串由完全相同的字母（含重复次数）重新排列而成，就称它们互为**异位词**。例如 `listen`、`silent`、`enlist`、`inlets` 两两互为异位词。

给定 $n$ 个只含小写字母的字符串，把互为异位词的字符串分到同一组（自己和自己也属于同一组）。请输出一共有多少个**不同的组**，也就是这 $n$ 个字符串中出现了多少种不同的「字母构成」。

### 输入格式

- 第一行一个整数 $n$。
- 第二行 $n$ 个字符串，相邻两个用一个空格隔开。

### 输出格式

输出一行一个整数，表示不同分组的个数。

### 数据范围

$1 \le n \le 200000$，$1 \le$ 每个字符串的长度 $\le 10$，字符串只含小写英文字母 `a` 到 `z`。

### 样例说明

样例 1 共 $6$ 个字符串：

- `listen`、`silent`、`enlist`、`inlets` 的字母构成都是 $\{e, i, l, n, s, t\}$，属于第 1 组；
- `google`、`gogole` 的字母构成都是 $\{e, g, g, l, o, o\}$，属于第 2 组。

所以一共有 $2$ 组，输出 `2`。
