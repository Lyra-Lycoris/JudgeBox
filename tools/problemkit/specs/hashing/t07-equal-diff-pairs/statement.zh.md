# 相同差值对计数

给定 $n$ 个整数 $a_1, a_2, \dots, a_n$。如果一对下标 $(i, j)$ 满足 $1 \le i < j \le n$ 且

$$|a_i - a_j| = |i - j|,$$

就称它们是「相同差值对」：数值之差的绝对值正好等于下标之差的绝对值。请统计这样的下标对个数。

### 输入格式

- 第一行一个整数 $n$。
- 第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个用一个空格隔开。

### 输出格式

输出一行一个整数，表示满足条件的不同下标对 $(i, j)$ 的个数。

### 数据范围

$1 \le n \le 200000$，$|a_i| \le 10^9$。

答案最大可以达到 $\frac{n(n-1)}{2}$，约为 $2 \times 10^{10}$，请使用 64 位整数。

### 样例说明

样例 1 中 $n = 5$，序列为 $1, 2, 3, 5, 4$。逐对检查：

| 下标对 | $\lvert a_i - a_j \rvert$ | $\lvert i - j \rvert$ | 是否满足 |
| --- | --- | --- | --- |
| (1, 2) | 1 | 1 | 是 |
| (1, 3) | 2 | 2 | 是 |
| (1, 4) | 4 | 3 | 否 |
| (1, 5) | 3 | 4 | 否 |
| (2, 3) | 1 | 1 | 是 |
| (2, 4) | 3 | 2 | 否 |
| (2, 5) | 2 | 3 | 否 |
| (3, 4) | 2 | 1 | 否 |
| (3, 5) | 1 | 2 | 否 |
| (4, 5) | 1 | 1 | 是 |

共 $4$ 对满足条件，所以输出 `4`。

### 提示

把绝对值拆开，条件等价于 $a_i - i = a_j - j$ 或 $a_i + i = a_j + j$。分别统计这两种「键」相同的下标对即可。
