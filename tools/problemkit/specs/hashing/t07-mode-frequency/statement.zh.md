# 众数出现次数

给定 $n$ 个整数 $a_1, a_2, \dots, a_n$，请统计出现次数最多的那个数一共出现了多少次。这个次数称为这组数据的「众数出现次数」，即使有多个数并列出现次数最多，答案也只有一个。

### 输入格式

- 第一行一个整数 $n$。
- 第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个用一个空格隔开。

### 输出格式

输出一行一个整数，表示出现次数最多的数的出现次数。

### 数据范围

$1 \le n \le 200000$，$|a_i| \le 10^9$。

### 样例说明

样例 1 中序列为 $1, 2, 2, 3, 3, 3, 4$：

- $1$ 出现 $1$ 次，$2$ 出现 $2$ 次，$3$ 出现 $3$ 次，$4$ 出现 $1$ 次；
- 出现次数最多的是 $3$，共 $3$ 次。

因此输出 `3`。
