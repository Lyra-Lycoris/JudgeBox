# 两数之和是否存在

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$ 以及一个整数 $target$，判断是否存在两个**不同**的下标 $i < j$，满足

$$a_i + a_j = target.$$

### 输入格式

- 第一行一个整数 $n$。
- 第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个用一个空格隔开。
- 第三行一个整数 $target$。

### 输出格式

如果存在这样的一对下标，输出一行 `YES`；否则输出一行 `NO`。

### 数据范围

$1 \le n \le 200000$，$|a_i| \le 10^9$，$|target| \le 2 \times 10^9$。

### 样例说明

样例 1 中 $n = 4$，序列为 $2, 7, 11, 15$，$target = 9$。取 $a_1 = 2$ 与 $a_2 = 7$，它们的和正好是 $9$，因此输出 `YES`。

注意下标必须不同：当 $n = 1$ 时一定输出 `NO`。
