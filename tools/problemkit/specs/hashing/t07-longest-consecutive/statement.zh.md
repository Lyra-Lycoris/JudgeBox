# 最长连续序列长度

给定 $n$ 个整数 $a_1, a_2, \dots, a_n$。考虑去重后（相同的数只算一个）的所有数值，请找出其中最长的一段**连续整数**，输出这段区间的长度。

例如数值集合为 $\{1, 2, 3, 10, 11, 12, 13\}$ 时，最长的一段是 $10, 11, 12, 13$，长度为 $4$。

### 输入格式

- 第一行一个整数 $n$。
- 第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个用一个空格隔开。

### 输出格式

输出一行一个整数，表示最长连续整数段的长度。

### 数据范围

$1 \le n \le 200000$，$|a_i| \le 10^9$。

### 样例说明

样例 1 的数值集合为 $\{1, 2, 3, 4, 100, 200\}$：

- $1, 2, 3, 4$ 是连续的，长度 $4$；
- $100$ 和 $200$ 各自单独成段，长度都是 $1$。

所以最长连续段长度为 $4$，输出 `4`。
