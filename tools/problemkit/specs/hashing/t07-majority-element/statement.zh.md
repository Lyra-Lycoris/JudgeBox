# 出现次数超过一半的数

给定 $n$ 个整数 $a_1, a_2, \dots, a_n$。数据保证存在一个数，它在这 $n$ 个数中出现的次数**严格大于** $\lfloor n/2 \rfloor$。请找出这个数。

### 输入格式

- 第一行一个整数 $n$。
- 第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个用一个空格隔开。

### 输出格式

输出一行一个整数，表示出现次数超过一半的那个数。

### 数据范围

$1 \le n \le 200000$，$|a_i| \le 10^9$。保证答案存在且唯一。

### 样例说明

样例 1 中 $n = 7$，序列为 $2, 2, 1, 1, 1, 2, 2$：

- $2$ 出现 $4$ 次，$4 > 7/2 = 3.5$；
- $1$ 出现 $3$ 次。

所以出现次数超过一半的数是 $2$，输出 `2`。
