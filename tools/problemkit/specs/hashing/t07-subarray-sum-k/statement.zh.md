# 子数组和为 k 的个数

给定 $n$ 个整数 $a_1, a_2, \dots, a_n$ 和一个整数 $k$。请统计有多少个**连续子数组**（即形如 $a_l, a_{l+1}, \dots, a_r$，$1 \le l \le r \le n$ 的一段）的元素之和恰好等于 $k$。

注意子数组不能为空，且不同的下标区间算作不同的子数组。

### 输入格式

- 第一行两个整数 $n$ 和 $k$，用一个空格隔开。
- 第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个用一个空格隔开。

### 输出格式

输出一行一个整数，表示元素和恰好为 $k$ 的连续子数组个数。

### 数据范围

$1 \le n \le 200000$，$|a_i| \le 10^9$，$|k| \le 10^{14}$。

### 样例说明

样例 1 中 $n = 5$，$k = 3$，序列为 $1, 1, 1, 1, 1$。和为 $3$ 的连续子数组正好有三个：

- $a_1 + a_2 + a_3$；
- $a_2 + a_3 + a_4$；
- $a_3 + a_4 + a_5$。

所以输出 `3`。

注意 $a_i$ 可以是负数或 $0$，因此前缀和可能重复出现，答案可能很大，需要用 64 位整数保存。
