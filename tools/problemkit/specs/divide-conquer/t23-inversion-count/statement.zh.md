# 归并排序求逆序对

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$。若存在两个下标 $i < j$ 满足 $a_i > a_j$，则称下标对 $(i, j)$ 是一个**逆序对**。请统计序列中逆序对的总数。

例如在序列 $2, 3, 4, 5, 6, 1$ 中，$1$ 比它前面的 $2, 3, 4, 5, 6$ 都小，所以共有 $5$ 个逆序对。

### 输入格式

- 第一行一个整数 $n$；
- 第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个用一个空格隔开。

### 输出格式

一行一个整数，表示逆序对的总数。

### 数据范围

$1 \le n \le 200000$，$|a_i| \le 10^9$。

答案最大约为 $\frac{n(n-1)}{2} = 19999900000$，超过了 32 位整数的范围，请使用 64 位整数。

### 样例说明

样例 1：$n = 6$，序列为 $2, 3, 4, 5, 6, 1$。只有 $1$ 与它前面的 $5$ 个数构成逆序对，答案是 `5`。

样例 2：$n = 5$，序列为 $3, 3, 3, 3, 3$，所有元素相同，没有逆序对，答案是 `0`。

样例 3：$n = 6$，序列为 $6, 5, 4, 3, 2, 1$，严格递减，任意两个下标都构成逆序对，共 $\binom{6}{2} = 15$ 对，答案是 `15`。

### 提示

把序列从中间分成两半，递归统计左半段内部的逆序对和右半段内部的逆序对。剩下的逆序对必然是一个下标在左半段、另一个在右半段，可以在归并两个有序子段时顺便统计：每当右半段的元素被取出时，左半段中尚未取出的元素都比它大，都与它构成逆序对。总时间复杂度 $O(n \log n)$。
