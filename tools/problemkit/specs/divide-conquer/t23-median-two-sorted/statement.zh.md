# 两个有序数组的中位数

给定两个**非降序**整数数组 $a$（长度为 $n$）和 $b$（长度为 $m$）。把它们合并成一个长度为 $n + m$ 的有序数组（合并时保留重复元素，不删除任何元素），求这个数组的中位数。

中位数的定义：

- 若合并后的长度为奇数，中位数是正中间的那个数；
- 若合并后的长度为偶数，中位数是正中间两个数的平均值。

本题要求输出**中位数的两倍**，这样答案一定是整数（可能是负数）。

例如 $a = [1, 3]$、$b = [2]$，合并后为 $[1, 2, 3]$，中位数是 $2$，输出 $4$；又如 $a = [1, 2]$、$b = [3, 4]$，合并后为 $[1, 2, 3, 4]$，中位数是 $2.5$，输出 $5$。

### 输入格式

- 第一行一个整数 $n$；
- 第二行 $n$ 个整数 $a_1 \le a_2 \le \dots \le a_n$；
- 第三行一个整数 $m$；
- 第四行 $m$ 个整数 $b_1 \le b_2 \le \dots \le b_m$。

### 输出格式

一行一个整数，表示中位数的两倍。

### 数据范围

- $1 \le n, m \le 100000$
- $|a_i|, |b_i| \le 10^9$
- 两个数组都保证非降序

答案的绝对值不超过 $2 \times 10^9$，在 64 位整数范围内。

### 样例说明

样例 1：$a = [1, 3]$，$b = [2]$，合并后为 $[1, 2, 3]$，中位数为 $2$，输出 `4`。

样例 2：$a = [1, 2]$，$b = [3, 4]$，合并后为 $[1, 2, 3, 4]$，中位数为 $(2 + 3) / 2 = 2.5$，输出 `5`。

样例 3：$a = [-5]$，$b = [5]$，合并后为 $[-5, 5]$，中位数为 $0$，输出 `0`。

### 提示

设合并后长度为 $S = n + m$。中位数的两倍等于「第 $\lfloor (S-1)/2 \rfloor + 1$ 小的数」加上「第 $\lfloor S/2 \rfloor + 1$ 小的数」（下标从 0 开始数）。

于是问题化为：在两个有序数组中求第 $k$ 小的数。用分治每次从两个数组中各取前 $\lceil (k+1)/2 \rceil$ 个元素，比较两段的末尾，较小的那一段整体不可能包含第 $k$ 小，可以直接排除，$k$ 相应减小，直到 $k = 0$。每轮至少排除一半，时间复杂度 $O(\log(n+m))$。
