# 分治求最大子段和

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$，元素可以为正、为负或为零。

请找出一段**非空**的连续子段 $a_l, a_{l+1}, \dots, a_r$（$1 \le l \le r \le n$），使得这段元素之和最大，输出这个最大和。

### 输入格式

- 第一行一个整数 $n$；
- 第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个用一个空格隔开。

### 输出格式

一行一个整数，表示最大的非空连续子段和。

### 数据范围

$1 \le n \le 200000$，$-10^9 \le a_i \le 10^9$。

答案的绝对值不超过 $2 \times 10^{14}$，请使用 64 位整数。

### 样例说明

样例 1：$n = 9$，序列为 $-2, 1, -3, 4, -1, 2, 1, -5, 4$。取子段 $a_4 \sim a_7$，即 $4, -1, 2, 1$，和为 $4 - 1 + 2 + 1 = 6$，这是所有非空连续子段中最大的和，输出 `6`。

样例 2：$n = 5$，序列全为负数，最大子段只能取单个元素，即 $-1$，输出 `-1`。

样例 3：$n = 1$，唯一的子段就是整个序列，输出 `-1000000000`。

### 提示

用分治求解。把序列从中间 $mid$ 分成左右两半，最大子段只有三种可能：

1. 完全在左半段 $[1, mid]$ 内；
2. 完全在右半段 $[mid+1, n]$ 内；
3. 跨过中点，即形如 $[l, r]$ 且 $l \le mid < r$ 的子段。此时它的和等于「左半段以 $mid$ 结尾的最大后缀和」加上「右半段以 $mid+1$ 开头的最大前缀和」，两者都可以从中间向两侧扫一遍 $O(n)$ 求出。

于是 $T(n) = 2T(n/2) + O(n)$，总复杂度 $O(n \log n)$。本题也允许 $O(n)$ 的动态规划做法。
