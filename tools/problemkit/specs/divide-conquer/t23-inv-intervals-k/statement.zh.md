# 逆序对不少于 k 的区间数

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$ 和一个非负整数 $k$。

对于一个连续子区间 $[l, r]$（$1 \le l \le r \le n$），定义它的**逆序对数**为满足下面条件的下标对 $(i, j)$ 的个数：

$$l \le i < j \le r \quad\text{且}\quad a_i > a_j.$$

请统计有多少个连续子区间，其逆序对数**不少于** $k$。

### 输入格式

- 第一行两个整数 $n$ 和 $k$；
- 第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个用一个空格隔开。

### 输出格式

一行一个整数，表示满足条件的连续子区间个数。

### 数据范围

- $1 \le n \le 100000$
- $0 \le k \le 10^{10}$
- $|a_i| \le 10^9$

区间总数不超过 $\frac{n(n+1)}{2} = 5000050000$，答案在 64 位整数范围内。

### 样例说明

样例 1：$n = 3$，$k = 1$，序列为 $2, 1, 3$。各子区间的逆序对数为：$[2]$、$[1]$、$[3]$、$[1,3]$ 都是 $0$；$[2,1]$ 是 $1$；$[2,1,3]$ 是 $1$。不少于 $1$ 的有 $2$ 个，输出 `2`。

样例 2：$n = 3$，$k = 0$，序列为 $5, 5, 5$。任何区间的逆序对数都为 $0 \ge 0$，全部 $\frac{3 \times 4}{2} = 6$ 个区间都满足，输出 `6`。

样例 3：$n = 3$，$k = 2$，序列为 $3, 2, 1$。各子区间的逆序对数依次为 $0, 0, 0, 1, 1, 3$，只有一个区间（整个序列）不少于 $2$，输出 `1`。

### 提示

固定左端点 $l$ 时，逆序对数随右端点 $r$ 增大而单调不减；固定 $r$ 时，随 $l$ 增大而单调不增。因此「使 $[l, r]$ 的逆序对数不少于 $k$ 的最小 $r$」随着 $l$ 增大也单调不减，可以用双指针维护一个滑动窗口。

窗口内逆序对数的动态维护需要支持「加入一个元素」和「删除一个元素」：

- 加入 $x$ 时，新增的逆序对数是窗口中严格大于 $x$ 的元素个数；
- 删除 $x$ 时，减少的逆序对数是窗口中严格小于 $x$ 的元素个数。

用树状数组（或平衡树）维护窗口内元素的出现次数，单次操作 $O(\log n)$。指针总共只移动 $O(n)$ 次，总复杂度 $O(n \log n)$。
