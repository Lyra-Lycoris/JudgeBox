# 记忆化搜索求斐波那契

斐波那契数列定义为

$$F(0) = 0,\quad F(1) = 1,\quad F(n) = F(n-1) + F(n-2)\ (n \ge 2).$$

给定整数 $n$，求 $F(n) \bmod (10^9 + 7)$。

### 输入格式

一行一个整数 $n$。

### 输出格式

一行一个整数，表示 $F(n) \bmod (10^9 + 7)$。

### 数据范围

$0 \le n \le 10^{18}$。

### 样例说明

样例 1：$n = 10$，$F(10) = 55$，输出 `55`。

样例 2：$n = 0$，$F(0) = 0$，输出 `0`。

样例 3：$n = 1$，$F(1) = 1$，输出 `1`。

### 提示

直接按定义递归会重复计算大量相同的子问题，复杂度是指数级的；加入记忆化（把已经算过的 $F(k)$ 存起来）后每个子问题只算一次，复杂度降为 $O(n)$。但本题 $n$ 高达 $10^{18}$，$O(n)$ 仍然无法通过。

利用下面两个恒等式可以把规模折半：

$$F(2k) = F(k)\bigl(2F(k+1) - F(k)\bigr),$$
$$F(2k+1) = F(k)^2 + F(k+1)^2.$$

于是递归地求出 $(F(k), F(k+1))$（其中 $k = \lfloor n/2 \rfloor$），再合并出 $(F(n), F(n+1))$，递归深度只有 $O(\log n)$。由于只需要模 $10^9 + 7$ 的结果，所有乘法都要在取模意义下进行，注意 $2F(k+1) - F(k)$ 可能为负数，取模前要先加模数。
