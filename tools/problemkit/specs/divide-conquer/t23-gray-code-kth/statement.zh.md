# 格雷码的第 k 项

$n$ 位格雷码是一个由 $2^n$ 个 $n$ 位二进制数（允许前导零）组成的序列，满足：任意两个相邻的项恰好有一位二进制不同，并且首项与末项也恰好有一位不同。

格雷码可以按如下方式**递归构造**：

- $n = 1$ 时，序列为 $[0, 1]$；
- $n > 1$ 时，设 $n-1$ 位格雷码序列为 $G$，先写下 $G$ 的每一项并在最高位补 $0$，再写下 $G$ 的**逆序**并在最高位补 $1$，拼接起来就是 $n$ 位格雷码。

例如 $n = 3$ 时的序列（十进制）为：

$$0,\ 1,\ 3,\ 2,\ 6,\ 7,\ 5,\ 4.$$

给定 $n$ 和 $k$（$0 \le k < 2^n$），请求出这个序列中下标为 $k$（从 $0$ 开始）的那一项的十进制值。

### 输入格式

一行两个整数 $n$ 和 $k$，用一个空格隔开。

### 输出格式

一行一个整数，表示第 $k$ 项格雷码的十进制值。

### 数据范围

- $1 \le n \le 60$
- $0 \le k \le 2^n - 1$，即 $k$ 一定是一个合法的下标

答案最大为 $2^{60} - 1 = 1152921504606846975$，在 64 位有符号整数范围内。

### 样例说明

样例 1：$n = 3$，序列为 $0, 1, 3, 2, 6, 7, 5, 4$，下标 $5$ 的项是 $7$，输出 `7`。

样例 2：$n = 1$，序列为 $0, 1$，下标 $1$ 的项是 $1$，输出 `1`。

样例 3：$n = 2$，序列为 $0, 1, 3, 2$，下标 $2$ 的项是 $3$，输出 `3`。

### 提示

按递归定义求解：设当前位数为 $h$，$half = 2^{h-1}$。若 $k < half$，则第 $k$ 项落在前半段（最高位为 $0$），等于 $h-1$ 位格雷码的第 $k$ 项；否则它落在后半段（最高位为 $1$），后半段是前半段的逆序，对应 $h-1$ 位格雷码的下标 $2 \cdot half - 1 - k$，答案为 $half$ 加上这个子问题的答案。递归深度 $O(n)$。

另一个等价且更快的结论是（$k$ 用二进制表示）：

$$G(k) = k \oplus (k \gg 1).$$
