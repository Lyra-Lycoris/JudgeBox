# 汉诺塔的最少移动步数

有三根柱子，编号为 A、B、C。初始时 A 柱上套着 $n$ 个圆盘，从下到上圆盘的半径严格递减（最下面的最大）。

一次移动可以把某根柱子最上面的一个圆盘移到另一根柱子上，但任何时刻都不能把较大的圆盘放在较小的圆盘上面。请求出：把全部 $n$ 个圆盘从 A 柱移动到 C 柱，最少需要多少次移动。

### 输入格式

一行一个整数 $n$。

### 输出格式

一行一个整数，表示最少移动次数。

### 数据范围

$1 \le n \le 60$。

答案最大为 $2^{60} - 1 = 1152921504606846975$，在 64 位有符号整数范围内，但超过了 32 位整数范围。

### 样例说明

样例 1：$n = 1$，直接把圆盘从 A 移到 C，需要 $1$ 次，输出 `1`。

样例 2：$n = 3$，最少需要 $7$ 次：先把上面 2 个圆盘移到 B 柱（3 次），把最大的圆盘移到 C 柱（1 次），再把 B 柱上的 2 个圆盘移到 C 柱（3 次），共 $3 + 1 + 3 = 7$ 次，输出 `7`。

样例 3：$n = 60$，答案为 $2^{60} - 1 = 1152921504606846975$。

### 提示

设 $T(n)$ 为把 $n$ 个圆盘整体移动一次所需的最少步数。移动最大的圆盘之前，必须先把上面 $n-1$ 个圆盘移到辅助柱上（$T(n-1)$ 步）；然后移动最大圆盘（$1$ 步）；最后把那 $n-1$ 个圆盘移到目标柱上（$T(n-1)$ 步）。因此

$$T(n) = 2T(n-1) + 1,\qquad T(1) = 1,$$

解得 $T(n) = 2^n - 1$。
