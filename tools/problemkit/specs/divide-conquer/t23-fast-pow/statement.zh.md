# 递归快速幂

给定三个整数 $a, b, m$，计算 $a^b \bmod m$ 的值。约定 $0^0 = 1$（即 $a = b = 0$ 时答案为 $1 \bmod m$）。

### 输入格式

一行三个整数 $a, b, m$，相邻两个用一个空格隔开。

### 输出格式

一行一个整数，表示 $a^b \bmod m$。

### 数据范围

- $0 \le a \le 10^9$
- $0 \le b \le 10^{18}$
- $1 \le m \le 2 \times 10^9$

### 样例说明

样例 1：$a = 2$，$b = 10$，$m = 1000$。$2^{10} = 1024$，$1024 \bmod 1000 = 24$，输出 `24`。

样例 2：$a = 0$，$b = 0$，$m = 7$。按约定 $0^0 = 1$，$1 \bmod 7 = 1$，输出 `1`。

样例 3：$a = 123456789$，$b = 10^{18}$，$m = 10^9 + 7$，输出 `228100152`。

### 提示

把指数折半：当 $b$ 为偶数时 $a^b = (a^{b/2})^2$，当 $b$ 为奇数时 $a^b = (a^{b/2})^2 \cdot a$。递归深度只有 $O(\log b)$，每一步都对 $m$ 取模，可以避免溢出。时间复杂度 $O(\log b)$。

注意 $a$ 与 $m$ 不一定互质，不能使用费马小定理或扩展欧拉定理，直接折半递推即可。
