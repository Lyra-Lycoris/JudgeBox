# 最长上升子序列

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$。

请你求出它的**最长严格上升子序列**的长度。

子序列是指从原序列中删去若干（可以为零个）元素后，剩下元素按原顺序构成的序列。严格上升是指子序列中后一个元素严格大于前一个元素。

### 输入格式

- 第一行一个整数 $n$；
- 第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个用一个空格隔开。

### 输出格式

一行一个整数，表示最长严格上升子序列的长度。

### 数据范围

$1 \le n \le 200000$，$-10^9 \le a_i \le 10^9$。

朴素 $O(n^2)$ 的动态规划无法在时限内通过本题，需要使用 $O(n \log n)$ 的做法。

### 样例说明

样例 1：$n = 8$，序列为 $10, 9, 2, 5, 3, 7, 101, 18$。

可以取子序列 $2, 3, 7, 101$（对应下标 $3, 5, 6, 7$），长度为 $4$；也可以取 $2, 5, 7, 101$。不存在长度为 $5$ 的严格上升子序列，因此输出 `4`。

### 提示

设 $tails[k]$ 表示「长度为 $k+1$ 的上升子序列中，结尾元素的最小可能值」。这个数组是单调不降的，因此对每个 $a_i$ 可以二分出第一个 $\ge a_i$ 的位置并替换它；若所有元素都小于 $a_i$，就在末尾追加。最终 $tails$ 的长度就是答案，时间复杂度 $O(n \log n)$。
