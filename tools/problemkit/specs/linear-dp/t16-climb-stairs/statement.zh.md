# 爬楼梯方案数

一段楼梯共有 $n$ 级台阶。你从第 $0$ 级（地面）出发，每次可以向上走 $1$ 级或 $2$ 级台阶，最终必须恰好走到第 $n$ 级。

请你计算一共有多少种不同的走法。两种走法只要在任意一步所走的级数不同，就被认为是不同的走法。

由于答案可能很大，只需要输出方案数对 $10^9+7$ 取模后的结果。

### 输入格式

一行一个整数 $n$。

### 输出格式

一行一个整数，表示走法总数对 $10^9+7$ 取模后的结果。

### 数据范围

$1 \le n \le 500000$。

### 样例说明

样例 1：$n = 5$。所有合法的走法共 $8$ 种，分别是：

- $1+1+1+1+1$
- $1+1+1+2$
- $1+1+2+1$
- $1+2+1+1$
- $2+1+1+1$
- $1+2+2$
- $2+1+2$
- $2+2+1$

因此输出 `8`。

### 提示

设 $f_i$ 表示走到第 $i$ 级的方案数，则 $f_0 = 1$，$f_1 = 1$，且对 $i \ge 2$ 有
$f_i = f_{i-1} + f_{i-2}$。答案就是 $f_n \bmod (10^9+7)$。
