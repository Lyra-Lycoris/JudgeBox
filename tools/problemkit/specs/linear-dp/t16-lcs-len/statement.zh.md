# 最长公共子序列

给定两个只包含小写英文字母的字符串 $s$ 和 $t$。

请你求出它们**最长公共子序列**的长度。

子序列是指从字符串中删去若干（可以为零个）字符后，剩余字符按原顺序构成的序列。公共子序列是指同时是 $s$ 和 $t$ 的子序列的字符串。

### 输入格式

- 第一行一个非空字符串 $s$；
- 第二行一个非空字符串 $t$。

字符串中不含空格，只包含小写英文字母。

### 输出格式

一行一个整数，表示最长公共子序列的长度。

### 数据范围

$1 \le |s|, |t| \le 2000$。

### 样例说明

样例 1：$s = \texttt{abcde}$，$t = \texttt{ace}$。

$\texttt{ace}$ 同时是 $s$ 和 $t$ 的子序列，长度为 $3$；由于 $t$ 只有 $3$ 个字符，不可能更长，因此输出 `3`。

### 提示

设 $f_{i,j}$ 表示 $s$ 的前 $i$ 个字符与 $t$ 的前 $j$ 个字符的最长公共子序列长度，则

$$f_{i,j} = \begin{cases} f_{i-1,j-1} + 1, & s_i = t_j \\ \max(f_{i-1,j},\ f_{i,j-1}), & s_i \ne t_j \end{cases}$$

边界为 $f_{0,j} = f_{i,0} = 0$，答案为 $f_{|s|,|t|}$。用滚动数组可以把空间降到 $O(|t|)$。
