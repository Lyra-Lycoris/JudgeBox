# 最大子段和

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$，其中元素可以为正、为负或为零。

请在其中找出一段**非空**的连续子段 $a_l, a_{l+1}, \dots, a_r$（$1 \le l \le r \le n$），使得这段元素之和最大，输出这个最大和。

### 输入格式

- 第一行一个整数 $n$；
- 第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个用一个空格隔开。

### 输出格式

一行一个整数，表示最大的非空连续子段和。

### 数据范围

$1 \le n \le 200000$，$-10^9 \le a_i \le 10^9$。

保证答案的绝对值不超过 $2 \times 10^{14}$，可以用 64 位整数存放。

### 样例说明

样例 1：$n = 9$，序列为 $-2, 1, -3, 4, -1, 2, 1, -5, 4$。

取子段 $a_4 \sim a_7$，即 $4, -1, 2, 1$，其和为 $4 - 1 + 2 + 1 = 6$，这是所有非空连续子段中最大的和，因此输出 `6`。

### 提示

设 $f_i$ 表示以位置 $i$ 结尾的最大子段和，则 $f_1 = a_1$，
$f_i = \max(a_i, f_{i-1} + a_i)$，答案即所有 $f_i$ 的最大值。时间复杂度 $O(n)$。
