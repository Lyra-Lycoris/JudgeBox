# 编辑距离

给定两个只包含小写英文字母的字符串 $s$ 和 $t$。

你可以对字符串 $s$ 进行任意多次以下三种操作，每次操作算作一步：

- 插入：在任意位置插入一个字符；
- 删除：删除任意一个字符；
- 替换：把任意一个字符替换成另一个字符。

请你求出把 $s$ 变成 $t$ 所需的最少操作步数，即两个字符串之间的**编辑距离**。

### 输入格式

- 第一行一个非空字符串 $s$；
- 第二行一个非空字符串 $t$。

字符串中不含空格，只包含小写英文字母。

### 输出格式

一行一个整数，表示把 $s$ 变成 $t$ 的最少操作步数。

### 数据范围

$1 \le |s|, |t| \le 2000$。

### 样例说明

样例 1：$s = \texttt{kitten}$，$t = \texttt{sitting}$。

一种最优方案共 $3$ 步：

1. `kitten` $\to$ `sitten`：把 `k` 替换成 `s`；
2. `sitten` $\to$ `sittin`：把 `e` 替换成 `i`；
3. `sittin` $\to$ `sitting`：在末尾插入 `g`。

因此输出 `3`。

### 提示

设 $f_{i,j}$ 表示把 $s$ 的前 $i$ 个字符变成 $t$ 的前 $j$ 个字符所需的最少步数，则

$$f_{i,j} = \begin{cases} f_{i-1,j-1}, & s_i = t_j \\ 1 + \min(f_{i-1,j},\ f_{i,j-1},\ f_{i-1,j-1}), & s_i \ne t_j \end{cases}$$

其中 $f_{i-1,j}+1$ 对应删除 $s_i$，$f_{i,j-1}+1$ 对应在 $s$ 中插入 $t_j$，$f_{i-1,j-1}+1$ 对应替换。

边界为 $f_{0,j} = j$、$f_{i,0} = i$，答案为 $f_{|s|,|t|}$。用滚动数组即可把空间降到 $O(|t|)$。
