# 股票买卖最大收益（一次交易）

给你一个长度为 $n$ 的数组 $a$，其中 $a_i$ 表示某支股票在第 $i$ 天的价格。

你最多只能进行**一次**交易：选择某一天 $l$ 买入一股，再选择之后的某一天 $r$（$l \le r$）卖出这一股。你也可以选择不进行任何交易。

请计算这笔交易能获得的最大收益（卖出价减去买入价）。如果无论如何都无法获利，则收益为 $0$。

### 输入格式

- 第一行一个整数 $n$；
- 第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个用一个空格隔开。

### 输出格式

一行一个整数，表示最大收益。若不交易，输出 `0`。

### 数据范围

$1 \le n \le 200000$，$0 \le a_i \le 10^9$。

保证答案可以用 64 位整数存放。

### 样例说明

样例 1：$n = 6$，价格依次为 $7, 1, 5, 3, 6, 4$。

- 第 $2$ 天以 $1$ 买入，第 $5$ 天以 $6$ 卖出，收益 $6 - 1 = 5$；
- 这是所有「先买后卖」组合中的最大收益，因此输出 `5`。

### 提示

从左到右扫描，维护「目前为止的最低价格」$mn$。对每一天 $i$，用它作为卖出日可以得到收益 $a_i - mn$，更新答案后再用 $a_i$ 更新 $mn$。时间复杂度 $O(n)$，空间复杂度 $O(1)$。
