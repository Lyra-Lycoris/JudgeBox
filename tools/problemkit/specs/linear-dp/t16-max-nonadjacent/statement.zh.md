# 不相邻元素最大和

一条街上有 $n$ 座房屋排成一排，第 $i$ 座房屋内有 $a_i$ 元现金，其中 $a_i$ 为非负整数。

你希望取走尽可能多的钱，但有一条限制：**不能同时取走相邻两座房屋**中的钱（否则会触发警报）。

请计算在满足限制的前提下，最多能取走多少钱。允许一座房屋都不取，此时答案为 $0$。

### 输入格式

- 第一行一个整数 $n$；
- 第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个用一个空格隔开。

### 输出格式

一行一个整数，表示能取走的最大金额。

### 数据范围

$1 \le n \le 200000$，$0 \le a_i \le 10^9$。

保证答案不超过 $10^{14}$，可以用 64 位整数存放。

### 样例说明

样例 1：$n = 5$，金额为 $2, 7, 9, 3, 1$。

如果取第 $1, 3, 5$ 座房屋，得到 $2 + 9 + 1 = 12$；如果取第 $2, 4$ 座房屋，得到 $7 + 3 = 10$。最大值为 $12$，因此输出 `12`。

### 提示

按位置从左到右做线性 DP。设

- $f_i$：考虑前 $i$ 座房屋、且**不取**第 $i$ 座房屋时的最大金额；
- $g_i$：考虑前 $i$ 座房屋、且**取**第 $i$ 座房屋时的最大金额。

则 $g_i = f_{i-1} + a_i$，$f_i = \max(f_{i-1}, g_{i-1})$，答案为 $\max(f_n, g_n)$。只需保留相邻两项，空间复杂度 $O(1)$。
