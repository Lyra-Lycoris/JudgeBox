# 乘积最大子数组

给定一个长度为 $n$ 的整数数组 $a$，其中每个元素 $a_i$ 只能取 $-2, -1, 0, 1, 2$ 之一。

请找出一个**非空**连续子数组 $a_l, a_{l+1}, \dots, a_r$（$1 \le l \le r \le n$），使得这段元素的乘积最大，输出这个最大乘积。

注意乘积可能为负数，例如数组中只有一个 $-2$ 时答案就是 $-2$。

### 输入格式

- 第一行一个整数 $n$；
- 第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个用一个空格隔开。

### 输出格式

一行一个整数，表示最大的连续子数组乘积。

### 数据范围

$1 \le n \le 200000$，$a_i \in \{-2, -1, 0, 1, 2\}$。

数据保证**任意连续子数组的乘积绝对值都不超过 $10^{18}$**，因此答案可以用 64 位整数存放。

### 样例说明

样例 1：$n = 5$，数组为 $2, -2, -1, 0, 1$。

- 子数组 $a_1 \sim a_3$ 的乘积为 $2 \times (-2) \times (-1) = 4$；
- 其余子数组的乘积分别为 $2, -4, -2, -1, 0, 0, 0, 1$ 等，均不超过 $4$。

因此最大乘积为 $4$，输出 `4`。

### 提示

只维护「以当前位置结尾的最大乘积」是不够的，因为乘以一个负数会让最大值变成最小值。因此同时维护：

- $mx_i$：以 $i$ 结尾的子数组乘积最大值；
- $mn_i$：以 $i$ 结尾的子数组乘积最小值。

则 $mx_i = \max(a_i,\ mx_{i-1} \cdot a_i,\ mn_{i-1} \cdot a_i)$，$mn_i = \min(a_i,\ mx_{i-1} \cdot a_i,\ mn_{i-1} \cdot a_i)$，答案为所有 $mx_i$ 的最大值。时间复杂度 $O(n)$。
