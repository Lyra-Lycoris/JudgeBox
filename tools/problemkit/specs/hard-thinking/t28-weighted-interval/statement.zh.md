# 加权区间调度

给定 $n$ 个闭区间，第 $i$ 个区间是 $[l_i, r_i]$，权重为 $w_i$。

请从中选出若干个区间，要求选出的区间**两两互不重叠**，并使总权重（被选中区间的 $w_i$ 之和）最大。

两个闭区间 $[l, r]$ 与 $[l', r']$ 互不重叠，当且仅当 $r < l'$ 或 $r' < l$。也就是说，只要两个区间**共用端点**（例如 $[1, 2]$ 与 $[2, 3]$）也算重叠，不能同时选。

### 输入格式

- 第一行一个整数 $n$；
- 接下来 $n$ 行，每行三个整数 $l_i, r_i, w_i$，表示第 $i$ 个区间的左右端点与权重。

### 输出格式

输出一行一个整数，表示能选出的互不重叠区间的最大总权重。

### 数据范围

- $1 \le n \le 2 \times 10^5$；
- $1 \le l_i \le r_i \le 10^{9}$；
- $1 \le w_i \le 10^{9}$。

最大总权重不超过 $2 \times 10^{14}$，可以用 $64$ 位有符号整数保存。

### 样例说明

样例 1 有 $4$ 个区间：$[1,3]$ 权 $5$，$[2,5]$ 权 $6$，$[4,6]$ 权 $5$，$[6,7]$ 权 $4$。

- 选 $[1,3]$ 与 $[4,6]$：因为 $3 < 4$，互不重叠，总权重 $5 + 5 = 10$；
- 选 $[2,5]$ 与 $[6,7]$：$5 < 6$，总权重 $6 + 4 = 10$；
- 选更多区间不可能（任意三个两两都会重叠），而单个区间权重最大只有 $6$。

所以最大总权重为 $10$，输出 `10`。

### 提示

把所有区间按**右端点从小到大**排序，相同的右端点再按左端点排序，得到顺序 $[l_1, r_1], \dots, [l_n, r_n]$（右端点非降）。

令 $dp[i]$ 表示只考虑前 $i$ 个区间时的最大总权重，$dp[0] = 0$。对第 $i$ 个区间（$1 \le i \le n$）：

- 不选它：$dp[i] = dp[i-1]$；
- 选它：此时能接在它前面的区间必须满足右端点 $< l_i$，于是在右端点数组上二分出最后一个 $< l_i$ 的位置 $k$，收益为 $dp[k] + w_i$。

即 $dp[i] = \max(dp[i-1], dp[k] + w_i)$，答案为 $dp[n]$，复杂度 $O(n \log n)$。

注意「互不重叠」用的是严格小于：右端点等于 $l_i$ 的区间与第 $i$ 个区间共用端点，不能同时选，因此二分要找的是**第一个 $\ge l_i$** 的右端点。
