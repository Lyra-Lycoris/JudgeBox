# 相邻交换排序

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$。

一次操作可以交换**相邻**的两个元素 $a_i$ 与 $a_{i+1}$，代价为 $1$。

请求出使序列变成**非降序**（即 $a_1 \le a_2 \le \dots \le a_n$）所需要的**最少**操作次数。

序列中允许出现相同的元素。

### 输入格式

- 第一行一个整数 $n$；
- 第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，用空格分隔。

### 输出格式

一行一个整数，表示最少操作次数。

### 数据范围

- $1 \le n \le 2 \times 10^5$；
- $-10^9 \le a_i \le 10^9$。

最少次数不超过 $\dfrac{n(n-1)}{2} \le 2 \times 10^{10}$，请使用 64 位整数。

### 样例说明

样例 1：$n = 5$，$a = (2, 4, 1, 3, 3)$，四步即可排好序：

1. 交换 $4$ 与 $1$：$(2, 1, 4, 3, 3)$；
2. 交换 $2$ 与 $1$：$(1, 2, 4, 3, 3)$；
3. 交换 $4$ 与第一个 $3$：$(1, 2, 3, 4, 3)$；
4. 交换 $4$ 与第二个 $3$：$(1, 2, 3, 3, 4)$。

可以证明少于 $4$ 步不可能完成，所以输出 `4`。

### 提示

- 对一个**排列** $p$，通过相邻交换把它变成 $1, 2, \dots, n$ 的最少次数等于 $p$ 的逆序对数。因此先把「目标排列」确定下来，再数逆序对即可。
- 相等元素的相对顺序不需要改变：交换两个相等的元素对序列没有任何影响，所以可以认为排好序后相等元素仍按原来的先后顺序排列。于是把每个元素写成 $(a_i, i)$ 并排序，得到的目标排列是唯一确定的。
- 逆序对可以用树状数组（或归并排序）在 $O(n \log n)$ 时间内统计：从左到右依次插入目标排列的元素，每次查询已经插入的元素中比当前元素大的个数。
