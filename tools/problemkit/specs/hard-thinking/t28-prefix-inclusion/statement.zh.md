# 容斥计数：至少一个条件的数

给定一个正整数 $n$ 和 $m$ 个条件。每个条件都是下面两种之一：

- **整除条件** `1 k`：整数 $x$ 是 $k$ 的倍数。输入保证 $k$ 是 $2$ 的幂，即 $k = 2^{p}$（$0 \le p \le 20$），所以这个条件等价于「$x$ 的低 $p$ 位全为 $0$」；
- **数位条件** `2 b`：整数 $x$ 的二进制表示中第 $b$ 位是 $1$（$0 \le b \le 59$，最低位是第 $0$ 位）。

请统计区间 $[1, n]$ 中**至少满足一个条件**的整数 $x$ 的个数。

### 输入格式

- 第一行两个整数 $n, m$；
- 接下来 $m$ 行，每行两个整数 $t, x$，描述一个条件：
  - $t = 1$ 时，$x$ 给出的是 $k$，条件为「$x$ 是 $k$ 的倍数」，此时 $x$ 一定是 $2$ 的幂；
  - $t = 2$ 时，$x$ 给出的是 $b$，条件为「$x$ 的二进制第 $b$ 位为 $1$」。

### 输出格式

输出一行一个整数，表示 $[1, n]$ 中至少满足一个条件的整数个数。

### 数据范围

- $1 \le n \le 10^{18}$；
- $1 \le m \le 8$；
- $t \in \{1, 2\}$；
- $t = 1$ 时 $k = x$ 是 $2$ 的幂，即 $k = 2^{p}$，$0 \le p \le 20$，所以 $1 \le k \le 2^{20}$；
- $t = 2$ 时 $0 \le b = x \le 59$。

答案不超过 $n \le 10^{18}$，可以用 $64$ 位有符号整数保存。用容斥计算时，请按子集大小分组求和（每组之和约为 $C(m,k) \cdot n / 2^{k}$），这样中间结果也不会超过 $64$ 位。

### 样例说明

样例 1：$n = 10$，两个条件分别是「是 $2$ 的倍数」和「第 $1$ 位为 $1$」。

- $2$ 的倍数：$2, 4, 6, 8, 10$；
- 第 $1$ 位为 $1$ 的数：$2, 3, 6, 7, 10$。

并集为 $\{2, 3, 4, 6, 7, 8, 10\}$，共 $7$ 个，所以输出 `7`。

### 提示

容斥原理：

$$\text{答案} = \sum_{\varnothing \ne T \subseteq \{1,\dots,m\}} (-1)^{|T|+1} \cdot c(T),$$

其中 $c(T)$ 是 $[1, n]$ 中同时满足 $T$ 中所有条件的整数个数。

注意到两类条件都只是对二进制位做限制：整除条件 $k = 2^{p}$ 要求低 $p$ 位为 $0$（因此 `zero_mask |= k - 1`），数位条件要求第 $b$ 位为 $1$（`one_mask |= 1 << b`）。所以子集 $T$ 的约束可以合并成两个掩码 `zero_mask`、`one_mask`：

- 若两个掩码有交，则 $c(T) = 0$；
- 否则 $c(T)$ 就是「满足若干位固定为 $0$／$1$、其余位任意」的 $[0, n]$ 内整数个数，可以按位从高到低统计：若 $n$ 的当前位是 $1$ 而这一位未被强制为 $1$，则把这一位放 $0$，其余未被限制的低位任意，贡献 $2^{\text{自由位数}}$；然后继续沿「与 $n$ 前缀相同」的分支走下去。最后扣掉 $x = 0$（当且仅当 `one_mask` 为 $0$ 时 $0$ 会被算进去）。

$m \le 8$，枚举 $2^{m} - 1 \le 255$ 个非空子集，每个子集 $O(60)$ 统计即可。
