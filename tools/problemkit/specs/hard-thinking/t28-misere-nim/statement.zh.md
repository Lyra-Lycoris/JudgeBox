# 反尼姆游戏

有 $n$ 堆石子，第 $i$ 堆有 $a_i$ 颗石子。

两名玩家轮流操作，**先手**先动。每次操作时，当前玩家必须选择一堆**非空**的石子，从中取走**任意正整数颗**（可以把这一堆取光）。

本题的胜负规则与普通 Nim 游戏相反：

> **取走最后一颗石子的人输。**

也就是说，谁进行了「使所有石子堆都变空」的那次操作，谁就输。由于石子总数有限，游戏一定会在有限步内结束，不会平局。

给定初始局面，请判断**先手是否必胜**。

### 输入格式

- 第一行一个整数 $n$，表示石子堆数；
- 第二行 $n$ 个正整数 $a_1, a_2, \dots, a_n$，表示每堆的石子数，用空格分隔。

### 输出格式

- 若先手必胜，输出一行 `YES`；
- 否则输出一行 `NO`。

### 数据范围

- $1 \le n \le 2 \times 10^5$；
- $1 \le a_i \le 10^9$。

### 样例说明

样例 1：$n = 2$，两堆各 $1$ 颗石子。

先手取走第一堆（或第二堆）中唯一的石子，此时只剩一堆、$1$ 颗石子。轮到后手时他无别的选择，只能取走这最后一颗石子，于是后手输，先手胜。

因此输出 `YES`。

### 提示

设 $x = a_1 \oplus a_2 \oplus \dots \oplus a_n$（按位异或）。

- 如果所有堆都只有 $1$ 颗石子，那么游戏恰好进行 $n$ 步，最后一步由第 $n$ 个行动的人完成，因此**先手胜当且仅当 $n$ 是偶数**；
- 否则（至少有一堆超过 $1$ 颗），**先手胜当且仅当 $x \ne 0$**，这与普通 Nim 的判定完全相同。

所以要特判「全是 $1$」的情况，其余情况只需计算异或和。
