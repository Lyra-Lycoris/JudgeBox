# 给无向图定向

给定一张 $n$ 个点、$m$ 条边的无向简单图（无自环、无重边）。你可以为每条边指定一个方向，把它变成一条有向边。

请给出一种定向方案，使得**每个点的入度都不超过 $1$**；如果不存在这样的方案，请报告无解。

入度不超过 $1$ 意味着：定向后的图由若干条有向链和若干个有向环组成，每个点至多有一条入边（入度为 $0$ 的点是有向链的起点）。

### 输入格式

- 第一行两个整数 $n, m$；
- 接下来 $m$ 行，每行两个整数 $u_i, v_i$，表示第 $i$ 条无向边。

### 输出格式

- 如果存在合法方案：输出 $2m$ 个用空格分隔的整数。按输入顺序，对第 $i$ 条边输出两个整数 $a_i, b_i$，表示这条边被定向为 $a_i \to b_i$。这里 $(a_i, b_i)$ 必须等于 $(u_i, v_i)$ 或 $(v_i, u_i)$。
- 如果不存在合法方案：只输出一个整数 `-1`。

本题使用**特殊评判**（SPJ），任何满足条件的方案都会被接受。

### 数据范围

- $1 \le n \le 2 \times 10^5$；
- $0 \le m \le 2 \times 10^5$；
- $1 \le u_i \ne v_i \le n$，保证图中没有自环，也没有重边。

### 样例说明

样例 1：$n = 4$，$m = 4$，边依次是 $1-2$、$2-3$、$3-1$、$3-4$。

输出 `2 1 3 2 1 3 3 4` 表示把四条边分别定向为 $2 \to 1$、$3 \to 2$、$1 \to 3$、$3 \to 4$。

四个点的入度分别是：点 $1$ 来自 $2$、点 $2$ 来自 $3$、点 $3$ 来自 $1$、点 $4$ 来自 $3$，全部为 $1$，都不超过 $1$，所以这个方案合法。（只要输出任意一种合法方案即可，例如 `1 2 2 3 3 1 3 4` 同样正确。）

### 提示

对每个连通块，设点数为 $V$、边数为 $E$。定向后所有点的入度之和恰好等于 $E$，而每个点的入度不超过 $1$，所以必须 $E \le V$。另一方面，连通块至少要有 $V-1$ 条边才能连通。因此每个连通块只能是**树**（$E = V-1$）或**基环树**（$E = V$）；只要某个连通块满足 $E > V$，就无解。

构造方法：对每个连通块做一次迭代式 DFS，得到一棵生成树。

- 树边一律从父亲指向儿子。这样根入度为 $0$，其余每个点恰有 $1$ 条入边。
- 基环树里恰好有一条非树边（返祖边）。把这条返祖边从**深的端点指向浅的端点**，于是它与环上的树边一起构成一个有向环，环上每个点的入度恰为 $1$。
- 注意环「顶部」的那个点如果不在 DFS 根上，那么从环顶到根这一小段「柄」上的树边必须**反向**（儿子指向父亲）：否则环顶既收到柄上的入边，又收到返祖边的入边，入度就变成 $2$ 了。
