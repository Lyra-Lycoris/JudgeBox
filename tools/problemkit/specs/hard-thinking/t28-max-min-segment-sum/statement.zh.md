# 最大化的最小段和

给定 $n$ 个正整数 $a_1, a_2, \dots, a_n$ 和一个整数 $k$（$1 \le k \le n$）。

你需要把整个序列切成**恰好 $k$ 段连续的非空子段**：存在下标

$$0 = p_0 < p_1 < p_2 < \dots < p_k = n,$$

第 $i$ 段就是 $a_{p_{i-1}+1}, \dots, a_{p_i}$，每段的和记为

$$s_i = \sum_{j=p_{i-1}+1}^{p_i} a_j .$$

设 $M = \min(s_1, s_2, \dots, s_k)$ 是这些段和中的最小值。请选择一种切分方式，使 $M$ **尽可能大**，输出这个最大的 $M$。

### 输入格式

- 第一行两个整数 $n$ 和 $k$；
- 第二行 $n$ 个正整数 $a_1, a_2, \dots, a_n$，用空格分隔。

### 输出格式

一行一个整数，表示最大的 $M$。

### 数据范围

- $1 \le n \le 2 \times 10^5$；
- $1 \le k \le n$；
- $1 \le a_i \le 10^9$，因此 $\sum a_i \le 2 \times 10^{14}$，答案同样不超过 $2 \times 10^{14}$。

### 样例说明

样例 1：$n = 5$，$k = 3$，$a = (1, 2, 3, 4, 5)$。

若切成 $(1,2,3)\mid(4)\mid(5)$，三段和分别是 $6, 4, 5$，最小值是 $4$。

若想使最小值达到 $5$：由于 $4 < 5$，元素 $4$ 必须和别的元素合并。合并后最多只能切出两段，与 $k = 3$ 矛盾。所以最大值是 $4$，输出 `4`。

### 提示

答案具有单调性：若存在一种方案使每段和都 $\ge x$，那么对更小的 $x$ 也同样成立，因此可以对答案二分。

判定给定的 $x$ 是否可行时，从左往右贪心：只要当前累计和 $\ge x$ 就立刻切一段。设这样最多能切出 $c$ 段（末尾不足 $x$ 的残余不计）。则 $x$ 可行**当且仅当** $c \ge k$：若 $c \ge k$，把第 $k$ 段及其后的所有元素合并成最后一段，它的和只会更大；反之若某种方案有 $k$ 段且每段 $\ge x$，贪心得到的段数不会更少。
