# 子树大小统计

给定一棵以节点 $1$ 为根、共 $n$ 个节点的有根树，节点编号 $1 \sim n$。树的形态用父亲数组给出：对于每个 $i \ge 2$，节点 $i$ 的父亲是 $p_i$，并保证 $1 \le p_i < i$。

节点 $v$ 的**子树**由 $v$ 本身以及所有以 $v$ 为祖先的节点组成，即从 $v$ 出发向下能到达的全部节点。子树大小就是子树内节点的个数。

请对每个 $1 \le v \le n$ 求出节点 $v$ 的子树大小。

### 输入

第一行一个整数 $n$。

第二行 $n-1$ 个整数 $p_2, p_3, \dots, p_n$，依次表示节点 $2, 3, \dots, n$ 的父亲。当 $n = 1$ 时这一行为空（可以省略）。

输入保证 $1 \le p_i < i$，因此一定构成一棵以 $1$ 为根的有根树。

### 输出

一行 $n$ 个整数，用空格分隔，第 $v$ 个数表示节点 $v$ 的子树大小。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $1 \le p_i < i$（对 $2 \le i \le n$）

### 样例说明

$n = 5$，父亲为 $p_2 = 1,\ p_3 = 1,\ p_4 = 2,\ p_5 = 2$。

于是 $1$ 的孩子是 $2, 3$，$2$ 的孩子是 $4, 5$。各节点子树内的节点为：

- 节点 $1$：$\{1,2,3,4,5\}$，大小 $5$；
- 节点 $2$：$\{2,4,5\}$，大小 $3$；
- 节点 $3$：$\{3\}$，大小 $1$；
- 节点 $4$：$\{4\}$，大小 $1$；
- 节点 $5$：$\{5\}$，大小 $1$。

所以输出 `5 3 1 1 1`。
