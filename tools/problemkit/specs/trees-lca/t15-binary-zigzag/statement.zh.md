# 二叉树之字形层序遍历

给定一棵有 $n$ 个节点的二叉树，节点编号 $1 \sim n$，根为节点 $r$。每个节点的左、右孩子用两个整数表示，$0$ 表示该孩子不存在。

请按**之字形**（zigzag）顺序输出所有节点：

- 第 $0$ 层（根）从左到右输出；
- 第 $1$ 层从右到左输出；
- 第 $2$ 层从左到右输出；
- 第 $3$ 层从右到左输出；
- 以此类推，层号每增加一层就翻转一次方向。

### 输入

第一行两个整数 $n, r$。

接下来 $n$ 行，第 $i$ 行（$1 \le i \le n$）两个整数 $l_i, r_i$，表示节点 $i$ 的左孩子与右孩子编号；$0$ 表示没有该孩子。

输入保证这些节点确实构成一棵以 $r$ 为根的二叉树（每个节点最多一个父亲，且从 $r$ 能到达所有节点，没有环）。

### 输出

一行 $n$ 个整数，用空格分隔，表示之字形层序遍历的节点编号序列。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $1 \le r \le n$
- $0 \le l_i, r_i \le n$
- 树的深度可能达到 $n$（是一条链），请注意不要使用递归

### 样例说明

样例中 $n = 7$，根为 $1$：$1$ 的孩子是 $2, 3$；$2$ 的孩子是 $4, 5$；$3$ 的孩子是 $6, 7$。

- 第 $0$ 层：$1$；
- 第 $1$ 层从左到右是 $2, 3$，翻转后输出 $3, 2$；
- 第 $2$ 层从左到右是 $4, 5, 6, 7$，本层不翻转，输出 $4, 5, 6, 7$。

所以输出 `1 3 2 4 5 6 7`。
