# 两两节点距离之和

给定一棵有 $n$ 个节点的无向树，节点编号 $1 \sim n$，每条边的长度都是 $1$。

树上的距离 $\mathrm{dist}(u, v)$ 定义为连接 $u, v$ 的唯一简单路径上经过的边数。请计算所有**无序点对**的距离之和：

$$\sum_{1 \le u < v \le n} \mathrm{dist}(u, v).$$

### 输入

第一行一个整数 $n$。

接下来 $n-1$ 行，每行两个整数 $u_i, v_i$，表示一条树边。当 $n = 1$ 时没有这些行。

输入保证这些边构成一棵树。

### 输出

一行一个整数，表示所有无序点对的距离之和。当 $n = 1$ 时答案为 $0$。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $1 \le u_i, v_i \le n$
- 边权均为 $1$

### 样例说明

样例是一条链 $1 - 2 - 3$。三个无序点对及其距离为：

- $\mathrm{dist}(1,2) = 1$
- $\mathrm{dist}(2,3) = 1$
- $\mathrm{dist}(1,3) = 2$

总和为 $1 + 1 + 2 = 4$。
