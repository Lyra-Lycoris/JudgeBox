# 树的直径

给定一棵有 $n$ 个节点的无向树，节点编号为 $1 \sim n$，每条边的长度都是 $1$。

树上两点之间的距离定义为连接它们的唯一简单路径上经过的边数。树的**直径**是所有点对之间距离的最大值，也就是距离最远的两点之间的距离。请计算这棵树的直径。

### 输入

第一行一个整数 $n$。

接下来 $n-1$ 行，每行两个整数 $u_i, v_i$，表示一条连接节点 $u_i$ 与 $v_i$ 的边。当 $n = 1$ 时没有这些行。

输入的图保证是一棵以 $1 \sim n$ 为节点的树。

### 输出

一行一个整数，表示树的直径（经过的边数）。当 $n = 1$ 时答案为 $0$。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $1 \le u_i, v_i \le n$
- 边权均为 $1$，所有节点连通且无环

### 样例说明

样例给出的树有 $6$ 个节点，边为 $(1,2), (2,3), (3,4), (2,5), (5,6)$。

距离最远的两点是 $4$ 与 $6$，路径为 $4 \to 3 \to 2 \to 5 \to 6$，经过 $4$ 条边。其他点对的距离都不超过 $4$，所以直径为 $4$。
