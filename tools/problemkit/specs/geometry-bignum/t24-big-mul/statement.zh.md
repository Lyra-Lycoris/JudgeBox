# 高精度乘法

给定两个非负整数 $a$ 和 $b$（以十进制字符串的形式给出，每个至多 $5000$ 位），请计算它们的乘积 $a\times b$。

结果的位数可能达到 $10^4$ 位，远超 64 位整数的范围，因此必须自己实现高精度乘法（竖式乘法）。

### 输入格式

- 第一行一个十进制字符串 $a$；
- 第二行一个十进制字符串 $b$。

两个字符串都由数字 `0`–`9` 组成，不含前导零（除非这个数本身就是 `0`，此时字符串就是单个字符 `0`）。

### 输出格式

一行一个十进制字符串，表示 $a\times b$ 的十进制表示，不含前导零（若乘积为 $0$，输出单个 `0`）。

### 数据范围

$1 \le |a|, |b| \le 5000$，其中 $|a|$、$|b|$ 分别是两个字符串的长度。

竖式乘法的运算量为 $|a|\cdot|b| \le 2.5\times 10^7$ 次乘加，在 2000 ms 的时限内用 64 位整数累加即可通过。

### 样例说明

样例中 $a = 123456789$，$b = 987654321$，逐位竖式相乘得到
$$123456789 \times 987654321 = 121932631112635269,$$
因此输出 `121932631112635269`。

### 提示

把两个数都倒序存成数字数组（下标 $0$ 是个位），设 $a$ 的第 $i$ 位为 $A_i$、$b$ 的第 $j$ 位为 $B_j$，则乘积的第 $i+j$ 位需要累加 $A_i \cdot B_j$。先把所有乘积累加到数组里（每个位置最大约为 $5000 \times 81$，用 64 位整数不会溢出），再从低位到高位统一处理进位：

$$c_{k+1} \mathrel{+}= \left\lfloor \frac{c_k}{10} \right\rfloor, \qquad c_k \leftarrow c_k \bmod 10.$$

最后去掉高位的多余零，反转输出。总复杂度 $O(|a|\cdot|b|)$。

注意特判乘数为 `0` 的情况，否则输出会出现前导零。
