# 凸包顶点数

给定平面上 $n$ 个整点，请计算它们**凸包的顶点个数**。

凸包是能包含所有给定点的最小凸多边形。约定：

- 如果所有点都相同，凸包退化成一个点，顶点数为 $1$；
- 如果所有点都在同一条直线上（但不止一个点），凸包退化成一个线段，顶点数为 $2$；
- 否则，凸包是一个凸多边形，**落在凸包某条边内部的点不算顶点**（即只统计“拐角”上的点）。

### 输入格式

- 第一行一个整数 $n$，表示点的个数。
- 第二行 $n$ 个整数 $x_1, x_2, \dots, x_n$，依次是各点的横坐标。
- 第三行 $n$ 个整数 $y_1, y_2, \dots, y_n$，依次是各点的纵坐标。

第 $i$ 个点是 $(x_i, y_i)$。也就是说，输入把 $x$ 坐标和 $y$ 坐标**分开**给出。点可能有重复。

### 输出格式

一行一个整数，表示凸包的顶点个数。

### 数据范围

$1 \le n \le 200000$，$-10^9 \le x_i, y_i \le 10^9$。

坐标差的绝对值不超过 $2 \times 10^9$，叉积（两个乘积再相减）的绝对值不超过 $8 \times 10^{18}$，可以放进 64 位有符号整数。

### 样例说明

样例共有 $6$ 个点：$(0,0),(4,0),(4,4),(0,4),(2,2),(1,1)$。

其中 $(0,0),(4,0),(4,4),(0,4)$ 是一个正方形的四个角，$(2,2)$ 与 $(1,1)$ 都落在正方形的内部，不会成为凸包顶点。因此凸包就是这四条边围成的正方形，顶点数为 $4$。

### 提示

用 Andrew 单调链算法：

1. 把所有点按 $(x,y)$ 字典序排序并去重；
2. 从左到右扫描，用一个栈维护“下凸壳”：当栈顶的两个点与新点构成的方向不是严格左转（叉积 $\le 0$）时弹出栈顶；
3. 从右到左再做一遍，得到“上凸壳”；
4. 两段点数之和减去 $2$（首尾两点被数了两遍）就是凸包顶点数。

排序与扫描都是 $O(n \log n)$。注意叉积要用 $\le 0$ 判断，这样落在边上的共线点会被丢掉，与题目要求一致。
