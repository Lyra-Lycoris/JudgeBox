# 线段相交判定

平面上给出两条线段 $AB$ 与 $CD$，其中 $A(x_A,y_A)$、$B(x_B,y_B)$、$C(x_C,y_C)$、$D(x_D,y_D)$ 都是整点。请判断这两条线段**是否有公共点**。

这里把线段看成闭线段：两个端点都属于线段。因此下面几种情况都算相交：

- 两条线段在内部真正交叉；
- 一条线段的端点落在另一条线段上（包括落在端点上）；
- 两条线段共线且有重叠部分（包括只重叠一个端点）；
- 某条线段退化成一个点，且这个点在另一条线段上。

### 输入格式

- 第一行一个整数 $T$，表示询问组数。
- 接下来 $T$ 行，每行八个整数 $x_A, y_A, x_B, y_B, x_C, y_C, x_D, y_D$，表示一组询问。

### 输出格式

输出 $T$ 行，每行对应一组询问：两条线段有公共点输出 `YES`，否则输出 `NO`。

### 数据范围

$1 \le T \le 100000$，$-10^9 \le x_A, y_A, x_B, y_B, x_C, y_C, x_D, y_D \le 10^9$。

坐标差的绝对值不超过 $2 \times 10^9$，每个叉积的绝对值不超过 $8 \times 10^{18}$，可以放进 64 位有符号整数。

### 样例说明

样例共 6 组询问：

1. $(0,0)-(4,4)$ 与 $(0,4)-(4,0)$：在 $(2,2)$ 处真正交叉，输出 `YES`；
2. $(0,0)-(4,0)$ 与 $(4,0)-(4,4)$：共享端点 $(4,0)$，输出 `YES`；
3. $(0,0)-(4,0)$ 与 $(0,1)-(4,1)$：平行且不重合，输出 `NO`；
4. $(0,0)-(4,0)$ 与 $(1,0)-(3,0)$：共线且有重叠，输出 `YES`；
5. $(0,0)-(1,0)$ 与 $(2,0)-(3,0)$：共线但分离，输出 `NO`；
6. 退化成点 $(2,2)$ 的线段与 $(0,0)-(4,4)$：该点在线段上，输出 `YES`。

### 提示

记
$$\text{cross}(P,Q,R) = (x_Q-x_P)(y_R-y_P) - (y_Q-y_P)(x_R-x_P),$$
它表示向量 $\overrightarrow{PQ}$ 与 $\overrightarrow{PR}$ 的叉积。令
$$d_1=\text{cross}(A,B,C),\quad d_2=\text{cross}(A,B,D),\quad d_3=\text{cross}(C,D,A),\quad d_4=\text{cross}(C,D,B).$$

- 若 $d_1$ 与 $d_2$ 异号，且 $d_3$ 与 $d_4$ 异号，则两线段真正交叉，答案为 `YES`；
- 否则若某个 $d_i = 0$（相应点与相应线段共线），且该点确实落在该线段的包围盒内（横纵坐标都在两端点之间），答案为 `YES`；
- 否则答案为 `NO`。

单组询问 $O(1)$，总复杂度 $O(T)$。
