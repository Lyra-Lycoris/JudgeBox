# 高精度加法

给定两个非负整数 $a$ 和 $b$（以十进制字符串的形式给出，长度可能达到 $10^5$ 位），请计算它们的和 $a+b$。

由于结果可能远远超出 64 位整数的范围（$10^5$ 位的数大约有 $3\times10^5$ 个二进制位），你必须自己实现高精度加法：按十进制位从低位向高位逐位相加并处理进位。

### 输入格式

- 第一行一个十进制字符串 $a$；
- 第二行一个十进制字符串 $b$。

两个字符串都由数字 `0`–`9` 组成，不含前导零（除非这个数本身就是 `0`，此时字符串就是单个字符 `0`）。

### 输出格式

一行一个十进制字符串，表示 $a+b$ 的十进制表示。

输出中不允许有前导零（若 $a+b=0$，输出单个 `0`）。

### 数据范围

$1 \le |a|, |b| \le 100000$，其中 $|a|$、$|b|$ 分别是两个字符串的长度。

时间限制 2000 ms，加法本身是线性的，$O(|a|+|b|)$ 的逐位加法可以轻松通过。

### 样例说明

样例中 $a = 12345678901234567890$，$b = 98765432109876543210$。逐位相加（从最低位开始）得到
$$12345678901234567890 + 98765432109876543210 = 111111111011111111100,$$
因此输出 `111111111011111111100`。

注意最高位产生了进位，结果的位数比两个加数都多一位。

### 提示

设两个数的十进制表示分别为 $a = \overline{a_{n-1}\dots a_1 a_0}$、$b = \overline{b_{m-1}\dots b_1 b_0}$（下标从 $0$ 开始，$a_0$、$b_0$ 是个位）。从 $k = 0$ 开始依次计算
$$s_k = a_k + b_k + c_k, \quad d_k = s_k \bmod 10, \quad c_{k+1} = \lfloor s_k / 10 \rfloor,$$
其中缺失的位按 $0$ 处理，$c_0 = 0$。当两个数都取完且进位为 $0$ 时结束，把所有 $d_k$ 反序输出就是答案。

整条链路只用到 $0$–$9$ 的数字和 $0/1$ 的进位，不要试图转换成 64 位整数。
