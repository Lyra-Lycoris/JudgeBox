# 多边形面积的二倍

给定一个简单多边形（边与边互不相交）的 $n$ 个顶点，顶点按顺时针或逆时针顺序给出。请计算多边形面积的**两倍**并输出。

把多边形面积记作 $S$，请输出整数 $2S$。由于顶点都是整点，由鞋带公式可知 $2S$ 一定是整数（例如三角形面积为 $2.5$ 时 $2S = 5$），所以答案不会出现小数。

### 输入格式

- 第一行一个整数 $n$，表示顶点个数。
- 第二行 $n$ 个整数 $x_1, x_2, \dots, x_n$，依次是各顶点的横坐标。
- 第三行 $n$ 个整数 $y_1, y_2, \dots, y_n$，依次是各顶点的纵坐标。

第 $i$ 个顶点是 $(x_i, y_i)$。也就是说，输入把 $x$ 坐标和 $y$ 坐标**分开**给出，相邻两个数之间用一个空格隔开。

### 输出格式

一行一个整数，表示多边形面积的二倍，即 $2S$。答案是负数是不允许的（面积本身非负），请输出绝对值。

### 数据范围

$3 \le n \le 200000$，$-10^6 \le x_i, y_i \le 10^6$。

每个叉积项 $x_i y_{i+1} - x_{i+1} y_i$ 的绝对值不超过 $2 \times 10^{12}$，求和后不超过 $4 \times 10^{17}$，64 位有符号整数足够。

### 样例说明

样例为一个三角形，三个顶点依次是 $(0,0)$、$(4,0)$、$(0,3)$。它是一个直角边长为 $4$ 和 $3$ 的直角三角形，面积为
$$S = \frac{1}{2}\cdot 4 \cdot 3 = 6,$$
所以输出 $2S = 12$。

用鞋带公式验证：
$$\sum_{i=1}^{n}\left(x_i y_{i+1} - x_{i+1} y_i\right) = (0\cdot 0 - 4\cdot 0) + (4 \cdot 3 - 0\cdot 0) + (0\cdot 0 - 0\cdot 3) = 12.$$

### 提示

鞋带公式（Shoelace formula）：
$$2S = \left| \sum_{i=1}^{n} \left( x_i y_{i+1} - x_{i+1} y_i \right) \right|, \quad (x_{n+1}, y_{n+1}) = (x_1, y_1).$$

顶点按顺时或逆时针给出都可以，取绝对值即可；多边形允许是凹的，也允许面积为 $0$（例如所有顶点重合或全部共线）。时间复杂度 $O(n)$。
