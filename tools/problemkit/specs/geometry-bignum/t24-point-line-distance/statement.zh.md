# 点到直线距离的整数比较

平面上的直线由两个不同的整点 $A(x_1,y_1)$、$B(x_2,y_2)$ 给出。再给出一个整点 $P(p_x,p_y)$ 和一个整数 $d$，请判断**点 $P$ 到直线 $AB$ 的距离是否不超过 $d$**。

点 $P$ 到直线 $AB$ 的距离定义为：从 $P$ 向直线 $AB$ 作垂线，垂足到 $P$ 的距离。用公式写出来是
$$\text{dist}(P, AB) = \frac{\left| (x_2-x_1)(p_y-y_1) - (y_2-y_1)(p_x-x_1) \right|}{\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}}.$$

### 输入格式

- 第一行一个整数 $T$，表示询问组数。
- 接下来 $T$ 行，每行七个整数 $x_1, y_1, x_2, y_2, p_x, p_y, d$，表示一组询问。

保证每组询问中 $(x_1,y_1) \ne (x_2,y_2)$，即直线由两个不同的点确定。

### 输出格式

输出 $T$ 行，每行对应一组询问：如果距离不超过 $d$ 输出 `YES`，否则输出 `NO`。距离恰好等于 $d$ 时输出 `YES`。

### 数据范围

$1 \le T \le 100000$。

$-10^4 \le x_1, y_1, x_2, y_2, p_x, p_y \le 10^4$，$0 \le d \le 10^4$。

在这些限制下，叉积绝对值不超过 $8 \times 10^8$，其平方不超过 $6.4 \times 10^{17}$；而 $d^2 \cdot |AB|^2 \le 10^8 \times 8 \times 10^8 = 8 \times 10^{16}$。全部运算都可以用 64 位有符号整数完成，**不需要**开平方，也不会溢出。

### 样例说明

样例共 4 组询问：

1. 直线 $y=0$（过 $(0,0)$ 与 $(10,0)$），点 $(3,4)$ 到它的距离是 $4$，$4 \le 4$，输出 `YES`；
2. 同样的直线和点，$d=3$，距离 $4 > 3$，输出 `NO`；
3. 点 $(5,0)$ 就在直线上，距离为 $0$，$d=0$，输出 `YES`；
4. 直线过 $(0,0)$ 与 $(3,4)$，点 $(3,0)$ 到它的距离是 $\frac{|3\cdot 0 - 4 \cdot 3|}{5} = \frac{12}{5} = 2.4$，$2.4 > 2$，输出 `NO`。

### 提示

把「距离不超过 $d$」两边平方，得到等价的整数条件
$$\text{cross}^2 \le d^2 \cdot \left((x_2-x_1)^2+(y_2-y_1)^2\right),$$
其中 $\text{cross} = (x_2-x_1)(p_y-y_1) - (y_2-y_1)(p_x-x_1)$。这样比较完全在整数范围内进行，避免了浮点误差（例如样例第 4 组的 $2.4$ 与 $2$）。
