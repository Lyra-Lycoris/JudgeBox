# 阶乘的位数

给定 $T$ 个正整数 $n$，对每个 $n$ 求出 $n! = 1\times 2\times \cdots \times n$ 的十进制表示有多少位。

例如 $5! = 120$ 有 $3$ 位，$10! = 3628800$ 有 $7$ 位。

### 输入格式

- 第一行一个整数 $T$，表示询问组数。
- 接下来 $T$ 行，每行一个整数 $n$。

### 输出格式

输出 $T$ 行，每行一个整数，表示对应 $n!$ 的十进制位数。

### 数据范围

$1 \le T \le 100000$，$1 \le n \le 10^9$。

注意 $n$ 最大可达 $10^9$，此时 $n!$ 有八十多亿位，不可能把阶乘本身算出来；也不可能对每个 $n$ 都做 $O(n)$ 的对数累加（$10^9$ 次运算在时限内无法完成）。请使用常数时间的公式。

### 样例说明

样例有 $5$ 组询问：

- $1! = 1$，有 $1$ 位；
- $2! = 2$，有 $1$ 位；
- $5! = 120$，有 $3$ 位；
- $10! = 3628800$，有 $7$ 位；
- $20! = 2432902008176640000$，有 $19$ 位。

所以输出依次为 `1`、`1`、`3`、`7`、`19`。

### 提示

一个正整数 $m$ 的十进制位数为 $\lfloor \log_{10} m \rfloor + 1$，因此
$$d(n) = \left\lfloor \log_{10}(n!) \right\rfloor + 1, \qquad \log_{10}(n!) = \sum_{i=1}^{n} \log_{10} i .$$
直接求和是 $O(n)$ 的。借助 Stirling 公式
$$\ln(n!) = n\ln n - n + \frac{1}{2}\ln(2\pi n) + \frac{1}{12n} - O\!\left(\frac{1}{n^{3}}\right),$$
换成以 $10$ 为底：
$$\log_{10}(n!) \approx n\log_{10} n - n\log_{10} e + \frac{1}{2}\log_{10}(2\pi n) + \frac{1}{12n\ln 10},$$
于是每组询问 $O(1)$。$n$ 较小时（例如 $n \le 20$）直接用整数阶乘数位数更稳妥。

浮点运算的误差远小于 $10^{-6}$，本题数据保证答案不会落在浮点误差可能翻转的位置。
