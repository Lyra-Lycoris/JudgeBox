# 最长无重复字符子串

给定一个只含英文字母和数字的字符串 $s$，请找出其中不含重复字符的**最长连续子串**，输出该子串的长度。

子串指原字符串中连续的一段，两个子串只要起止位置不同就算不同，但这里只关心长度的最大值。

### 输入格式

一行一个非空字符串 $s$，只由大小写英文字母和数字组成。

### 输出格式

一行一个整数，表示最长无重复字符子串的长度。

### 数据范围

- $1 \le |s| \le 200000$，其中 $|s|$ 表示字符串长度。
- $s$ 中只包含 `a`–`z`、`A`–`Z`、`0`–`9`。

### 样例说明

样例 1：`abcabcbb`。最长的无重复字符子串是 `abc`，长度为 $3$。

样例 2：`bbbbb`。任意长度大于 $1$ 的子串都含有重复字符，答案是 $1$。

样例 3：`pwwkew`。最长的是 `wke`（也可以是 `kew`），长度为 $3$；`pwke` 只是子序列而不是子串，不算。
