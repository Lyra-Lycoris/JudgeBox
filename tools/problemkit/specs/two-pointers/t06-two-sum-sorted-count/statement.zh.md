# 有序数组两数之和的方案数

给定一个长度为 $n$ 的**非降序**整数数组 $a$ 和一个整数 $\mathit{target}$，请统计有多少对下标 $(i, j)$ 满足 $i < j$ 且 $a_i + a_j = \mathit{target}$。

数组中的元素可能重复，不同下标的对算作不同的方案：例如 $a = [2, 2, 2]$、$\mathit{target} = 4$ 时，三对下标 $(0,1)$、$(0,2)$、$(1,2)$ 都满足要求，答案是 $3$。

### 输入格式

第一行两个整数 $n$ 和 $\mathit{target}$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，保证 $a_1 \le a_2 \le \dots \le a_n$。

### 输出格式

一行一个整数，表示满足条件的下标对数。

### 数据范围

- $1 \le n \le 200000$
- $|a_i| \le 10^9$，且数组非降序
- $|\mathit{target}| \le 2 \times 10^9$
- 答案可能很大（最大约为 $2 \times 10^{10}$），请注意使用 64 位整数

### 样例说明

样例 1：$n = 5$，$\mathit{target} = 5$，数组为 $1, 2, 3, 4, 5$。满足条件的只有 $1 + 4 = 5$ 和 $2 + 3 = 5$ 两对，答案是 $2$。

样例 2：$n = 3$，$\mathit{target} = 4$，数组为 $2, 2, 2$。任意两个元素之和都是 $4$，共 $\binom{3}{2} = 3$ 对。

样例 3：$n = 1$，凑不出两个下标，答案是 $0$。
