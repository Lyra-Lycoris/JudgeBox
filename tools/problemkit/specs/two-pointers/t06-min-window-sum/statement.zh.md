# 和至少为 S 的最短子数组

给定 $n$ 个**正整数** $a_1, a_2, \dots, a_n$ 和一个整数 $S$，请找出一个连续子数组，使它的元素之和不少于 $S$，并且长度尽可能小。输出这个最小的长度；如果不存在这样的子数组，输出 `0`。

### 输入格式

第一行两个整数 $n$ 和 $S$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个整数之间用一个空格隔开。

### 输出格式

一行一个整数，表示满足「元素之和不少于 $S$」的连续子数组的最小长度；不存在时输出 `0`。

### 数据范围

- $1 \le n \le 200000$
- $1 \le a_i \le 10^9$
- $1 \le S \le 10^{14}$

### 样例说明

样例 1：$n = 6$，$S = 7$，数组为 $2, 3, 1, 2, 4, 3$。子数组 $[4, 3]$ 的和为 $7$，长度为 $2$；不存在长度为 $1$ 且和不少于 $7$ 的子数组，所以答案是 $2$。

样例 2：$n = 1$，$S = 6$，唯一的元素是 $5$，和不足 $6$，所以答案是 `0`。

样例 3：整个数组的和只有 $5$，远小于 $S = 100$，所以答案是 `0`。
