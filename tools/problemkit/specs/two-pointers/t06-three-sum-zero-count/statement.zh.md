# 三数之和为零的组合数

给定一个长度为 $n$ 的整数数组 $a$（**未排序**），请统计有多少个三元组下标 $(i, j, k)$ 满足 $i < j < k$ 且 $a_i + a_j + a_k = 0$。

数组中的元素可能重复，只要下标不同就视为不同的方案。

### 输入格式

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个整数之间用一个空格隔开。

### 输出格式

一行一个整数，表示满足条件的三元组个数。

### 数据范围

- $1 \le n \le 2000$
- $|a_i| \le 10^9$
- 答案最大约为 $\binom{2000}{3} \approx 1.33 \times 10^9$，请使用 64 位整数

### 样例说明

样例 1：$a = [-1, 0, 1, 2, -1, -4]$。满足条件的三元组有 $(-1, 0, 1)$（两种取法，因为 $-1$ 出现了两次）和 $(-1, -1, 2)$，共 $3$ 个。

样例 2：五个 $0$ 中任取三个之和都是 $0$，共 $\binom{5}{3} = 10$ 个三元组。

样例 3：$[1, 2, 3, 4]$ 中任意三个数之和都为正，答案是 $0$。
