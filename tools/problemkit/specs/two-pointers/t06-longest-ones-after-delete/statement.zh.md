# 删除一个元素后的最长连续 1

给定一个只含 $0$ 和 $1$ 的数组 $a$，你必须**恰好删除一个元素**，删除后数组长度变为 $n - 1$。请输出删除后数组中最长的连续 $1$ 段的长度。

注意：

- 必须删除且只能删除一个元素，不可以不删；
- 删除的元素可以是 $1$ 也可以是 $0$；
- 如果删除后数组为空（即 $n = 1$），最长连续 $1$ 的长度记为 $0$。

### 输入格式

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，每个都是 $0$ 或 $1$，相邻两个整数之间用一个空格隔开。

### 输出格式

一行一个整数，表示删除一个元素后最长连续 $1$ 段的长度。

### 数据范围

- $1 \le n \le 200000$
- $a_i \in \{0, 1\}$

### 样例说明

样例 1：$a = [1, 1, 0, 1]$。删除那个 $0$ 后数组变成 $[1, 1, 1]$，最长连续 $1$ 段长度为 $3$。

样例 2：$a = [1, 0, 1, 0, 1]$。无论删除哪个元素，都无法把两段 $1$ 连成一段超过 $2$ 的连续段，最优为删除中间某个 $0$ 后得到 $[1, 1, 0, 1]$，答案是 $2$。

样例 3：$a = [0, 0, 1, 1, 1, 0, 0]$。删除最左边或最右边的 $0$，中间那段 $111$ 保持完整，答案是 $3$。
