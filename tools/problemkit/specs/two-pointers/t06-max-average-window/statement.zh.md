# 固定长度窗口的最大平均值

给定长度为 $n$ 的整数数组 $a$ 和一个整数 $k$（$1 \le k \le n$），请找出所有长度**恰好为 $k$** 的连续子数组中，平均值最大的那个，并输出该平均值。

由于平均值可能不是有限小数，并且为了完全避免浮点数误差，请把答案写成**最简分数** $p/q$ 的形式：

- $q > 0$；
- $\gcd(|p|, q) = 1$；
- 输出格式为 `p/q`，中间没有空格，例如 `7/2`、`-5/2`、`22/1`。

### 输入格式

第一行两个整数 $n$ 和 $k$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个整数之间用一个空格隔开。

### 输出格式

一行一个字符串 `p/q`，表示所有长度为 $k$ 的连续子数组中的最大平均值（既约分数，分母为正）。

### 数据范围

- $1 \le k \le n \le 200000$
- $|a_i| \le 10^9$
- 窗口和最大约为 $2 \times 10^{14}$，请使用 64 位整数

### 样例说明

样例 1：$n = 3$，$k = 2$，数组为 $1, 3, 4$。长度为 $2$ 的窗口有 $[1, 3]$（平均 $2$）和 $[3, 4]$（平均 $3.5$），最大值是 $7/2$。

样例 2：只有一个元素 $5$，平均值为 $5$，写成既约分数是 `5/1`。

样例 3：$k = n = 4$，唯一窗口是 $-1, -2, -3, -4$，和为 $-10$，平均值为 $-10/4 = -5/2$。
