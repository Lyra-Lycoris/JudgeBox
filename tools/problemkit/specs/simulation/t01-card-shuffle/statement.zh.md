# 卡片洗牌模拟

有 $n$ 张卡片，编号 $1 \sim n$，初始时第 $i$ 个位置上放着编号为 $i$ 的卡片。

给定一个 $1 \sim n$ 的排列 $p$，它定义了一次洗牌规则：洗完一次后，原来在位置 $i$ 上的卡片会移动到位置 $p_i$（所有卡片同时移动，因此洗牌后每个位置仍然恰好有一张卡片）。

现在把这个洗牌规则连续执行 $k$ 次，请输出最终从位置 $1$ 到位置 $n$ 每个位置上的卡片编号。

注意 $k$ 可能非常大，不能真的模拟 $k$ 次洗牌；但洗牌规则是一个排列，卡片的移动会形成若干循环，利用循环长度即可快速得到答案。

### 输入格式

- 第一行两个整数 $n, k$，用一个空格隔开；
- 第二行 $n$ 个整数 $p_1, p_2, \dots, p_n$，相邻两个用一个空格隔开。

### 输出格式

一行 $n$ 个整数，依次表示最终位置 $1$ 到位置 $n$ 上的卡片编号，相邻两个用一个空格隔开。

### 数据范围

$1 \le n \le 200000$，$0 \le k \le 10^{18}$，$p$ 是 $1 \sim n$ 的一个排列。

### 样例说明

样例 1：$n = 4$，$k = 1$，$p = (2, 3, 4, 1)$。洗完一次后：位置 $1$ 的卡片 $1$ 移到位置 $2$，卡片 $2$ 移到位置 $3$，卡片 $3$ 移到位置 $4$，卡片 $4$ 移到位置 $1$，所以最终序列是 `4 1 2 3`。
