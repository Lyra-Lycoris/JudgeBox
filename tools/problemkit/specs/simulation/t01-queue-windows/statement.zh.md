# 多窗口排队模拟

银行有 $k$ 个服务窗口，第 $i$ 位顾客在时刻 $a_i$ 到达，办理业务需要 $s_i$ 个时间单位。

顾客按到达顺序依次办理业务（保证 $a_i$ 非降）。每位顾客会选择「最早空闲」的窗口：哪个窗口最先空出来就去哪个；如果同时有多个窗口空闲，选择编号最小的窗口（这不影响答案）。如果到达时所有窗口都在忙，就等待到有窗口空闲为止。

一位顾客的等待时间 = 他开始办理的时刻 − 他的到达时刻。请求出所有顾客等待时间之和。

### 输入格式

- 第一行两个整数 $n, k$，用一个空格隔开；
- 第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个用一个空格隔开；
- 第三行 $n$ 个整数 $s_1, s_2, \dots, s_n$，相邻两个用一个空格隔开。

### 输出格式

一行一个整数，表示所有顾客等待时间之和。

### 数据范围

$1 \le n \le 200000$，$1 \le k \le 200000$，$0 \le a_i \le 10^9$ 且 $a_1 \le a_2 \le \dots \le a_n$，$0 \le s_i \le 10^9$。

保证所有顾客的等待时间之和不超过 $10^{18}$，即可以用 64 位整数存下。

### 样例说明

样例 1：$n = 3$，$k = 1$，到达时刻为 $0, 2, 5$，服务时长为 $4, 4, 4$。

- 第 $1$ 位顾客 $0$ 时刻直接开始，等待 $0$；
- 第 $2$ 位顾客 $2$ 时刻到达，窗口要 $4$ 时刻才空，等待 $2$，$8$ 时刻离开；
- 第 $3$ 位顾客 $5$ 时刻到达，等到 $8$ 时刻开始，等待 $3$。

答案为 $0 + 2 + 3 = 5$。

样例 2：窗口数 $5$ 多于顾客数 $3$，每个人都立刻开始，答案为 $0$。
