# 机器人指令模拟

一个机器人初始站在坐标 $(0, 0)$，面朝正北（$y$ 轴正方向）。

它按顺序执行一条指令串，每个字符的含义是：

- `L`：原地左转 $90^\circ$（不移动）；
- `R`：原地右转 $90^\circ$（不移动）；
- `F`：朝当前方向前进 $1$ 格；
- `B`：朝当前方向后退 $1$ 格（方向不变）。

求执行完所有指令后机器人所在的位置。

### 输入格式

一行一个只由 `L`、`R`、`F`、`B` 组成的字符串，长度不超过 $200000$。

### 输出格式

一行两个整数 $x$ 和 $y$，用一个空格隔开，表示机器人的最终坐标。

### 数据范围

$1 \le |s| \le 200000$，其中 $|s|$ 是指令串长度。最终坐标满足 $-200000 \le x, y \le 200000$。

### 样例说明

样例 1：`FFRFF` —— 先朝北走两格到 $(0,2)$，右转朝东，再走两格到 $(2,2)$，输出 `2 2`。

样例 2：`RRFF` —— 连续右转两次后朝南，走两格到 $(0,-2)$，输出 `0 -2`。
