# 中缀表达式求值

给定一个合法的中缀算术表达式，其中只含非负整数、二元运算符 `+`、`-`、`*`、`/` 以及左右圆括号，请计算它的值。

规则：

- 运算优先级与通常一致：`*` 和 `/` 高于 `+` 和 `-`，同级运算从左到右结合；
- 圆括号改变运算顺序；
- 除法一律向零取整，例如 `7/2 = 3`，`(0-7)/2 = -3`（注意是向零取整，不是向下取整）；
- 表达式中不会出现一元负号：`-` 只作为二元减号出现，也不会出现两个连续的运算符；
- 表达式中不含空格。

### 输入格式

一行，一个合法的中缀表达式，长度不超过 $200000$。

### 输出格式

一行一个整数，表示表达式的值。

### 数据范围

表达式长度 $1 \le L \le 200000$，每个整数字面量不超过 $10^9$；保证除法不会除以零，且计算过程中所有中间结果（包括最后的答案）的绝对值都不超过 $10^{15}$，可以用 64 位整数存下。

### 样例说明

样例 1：`(1+2)*3`，先算括号里的 $1+2=3$，再乘 $3$，得 $9$。

样例 2：`(3-10)/2`，先算 $3-10=-7$，再算 $-7/2$；向零取整得到 $-3$（向下取整会得到 $-4$，不是本题的规定）。
