# 环形密码锁

一把密码锁有 $4$ 个转盘，每个转盘上是 $0 \sim 9$ 中的数字，首尾相邻：$9$ 的下一档是 $0$，$0$ 的上一档是 $9$。

一次操作可以把任意一个转盘向上或向下拨动一档。

给定初始锁面 `start`、目标锁面 `target`，以及若干个「死亡数字」：任何时刻锁面都不能等于其中任何一个。请计算从 `start` 拨到 `target` 的最少操作次数，如果无法做到则输出 `-1`。

判断顺序如下：

1. 若 `start` 或 `target` 本身是死亡数字，直接输出 `-1`；
2. 否则若 `start` 与 `target` 相同，输出 `0`；
3. 否则按上述规则拨动，过程中锁面不能出现死亡数字。

### 输入格式

- 第一行一个长度为 $4$ 的数字串，表示 `start`；
- 第二行一个长度为 $4$ 的数字串，表示 `target`；
- 第三行一个整数 $n$，表示死亡数字的个数；
- 若 $n > 0$，第四行给出 $n$ 个长度为 $4$ 的数字串，相邻两个用一个空格隔开；若 $n = 0$，则没有第四行。

数字串允许有前导零。

### 输出格式

一行一个整数：最少操作次数，或 `-1`。

### 数据范围

$0 \le n \le 500$，每个数字串恰好 $4$ 个字符，且只含 `0` 到 `9`。

### 样例说明

样例 1：从 `0000` 出发，可以沿 `0000 -> 1000 -> 1100 -> 1200 -> 1201 -> 1202 -> 0202` 走，共 $6$ 步，且途中没有踩到任何死亡数字，所以答案是 `6`。

样例 2：`0000` 与 `9000` 只差第一个转盘一档，$0$ 向上一档就是 $9$，所以答案是 `1`。
