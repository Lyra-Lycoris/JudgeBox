# 井字棋胜负判定

在一个 $3 \times 3$ 的井字棋盘上，两人轮流落子。先手用 `X`，后手用 `O`，一共落满 $9$ 手。

棋盘格子的编号如下：

```
1 2 3
4 5 6
7 8 9
```

现在按落子顺序给出 $9$ 个格子编号（是 $1 \sim 9$ 的一个排列），第 $1, 3, 5, 7, 9$ 手由先手 `X` 落子，第 $2, 4, 6, 8$ 手由后手 `O` 落子。

请判断：游戏在第几手第一次分出胜负。三子连成一线（同一行、同一列或同一条对角线）即算获胜；如果下满 $9$ 手仍无人成线，则视为平局。分出胜负之后，输入中剩余的落子不再执行，直接忽略。

### 输入格式

一行 $9$ 个整数，按落子顺序给出格子编号，相邻两个数用一个空格隔开。

### 输出格式

一行一个整数：

- 若有人在第 $t$ 手后第一次连成三子，输出 $t$（$1 \le t \le 9$）；
- 若下满 $9$ 手仍无人连成三子，输出 `0`。

### 数据范围

输入的 $9$ 个整数是 $1 \sim 9$ 的排列，且保证任何一方的落子都不会重复占用同一个格子。

### 样例说明

样例 1：落子顺序为 `1 4 2 5 3 ...`，`X` 依次占据 1、2、3 号格子，第 5 手后第一行被 `X` 连成，输出 `5`。

样例 2：`X` 占据 1、3、4、8、9，`O` 占据 2、5、6、7，九手下满也没有任何一方连成三子，输出 `0`。
