# 区间和查询

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$。数据共有 $T$ 组，每组数据额外给出一个查询区间 $[l, r]$，请回答

$$\sum_{i=l}^{r} a_i = a_l + a_{l+1} + \dots + a_r.$$

### 输入

第一行一个整数 $T$，表示数据的组数。

接下来依次给出每组数据：

- 第一行一个整数 $n$，表示序列长度；
- 第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$；
- 第三行两个整数 $l, r$，表示查询区间。

### 输出

共 $T$ 行，每组数据输出一行一个整数，表示该组的区间和。

### 数据范围

- $1 \le T \le 5$
- 每组 $1 \le n \le 2 \times 10^5$，且同一条输入中所有组的 $n$ 之和不超过 $2 \times 10^5$
- $-10^9 \le a_i \le 10^9$
- $1 \le l \le r \le n$

### 样例说明

第一组数据序列为 $1, 2, 3$，查询区间 $[1, 3]$，区间和为 $1+2+3=6$。

第二组数据序列为 $-1, 5, -2, 4$，查询区间 $[2, 3]$，区间和为 $5 + (-2) = 3$。
