# 同余子段计数

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$ 和一个正整数 $k$，请统计有多少个**非空连续子段**的元素之和能被 $k$ 整除。

记前缀和 $P_0 = 0$，$P_i = a_1 + a_2 + \dots + a_i$。子段 $a_{l}, \dots, a_{r}$ 的和为 $P_r - P_{l-1}$，它能被 $k$ 整除当且仅当

$$P_r \equiv P_{l-1} \pmod{k}.$$

因此问题转化为：统计 $0 \le i < j \le n$ 且 $P_i \equiv P_j \pmod{k}$ 的下标对数。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

第三行一个整数 $k$。

### 输出

一行一个整数，表示和能被 $k$ 整除的非空连续子段个数。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $1 \le k \le 10^9$
- $-10^9 \le a_i \le 10^9$
- 答案不超过 $\frac{(n+1)n}{2}$，在 64 位整数范围内

### 样例说明

序列为 $4, 5, 0, 2, 3$，$k = 5$。前缀和为 $0, 4, 9, 9, 11, 14$，对 $5$ 取模为 $0, 4, 4, 4, 1, 4$。

余数 $4$ 出现 $4$ 次，贡献 $\binom{4}{2} = 6$ 对；余数 $0$、$1$ 各出现 $1$ 次，没有贡献。所以答案是 $6$。

对应的子段分别是 $[5]$、$[5,0]$、$[5,0,2,3]$、$[0]$、$[0,2,3]$、$[2,3]$，它们的和依次是 $5, 5, 10, 0, 5, 5$。
