# 长度至少为 K 的最大平均值

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$ 和一个整数 $k$，在所有长度**不小于** $k$ 的连续子段中，求最大的平均值

$$M = \max_{\substack{1 \le l \le r \le n \\ r - l + 1 \ge k}} \frac{a_l + a_{l+1} + \dots + a_r}{r - l + 1}.$$

由于 $M$ 可能不是整数，请输出它的 $1000$ 倍向下取整，即

$$\text{ans} = \left\lfloor 1000 \cdot M \right\rfloor,$$

也就是说，输出满足 $M \ge \dfrac{t}{1000}$ 的最大整数 $t$（对负数同样成立）。

### 输入

第一行两个整数 $n, k$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

### 输出

一行一个整数，表示 $\lfloor 1000 \cdot M \rfloor$。

### 数据范围

- $1 \le k \le n \le 10^5$
- $-10^9 \le a_i \le 10^9$
- 答案满足 $|\text{ans}| \le 10^{12}$

### 样例说明

序列为 $1, 12, -5, -6, 50$，$k = 2$。长度不小于 $2$ 的子段中，平均值最大的是 $[-6, 50]$，平均值为 $22$，所以 $\lfloor 1000 \cdot 22 \rfloor = 22000$。

### 提示

判定「是否存在平均值不小于 $t/1000$ 的子段」时，可以把每个数减去 $t/1000$ 后判断是否存在长度不小于 $k$ 且和为非负的子段。为避免浮点误差，可以两边同乘 $1000$，只用整数运算，并用前缀和与「下标差至少为 $k$ 的最小前缀」在 $O(n)$ 时间内完成判定。
