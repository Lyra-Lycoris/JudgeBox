# 最大子段和

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$，请找出一段**非空**连续子段 $a_l, a_{l+1}, \dots, a_r$（$1 \le l \le r \le n$），使得这段元素之和最大，输出这个最大值。

记前缀和 $P_0 = 0$，$P_i = a_1 + a_2 + \dots + a_i$，则子段和等于 $P_r - P_{l-1}$。于是问题等价于最大化 $P_r - P_{l-1}$，其中 $l-1 < r$。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

### 输出

一行一个整数，表示最大子段和。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $-10^9 \le a_i \le 10^9$
- 答案绝对值不超过 $2 \times 10^{14}$

### 样例说明

序列为 $-2, 1, -3, 4, -1, 2, 1, -5$。取子段 $4, -1, 2, 1$（第 $4$ 到第 $7$ 个元素），其和为 $6$，这也是所有非空连续子段中最大的和。
