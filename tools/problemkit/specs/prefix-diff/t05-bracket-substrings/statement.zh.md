# 合法括号子串计数

给定一个只由 `(` 和 `)` 组成的字符串 $s$，长度为 $n$。请统计 $s$ 中有多少个**连续子串**是合法的括号序列。

一个字符串是合法括号序列，当且仅当它的长度为偶数，并且从左到右扫描时：

- 任意时刻已出现的 `(` 个数都不少于 `)` 个数；
- 扫描结束时 `(` 与 `)` 个数相等。

把 `(` 记作 $+1$、`)` 记作 $-1$，设前缀和 $P_0 = 0$，$P_i = P_{i-1} + (\text{若 } s_i = \texttt{(} \text{ 则 } 1 \text{ 否则 } -1)$。那么子串 $s_{l}\dots s_{r}$ 合法当且仅当

$$P_r = P_{l-1} \quad\text{且}\quad \min_{l \le i \le r} P_i \ge P_{l-1}.$$

直接枚举两端是 $O(n^2)$ 的，需要用前缀和加单调栈在 $O(n)$ 时间内计数。

### 输入

一行一个字符串 $s$（不含空格）。

### 输出

一行一个整数，表示合法括号子串的个数。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $s$ 只包含 `(` 和 `)`
- 答案不超过 $\frac{n(n+1)}{2}$，在 64 位整数范围内

### 样例说明

$s = \texttt{()()}$。合法的连续子串有：

- 第 $1$ 到第 $2$ 个字符：`()`；
- 第 $3$ 到第 $4$ 个字符：`()`；
- 第 $1$ 到第 $4$ 个字符：`()()`。

共 $3$ 个，所以输出 $3$。

### 提示

从 $0$ 到 $n$ 依次处理前缀和 $P_j$。若某个下标 $i$ 满足 $P_i > P_j$，那么从 $i$ 出发的任何子串都不可能在 $j$（或更后面）结束，可以把 $P_i$ 从候选中删去。用一个严格递增的栈保存仍然「有用」的前缀和值，并用数组记录每个前缀和值当前的计数；处理 $P_j$ 时先弹出并清零所有大于 $P_j$ 的值，再把 $P_j$ 的计数加到答案中，最后让 $P_j$ 的计数加一。
