# 覆盖次数最多的地方

一条走廊上有 $n$ 个连续的位置，编号 $1$ 到 $n$。现在有 $q$ 次「覆盖」操作，第 $i$ 次操作给出两个整数 $l_i, r_i$，表示把 $[l_i, r_i]$ 中的每个位置都覆盖一次（区间可以重叠、可以完全相同）。

记位置 $x$ 被覆盖的次数为 $c_x$，即满足 $l_i \le x \le r_i$ 的操作个数。请找出覆盖次数最多的位置，输出：

1. 最大的覆盖次数 $M = \max_x c_x$；
2. 达到 $M$ 的所有位置中编号最小的那个位置 $p$。

### 输入

第一行一个整数 $n$。

第二行一个整数 $q$。

接下来 $q$ 行，每行两个整数 $l_i, r_i$，表示第 $i$ 次覆盖操作。

### 输出

一行两个整数 $M$ 和 $p$，用空格分隔。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $1 \le q \le 2 \times 10^5$
- $1 \le l_i \le r_i \le n$

### 样例说明

三次操作分别覆盖 $[1,4]$、$[3,5]$、$[5,6]$，各位置的覆盖次数为

$$c_1=1,\ c_2=1,\ c_3=2,\ c_4=2,\ c_5=2,\ c_6=1.$$

最大覆盖次数是 $2$，最左边的达到它的位置是 $3$，所以输出 `2 3`。
