# 区间加与还原

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$，初始时第 $i$ 个位置的值是 $a_i$。

接下来有 $q$ 次操作，第 $j$ 次操作给出三个整数 $l_j, r_j, v_j$，表示把区间 $[l_j, r_j]$ 内的每个数都加上 $v_j$：

$$a_i \leftarrow a_i + v_j \quad (l_j \le i \le r_j).$$

请按顺序执行所有操作，最后输出整个序列。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

第三行一个整数 $q$。

接下来 $q$ 行，每行三个整数 $l_j, r_j, v_j$，描述一次区间加操作。

### 输出

一行 $n$ 个整数，用空格分隔，表示全部操作执行完后的序列。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $1 \le q \le 2 \times 10^5$
- $1 \le l_j \le r_j \le n$
- $-10^9 \le a_i, v_j \le 10^9$
- 任意时刻每个位置的值都落在 $[-2 \times 10^{14}, 2 \times 10^{14}]$ 内

### 样例说明

初始序列为 $1, 2, 3, 4, 5$。

第一次操作把 $[1, 3]$ 加上 $10$，序列变为 $11, 12, 13, 4, 5$。

第二次操作把 $[2, 5]$ 加上 $-4$，序列变为 $11, 8, 9, 0, 1$。
