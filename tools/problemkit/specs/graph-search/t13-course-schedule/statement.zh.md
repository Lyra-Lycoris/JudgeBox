# 课程表

你要修完 $n$ 门课程，课程编号 $1 \sim n$。

学校给出了 $m$ 条先修约束，每条约束用两个整数 $a, b$ 表示：**必须先修完课程 $a$，才能修课程 $b$**（可以理解成有向边 $a \to b$）。

同一对约束可能被重复给出，也可能出现 $a = b$ 这种自相矛盾的要求。请判断是否存在一种修课顺序，使得所有先修约束都被满足（即：把 $n$ 门课排成一个序列，使每条约束的 $a$ 都排在 $b$ 前面）。

### 输入格式

- 第一行两个整数 $n$ 与 $m$，用一个空格隔开；
- 接下来 $m$ 行，每行两个整数 $a, b$，用一个空格隔开，表示课程 $a$ 必须在课程 $b$ 之前修完。

当 $m = 0$ 时，第一行之后没有其他内容。

### 输出格式

输出一行：如果可以修完全部课程输出 `YES`，否则输出 `NO`。

### 数据范围

- $1 \le n \le 200000$
- $0 \le m \le 200000$
- $1 \le a, b \le n$
- 时间限制 2000 ms，空间限制 256 MB

### 输入输出样例

**输入 1**

```
4 3
1 2
1 3
3 4
```

**输出 1**

```
YES
```

**输入 2**

```
3 3
1 2
2 3
3 1
```

**输出 2**

```
NO
```

### 样例说明

样例 1：约束为「$1$ 在 $2$ 前」「$1$ 在 $3$ 前」「$3$ 在 $4$ 前」，按 $1, 2, 3, 4$ 的顺序修课即可满足全部约束，因此输出 `YES`。

样例 2：三条约束要求 $1$ 在 $2$ 前、$2$ 在 $3$ 前、$3$ 在 $1$ 前，形成一个环，不可能同时满足，因此输出 `NO`。
