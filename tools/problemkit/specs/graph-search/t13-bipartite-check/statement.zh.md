# 二分图判定

给定一个 $n$ 个顶点（编号 $1 \sim n$）、$m$ 条边的**无向图**，请判断它是不是二分图。

二分图的定义：可以把所有顶点分成两个集合 $A, B$，使得每条边的两个端点恰好一个在 $A$ 中、另一个在 $B$ 中（等价于：图中不存在长度为奇数的环）。

注意图中允许自环（$u = v$）和重边。

### 输入格式

- 第一行两个整数 $n$ 与 $m$，用一个空格隔开；
- 接下来 $m$ 行，每行两个整数 $u, v$，用一个空格隔开，表示顶点 $u$ 与顶点 $v$ 之间有一条无向边。

当 $m = 0$ 时，第一行之后没有其他内容。

### 输出格式

输出一行：如果是二分图输出 `YES`，否则输出 `NO`。

### 数据范围

- $1 \le n \le 200000$
- $0 \le m \le 200000$
- $1 \le u, v \le n$
- 时间限制 2000 ms，空间限制 256 MB

### 输入输出样例

**输入 1**

```
4 4
1 2
2 3
3 4
4 1
```

**输出 1**

```
YES
```

**输入 2**

```
3 3
1 2
2 3
3 1
```

**输出 2**

```
NO
```

### 样例说明

样例 1：$1-2-3-4-1$ 是一个长度为 $4$ 的偶环，取 $A = \{1, 3\}$、$B = \{2, 4\}$ 即可，因此输出 `YES`。

样例 2：三个点两两相连，构成三角形（长度为 $3$ 的奇环），无论怎么分成两个集合，总有一条边的两个端点落在同一个集合里，因此输出 `NO`。
