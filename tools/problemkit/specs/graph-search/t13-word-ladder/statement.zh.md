# 单词接龙

给定两个单词 `begin`（开始单词）与 `end`（目标单词），以及一个单词列表（共 $n$ 个单词）。

每次变换可以**改变当前单词中的恰好一个字母**，得到一个新单词；新单词必须出现在给定的单词列表中（`begin` 不需要在列表中，`end` 必须在列表中）。同一个列表单词最多使用一次。

请计算从 `begin` 变换到 `end` 的最短「接龙序列」包含多少个单词（`begin` 和 `end` 都计入）。如果无法完成接龙，返回 $0$。

所有单词都只包含小写字母，且长度相同（记为 $L$）；当 `begin` 与 `end` 相同时，接龙序列只有 $1$ 个单词，答案为 $1$。

### 输入格式

- 第一行三个部分：整数 $n$、单词 `begin`、单词 `end`，相邻两个用一个空格隔开；
- 第二行 $n$ 个单词，相邻两个用一个空格隔开，表示单词列表。

### 输出格式

输出一行一个整数：最短接龙序列的单词个数；无法接龙输出 `0`。

### 数据范围

- $1 \le n \le 5000$
- $1 \le L \le 10$
- `begin`、`end` 与列表中的每个单词长度都等于 $L$，且只含小写英文字母
- 列表中的单词可能重复，也可能与 `begin` 或 `end` 相同
- 时间限制 2000 ms，空间限制 256 MB

### 输入输出样例

**输入**

```
6 hit cog
hot dot dog lot log cog
```

**输出**

```
5
```

### 样例说明

一条最短接龙为 `hit` → `hot` → `dot` → `dog` → `cog`，共 $5$ 个单词，每一步都只改变一个字母且中间单词都在列表中。

因为 `hit` 与 `cog` 三个位置上的字母全都不同，至少需要 $3$ 次变换（$4$ 个单词），而 $4$ 个单词的方案不存在，所以答案为 `5`。
