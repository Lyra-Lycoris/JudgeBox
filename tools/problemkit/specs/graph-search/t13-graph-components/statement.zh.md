# 连通分量计数

给定一个 $n$ 个顶点（编号 $1 \sim n$）、$m$ 条边的**无向图**。请统计这个图有多少个连通分量。

孤立点（没有任何边的顶点）本身也算一个连通分量。图中允许出现自环（$u = v$）和重边。

### 输入格式

- 第一行两个整数 $n$ 与 $m$，用一个空格隔开；
- 接下来 $m$ 行，每行两个整数 $u, v$，用一个空格隔开，表示顶点 $u$ 与顶点 $v$ 之间有一条无向边。

当 $m = 0$ 时，第一行之后没有其他内容。

### 输出格式

输出一行一个整数，表示连通分量的个数。

### 数据范围

- $1 \le n \le 200000$
- $0 \le m \le 200000$
- $1 \le u, v \le n$
- 时间限制 2000 ms，空间限制 256 MB

### 输入输出样例

**输入**

```
5 3
1 2
2 3
4 5
```

**输出**

```
2
```

### 样例说明

顶点 $1, 2, 3$ 连成一个分量；顶点 $4, 5$ 连成一个分量。所有顶点都被覆盖，因此共有 $2$ 个连通分量。
