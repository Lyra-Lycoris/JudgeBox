# 有向图判环

给定一个 $n$ 个顶点（编号 $1 \sim n$）、$m$ 条边的**有向图**。请判断图中是否存在环，并统计**位于至少一个有向环上的顶点个数**。

如果图中没有任何环，答案为 $0$。

说明：顶点 $v$ 位于某个环上，指的是存在一条从 $v$ 出发、经过至少一条边、最终回到 $v$ 的有向路径。自环 $u \to u$ 算作长度为 $1$ 的环。重边不改变结论。

### 输入格式

- 第一行两个整数 $n$ 与 $m$，用一个空格隔开；
- 接下来 $m$ 行，每行两个整数 $u, v$，用一个空格隔开，表示一条从 $u$ 指向 $v$ 的有向边。

当 $m = 0$ 时，第一行之后没有其他内容。

### 输出格式

输出一行一个整数，表示位于至少一个有向环上的顶点个数。

### 数据范围

- $1 \le n \le 200000$
- $0 \le m \le 200000$
- $1 \le u, v \le n$
- 时间限制 2000 ms，空间限制 256 MB

### 输入输出样例

**输入 1**

```
6 5
1 2
2 3
3 1
4 5
5 6
```

**输出 1**

```
3
```

**输入 2**

```
2 1
1 1
```

**输出 2**

```
1
```

### 样例说明

样例 1：$1 \to 2 \to 3 \to 1$ 构成一个有向环，所以顶点 $1, 2, 3$ 都在环上；$4 \to 5 \to 6$ 只是一条链，走不到任何地方再回来，所以 $4, 5, 6$ 都不在环上。答案是 `3`。

样例 2：$1 \to 1$ 是自环，顶点 $1$ 在环上；顶点 $2$ 没有任何边。答案是 `1`。
