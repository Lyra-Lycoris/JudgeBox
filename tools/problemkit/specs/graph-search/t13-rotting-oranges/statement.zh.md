# 腐烂的橘子

给定一个 $n$ 行 $m$ 列的网格，每个格子有三种取值：

- `0`：空格子，没有橘子；
- `1`：一个新鲜橘子；
- `2`：一个已经腐烂的橘子。

每一分钟，所有已经腐烂的橘子会同时把它们**上下左右相邻**的新鲜橘子也变成腐烂的橘子（新腐烂的橘子要到下一分钟才能继续传染）；腐烂不会穿过空格子。

请计算：最少经过多少分钟，网格中不再有新鲜橘子？如果无论如何都无法让所有新鲜橘子腐烂，返回 $-1$；如果一开始就没有新鲜橘子，返回 $0$。

### 输入格式

- 第一行两个整数 $n$ 与 $m$，用一个空格隔开；
- 接下来 $n$ 行，每行 $m$ 个整数（`0`、`1` 或 `2`），相邻两个用一个空格隔开。

### 输出格式

输出一行一个整数：所有新鲜橘子都腐烂所需的最少分钟数；不可能时输出 `-1`；一开始没有新鲜橘子时输出 `0`。

### 数据范围

- $1 \le n, m \le 500$
- 网格中的每个元素只可能是 `0`、`1` 或 `2`
- 时间限制 2000 ms，空间限制 256 MB

### 输入输出样例

**输入**

```
3 3
2 1 1
1 1 0
0 1 1
```

**输出**

```
4
```

### 样例说明

初始时只有左上角的橘子是腐烂的。

- 第 $1$ 分钟：$(0,1)$ 与 $(1,0)$ 腐烂；
- 第 $2$ 分钟：$(1,1)$ 腐烂；
- 第 $3$ 分钟：$(2,1)$ 腐烂（$(1,2)$ 是空格子）；
- 第 $4$ 分钟：$(2,2)$ 腐烂。

此时没有新鲜橘子，共用了 $4$ 分钟，所以输出 `4`。
