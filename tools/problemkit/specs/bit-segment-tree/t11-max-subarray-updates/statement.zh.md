# 带修改的最大子段和

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$。接下来有 $q$ 次操作，操作分为两种：

- `1 x v`：把第 $x$ 个数改为 $v$，即 $a_x \leftarrow v$；
- `2 l r`：求区间 $[l, r]$ 的**最大子段和**，即

$$\max_{l \le i \le j \le r} \sum_{k=i}^{j} a_k.$$

注意子段必须非空（即 $i \le j$）。请按顺序执行所有操作，并依次回答每一次询问。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

第三行一个整数 $q$。

接下来 $q$ 行，每行三个整数，描述一次操作：

- `1 x v` 表示单点赋值；
- `2 l r` 表示询问区间最大子段和。

保证至少有一次 `2` 类操作。

### 输出

一行，按询问出现的顺序输出每次询问的答案，相邻两个整数之间用一个空格分隔。

### 数据范围

- $1 \le n \le 5 \times 10^4$
- $1 \le q \le 10^5$
- $1 \le x, l \le r \le n$
- $-10^9 \le a_i, v \le 10^9$
- 任意时刻「区间和」的绝对值不超过 $2 \times 10^{14}$

### 样例说明

初始序列为 $1, -2, 3, -1, 2$。

第一次操作 `2 1 5` 询问整段的最大子段和，取子段 $[3, 5]$ 得 $3 + (-1) + 2 = 4$。

第二次操作 `1 2 3` 把第 $2$ 个数改为 $3$，序列变为 $1, 3, 3, -1, 2$。

第三次操作 `2 1 5` 询问整段，取子段 $[1, 5]$ 得 $1 + 3 + 3 + (-1) + 2 = 8$。

第四次操作 `2 2 2` 询问单点区间 $[2, 2]$，答案为 $3$。

因此输出 `4 8 3`。
