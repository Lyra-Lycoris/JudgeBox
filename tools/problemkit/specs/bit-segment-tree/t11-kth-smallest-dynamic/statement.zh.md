# 动态第 k 小

维护一个可重复的整数集合（多重集），初始为空。接下来有 $q$ 次操作，每次操作为下列三种之一：

- `1 v`：向集合中插入一个 $v$；
- `2 v`：从集合中删除一个 $v$（保证当前集合中至少存在一个 $v$）；
- `3 k`：询问当前集合中第 $k$ 小的数（保证 $1 \le k \le$ 当前集合元素个数）。

请按顺序执行所有操作，并依次回答每一次询问。

### 输入

第一行一个整数 $q$。

接下来 $q$ 行，每行两个整数 $t, v$，描述一次操作：

- $t = 1$ 表示插入 $v$；
- $t = 2$ 表示删除一个 $v$；
- $t = 3$ 表示询问第 $v$ 小（此时第二个整数就是 $k = v$）。

保证至少有一次 $t = 3$ 的操作。

### 输出

一行，按询问出现的顺序输出每次询问的答案，相邻两个整数之间用一个空格分隔。

### 数据范围

- $1 \le q \le 2 \times 10^5$
- 插入与删除时 $1 \le v \le 10^9$
- 询问时 $1 \le k \le$ 当前集合中的元素个数
- 所有删除操作删除的数值都保证当前存在

### 样例说明

初始集合为空。

`1 5`、`1 3`、`1 9` 之后集合为 $\{3, 5, 9\}$。

`3 1` 询问第 $1$ 小，答案是 $3$。

`3 3` 询问第 $3$ 小，答案是 $9$。

`2 3` 删除一个 $3$，集合变为 $\{5, 9\}$。

`3 1` 询问第 $1$ 小，答案是 $5$。

因此输出 `3 9 5`。
