# 区间赋值与总和

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$。接下来有 $q$ 次操作，第 $j$ 次操作给出三个整数 $l_j, r_j, v_j$，表示把区间 $[l_j, r_j]$ 内的**所有**数都改为 $v_j$：

$$a_i \leftarrow v_j \quad (l_j \le i \le r_j).$$

请在每次操作执行完毕之后，输出整个序列的总和 $\sum_{i=1}^{n} a_i$。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

第三行一个整数 $q$。

接下来 $q$ 行，每行三个整数 $l_j, r_j, v_j$，描述一次区间赋值操作。

### 输出

一行 $q$ 个整数，第 $j$ 个整数表示第 $j$ 次操作执行完毕之后整个序列的总和，相邻两个整数之间用一个空格分隔。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $1 \le q \le 10^5$
- $1 \le l_j \le r_j \le n$
- $-10^9 \le a_i, v_j \le 10^9$
- 任意时刻整个序列的总和都在 $[-2 \times 10^{14}, 2 \times 10^{14}]$ 内

### 样例说明

初始序列为 $1, 2, 3, 4, 5$。

第一次操作 `1 3 7` 把 $[1, 3]$ 都改为 $7$，序列变为 $7, 7, 7, 4, 5$，总和为 $30$。

第二次操作 `2 5 0` 把 $[2, 5]$ 都改为 $0$，序列变为 $7, 0, 0, 0, 0$，总和为 $7$。

第三次操作 `1 5 2` 把 $[1, 5]$ 都改为 $2$，序列变为 $2, 2, 2, 2, 2$，总和为 $10$。

因此输出 `30 7 10`。
