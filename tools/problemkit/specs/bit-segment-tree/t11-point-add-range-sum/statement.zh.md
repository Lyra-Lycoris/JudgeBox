# 单点修改与区间求和

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$。接下来有 $q$ 次操作，操作分为两种：

- `1 x v`：把第 $x$ 个数增加 $v$，即 $a_x \leftarrow a_x + v$；
- `2 l r`：询问区间 $[l, r]$ 内所有数之和，即 $\sum_{i=l}^{r} a_i$。

请按顺序执行所有操作，并依次回答每一次询问。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

第三行一个整数 $q$。

接下来 $q$ 行，每行三个整数，描述一次操作：

- `1 x v` 表示单点增加；
- `2 l r` 表示区间求和询问。

保证至少有一次 `2` 类操作。

### 输出

一行，按询问出现的顺序输出每次询问的答案，相邻两个整数之间用一个空格分隔。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $1 \le q \le 10^5$
- $1 \le x, l \le r \le n$
- $-10^9 \le a_i, v \le 10^9$
- 任意时刻整个序列的和都在 $[-2 \times 10^{14}, 2 \times 10^{14}]$ 内

### 样例说明

初始序列为 $1, 2, 3, 4, 5$。

第一次操作 `1 3 10` 把第 $3$ 个数加 $10$，序列变为 $1, 2, 13, 4, 5$。

第二次操作 `2 1 3` 询问 $[1, 3]$ 的和，得到 $1 + 2 + 13 = 16$。

第三次操作 `2 2 5` 询问 $[2, 5]$ 的和，得到 $2 + 13 + 4 + 5 = 24$。

因此输出 `16 24`。
