# 区间加与单点查询

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$。接下来有 $q$ 次操作，每次操作由四个整数 $t, l, r, v$ 描述：

- $t = 1$：把区间 $[l, r]$ 内的每个数都加上 $v$，即 $a_i \leftarrow a_i + v\ (l \le i \le r)$；
- $t = 2$：询问当前 $a_l$ 的值。此时保证 $r = 0$、$v = 0$（这两个数不参与计算）。

请按顺序执行所有操作，并依次回答每一次单点查询。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

第三行一个整数 $q$。

接下来 $q$ 行，每行四个整数 $t, l, r, v$，描述一次操作。保证至少有一次 $t = 2$ 的操作。

### 输出

一行，按查询出现的顺序输出每次查询的答案，相邻两个整数之间用一个空格分隔。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $1 \le q \le 10^5$
- $1 \le l \le r \le n$（$t = 1$ 时），$1 \le l \le n$（$t = 2$ 时）
- $-10^9 \le a_i, v \le 10^9$
- 任意时刻每个位置的数都落在 $[-2 \times 10^{14}, 2 \times 10^{14}]$ 内

### 样例说明

初始序列为 $1, 2, 3, 4, 5$。

第一次操作 `1 1 3 10` 把 $[1, 3]$ 加 $10$，序列变为 $11, 12, 13, 4, 5$。

第二次操作 `2 2 0 0` 查询第 $2$ 个数，得到 $12$。

第三次操作 `1 2 5 -4` 把 $[2, 5]$ 加 $-4$，序列变为 $11, 8, 9, 0, 1$。

第四次操作 `2 3 0 0` 查询第 $3$ 个数，得到 $9$。

因此输出 `12 9`。
