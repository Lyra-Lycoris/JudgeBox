# 静态区间最大值

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$，序列在询问过程中**不会改变**。

接下来有 $q$ 次询问，第 $j$ 次询问给出 $l_j, r_j$，请回答

$$\max_{l_j \le i \le r_j} a_i.$$

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

第三行一个整数 $q$。

接下来 $q$ 行，每行两个整数 $l_j, r_j$，描述一次询问。

### 输出

一行，按询问出现的顺序输出每次询问的答案，相邻两个整数之间用一个空格分隔。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $1 \le q \le 2 \times 10^5$
- $1 \le l_j \le r_j \le n$
- $-10^9 \le a_i \le 10^9$

### 样例说明

序列为 $1, 7, 3, 9, 2, 8$。

- 询问 $[1, 3]$：最大值为 $\max(1, 7, 3) = 7$；
- 询问 $[4, 6]$：最大值为 $\max(9, 2, 8) = 9$；
- 询问 $[2, 2]$：只有一个数，答案为 $7$；
- 询问 $[1, 6]$：最大值为 $9$。

因此输出 `7 9 7 9`。
