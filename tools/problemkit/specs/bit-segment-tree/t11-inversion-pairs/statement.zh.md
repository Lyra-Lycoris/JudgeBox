# 逆序对计数

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$。若下标对 $(i, j)$ 满足 $i < j$ 且 $a_i > a_j$，则称它是一个**逆序对**。

请你统计序列中逆序对的总数。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

### 输出

一行一个整数，表示逆序对的总数。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $-10^9 \le a_i \le 10^9$
- 答案不超过 $\frac{n(n-1)}{2} \le 2 \times 10^{10}$，请使用 64 位整数

### 样例说明

序列为 $5, 4, 3, 2, 1$。任意两个位置都构成逆序对，共 $\binom{5}{2} = 10$ 个，因此输出 `10`。
