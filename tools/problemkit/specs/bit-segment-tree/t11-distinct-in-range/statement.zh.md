# 区间内不同数的个数

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$。

接下来有 $q$ 次询问，第 $j$ 次询问给出 $l_j, r_j$，请回答：区间 $a_{l_j}, a_{l_j+1}, \dots, a_{r_j}$ 中共有多少个**不同**的数值。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

第三行一个整数 $q$。

接下来 $q$ 行，每行两个整数 $l_j, r_j$，描述一次询问。

### 输出

一行，按询问出现的顺序输出每次询问的答案，相邻两个整数之间用一个空格分隔。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $1 \le q \le 10^5$
- $1 \le l_j \le r_j \le n$
- $-10^9 \le a_i \le 10^9$

### 样例说明

序列为 $1, 2, 1, 3, 2, 1$。

- 询问 $[1, 6]$：出现了 $1, 2, 3$，共 $3$ 种不同数值；
- 询问 $[1, 3]$：出现了 $1, 2$，共 $2$ 种；
- 询问 $[2, 4]$：出现了 $2, 1, 3$，共 $3$ 种；
- 询问 $[4, 4]$：只有 $3$，共 $1$ 种。

因此输出 `3 2 3 1`。
