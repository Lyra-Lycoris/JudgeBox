# 最小运载容量

有一批货物共 $n$ 件，第 $i$ 件的重量为 $w_i$。需要把它们从码头运到对岸，运输必须**按给定顺序**进行。

船每天出海一次，当天可以装上若干件**连续**的货物，因为这些货物要按顺序叠放。船有一个固定的单日运载容量 $C$：当天装的货物总重量不能超过 $C$。

现在要求在 $d$ 天之内（含 $d$ 天）把所有货物运完，求最小的可行容量 $C$。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $w_1, w_2, \dots, w_n$。

第三行一个整数 $d$。

### 输出

一行一个整数，表示最小的可行容量 $C$。

### 数据范围

- $1 \le d \le n \le 2 \times 10^5$
- $1 \le w_i \le 10^9$
- 保证 $\sum w_i \le 2 \times 10^{14}$，答案在 64 位整数范围内

### 样例说明

$n = 10$，重量依次为 $1, 2, \dots, 10$，要求 $d = 5$ 天内运完。

- 容量 $C = 14$ 时，按顺序贪心装载：第 1 天装 $1+2+3+4 = 10$，第 2 天装 $5+6 = 11$，第 3 天装 $7$，第 4 天装 $8$，第 5 天装 $9$，还剩 $10$ 需要第 6 天，超过 $5$ 天。
- 容量 $C = 15$ 时：第 1 天 $1+2+3+4+5 = 15$，第 2 天 $6+7 = 13$，第 3 天 $8$，第 4 天 $9$，第 5 天 $10$，正好 $5$ 天。

所以最小容量是 $15$。

判定一个容量 $C$ 是否可行时，只需按顺序贪心：能装就装，装不下就换一天，这样用的天数最少。天数随 $C$ 增大而不增，因此可以二分答案。
