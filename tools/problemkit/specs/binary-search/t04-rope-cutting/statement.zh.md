# 切绳子

有 $n$ 根绳子，第 $i$ 根的长度为 $a_i$ 厘米。现在需要从这些绳子上切出 $k$ 段长度相同的绳子，每段的长度必须是整数厘米，剩下的边角料可以丢弃。

求每段绳子的最大可能长度。如果连长度 $1$ 厘米都切不出 $k$ 段，输出 $0$。

注意：每根绳子只能切出整数段，不能把两根绳子的剩余部分拼接起来。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，表示每根绳子的长度（厘米）。

第三行一个整数 $k$。

### 输出

一行一个整数，表示能切出的 $k$ 段等长绳子的最大长度；若无法切出 $k$ 段则输出 $0$。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $1 \le a_i \le 10^9$
- $1 \le k \le 10^9$

### 样例说明

$n = 4$，绳子长度为 $8, 7, 6, 5$，需要切出 $k = 4$ 段。

- 若每段长 $5$：四根绳子分别能切出 $1, 1, 1, 1$ 段，共 $4$ 段，足够。
- 若每段长 $6$：四根绳子分别能切出 $1, 1, 1, 0$ 段，共 $3$ 段，不够。

所以最大长度是 $5$，输出 $5$。

一般的判定方法：固定每段长度 $L$，总共能切出 $\sum_i \lfloor a_i / L \rfloor$ 段，这个数量随 $L$ 增大而不增，因此可以对 $L$ 二分答案。
