# 第一个不小于 x 的位置

给定一个长度为 $n$ 的**非递减**整数数组 $a_0, a_1, \dots, a_{n-1}$，以及一个整数 $x$。

请找到最小的下标 $i$（$0 \le i \le n$），使得 $a_i \ge x$。如果不存在这样的下标（也就是所有元素都小于 $x$），则返回 $n$。

数组下标从 $0$ 开始计数。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_0, a_1, \dots, a_{n-1}$，保证非递减（$a_0 \le a_1 \le \dots \le a_{n-1}$）。

第三行一个整数 $x$。

### 输出

一行一个整数，表示最小的满足 $a_i \ge x$ 的下标 $i$；若不存在则输出 $n$。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $-10^9 \le a_i \le 10^9$，且数组非递减
- $-10^9 \le x \le 10^9$

### 样例说明

$n = 5$，数组为 $1, 3, 5, 7, 9$，$x = 5$。

$a_0 = 1 < 5$，$a_1 = 3 < 5$，$a_2 = 5 \ge 5$，所以最小的满足条件的下标是 $2$，输出 $2$。

数组是单调的，可以用二分查找在 $O(\log n)$ 时间内找到答案。
