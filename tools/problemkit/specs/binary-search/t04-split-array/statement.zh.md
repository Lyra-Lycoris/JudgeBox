# 分割数组使最大段和最小

给定一个长度为 $n$ 的非负整数数组 $a_0, a_1, \dots, a_{n-1}$，以及一个整数 $k$。

请把数组划分成 $k$ 段**非空**的连续子数组（即选择 $k-1$ 个切割位置），使得这 $k$ 段各自元素之和的最大值尽可能小。

求这个最小的“最大段和”。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_0, a_1, \dots, a_{n-1}$。

第三行一个整数 $k$。

### 输出

一行一个整数，表示最小的最大段和。

### 数据范围

- $1 \le k \le n \le 2 \times 10^5$
- $0 \le a_i \le 10^9$
- 保证 $\sum a_i \le 2 \times 10^{14}$，答案在 64 位整数范围内

### 样例说明

$n = 5$，数组为 $7, 2, 5, 10, 8$，$k = 2$。

可行的划分方式有：

- $[7] \mid [2, 5, 10, 8]$：两段和为 $7$ 和 $25$，最大值 $25$。
- $[7, 2] \mid [5, 10, 8]$：$9$ 和 $23$，最大值 $23$。
- $[7, 2, 5] \mid [10, 8]$：$14$ 和 $18$，最大值 $18$。
- $[7, 2, 5, 10] \mid [8]$：$24$ 和 $8$，最大值 $24$。

最大值的最小可能值是 $18$，输出 $18$。

判定“最大段和不超过 $S$”是否可行时，只需从左到右贪心：每段尽量装满但不超过 $S$，看能否用不超过 $k$ 段装完。由于元素非负，所需段数随 $S$ 增大而不增，因此可以二分答案 $S \in [\max a_i, \sum a_i]$。
