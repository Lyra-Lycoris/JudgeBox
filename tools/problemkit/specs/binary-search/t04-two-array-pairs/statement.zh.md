# 两数之和不超过 x 的数对

给定两个整数数组 $a_0, a_1, \dots, a_{n-1}$ 和 $b_0, b_1, \dots, b_{m-1}$，以及一个整数 $x$。

请统计满足 $a_i + b_j \le x$ 的下标对 $(i, j)$ 的个数，其中 $0 \le i < n$，$0 \le j < m$。

注意下标对是有序的（$(i, j)$ 与 $(j, i)$ 视为不同的两个数对，因为两个数组不同），同一个下标可以被多次使用。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_0, a_1, \dots, a_{n-1}$。

第三行一个整数 $m$。

第四行 $m$ 个整数 $b_0, b_1, \dots, b_{m-1}$。

第五行一个整数 $x$。

### 输出

一行一个整数，表示满足 $a_i + b_j \le x$ 的数对个数。

### 数据范围

- $1 \le n, m \le 2 \times 10^5$
- $-10^9 \le a_i, b_j \le 10^9$
- $-2 \times 10^9 \le x \le 2 \times 10^9$
- 答案最大为 $n \times m \le 4 \times 10^{10}$，在 64 位整数范围内

### 样例说明

$n = 3$，$a = [1, 2, 3]$；$m = 3$，$b = [4, 5, 6]$；$x = 7$。

- $a_0 = 1$：$1 + 4 = 5$、$1 + 5 = 6$、$1 + 6 = 7$ 都满足，共 $3$ 对。
- $a_1 = 2$：$2 + 4 = 6$、$2 + 5 = 7$ 满足，$2 + 6 = 8$ 不满足，共 $2$ 对。
- $a_2 = 3$：$3 + 4 = 7$ 满足，其余不满足，共 $1$ 对。

总数为 $3 + 2 + 1 = 6$，输出 $6$。

做法：把 $b$ 排序，枚举 $a_i$，在 $b$ 中二分统计有多少个元素不超过 $x - a_i$，总复杂度 $O(n \log m)$。
