# 旋转数组的最小值

一个长度为 $n$ 的**严格递增**整数数组，在某个位置被“旋转”了一次：把开头的若干元素整体搬到末尾（搬运的元素个数可以是 $0$，即数组保持原样）。

例如严格递增数组 $1, 2, 3, 4, 5$ 旋转后可能得到 $3, 4, 5, 1, 2$，也可能得到 $1, 2, 3, 4, 5$（没有旋转）。

给定旋转后的数组，求其中的最小元素。数组中的元素**互不相同**。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，表示旋转后的数组。

### 输出

一行一个整数，表示数组中的最小元素。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $-10^9 \le a_i \le 10^9$
- 数组中的元素互不相同
- 保证数组是由某个严格递增数组旋转得到的

### 样例说明

$n = 7$，数组为 $4, 5, 6, 7, 0, 1, 2$。

它由严格递增数组 $0, 1, 2, 4, 5, 6, 7$ 旋转 $4$ 位得到，最小元素是 $0$，输出 $0$。

由于数组由两段递增序列拼接而成，比较中点与右端点的值就能判断最小值落在哪一半，从而在 $O(\log n)$ 时间内找到答案。
