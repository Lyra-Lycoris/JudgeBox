# 峰值元素

给定一个长度为 $n$ 的整数数组 $a_0, a_1, \dots, a_{n-1}$，数组中的元素**互不相同**。

我们称下标 $i$ 是**峰值**，当且仅当：

- 若 $i > 0$，则 $a_i > a_{i-1}$；
- 若 $i < n - 1$，则 $a_i > a_{i+1}$。

换句话说，峰值比它所有存在的邻居都大。把下标 $-1$ 和 $n$ 处的元素看作 $-\infty$，因此数组的第一个元素和最后一个元素也可能是峰值。

请返回**任意一个**峰值元素的下标（下标从 $0$ 开始）。

本题使用**特殊评判（SPJ）**：只要返回的下标确实是峰值，就判为正确，不要求与标准答案的下标相同。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_0, a_1, \dots, a_{n-1}$。

### 输出

一行一个整数 $i$（$0 \le i < n$），表示一个峰值元素的下标。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $-10^9 \le a_i \le 10^9$
- 数组中的元素互不相同

### 样例说明

$n = 4$，数组为 $1, 2, 3, 0$。

- 下标 $0$：$a_0 = 1 < a_1 = 2$，不是峰值。
- 下标 $1$：$a_1 = 2 < a_2 = 3$，不是峰值。
- 下标 $2$：$a_2 = 3 > a_1 = 2$ 且 $a_2 = 3 > a_3 = 0$，是峰值。
- 下标 $3$：$a_3 = 0 < a_2 = 3$，不是峰值。

唯一的峰值是下标 $2$，输出 $2$ 即可（输出其他合法答案也算正确，但本题数据中只有 $2$ 合法）。

利用“向相邻的更大元素方向移动一定有峰值”这一性质，可以用二分在 $O(\log n)$ 时间内找到一个峰值。
