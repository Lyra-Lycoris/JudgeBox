# 二进制中 1 的个数

给定一个非负整数 $n$，请统计 $n$ 的二进制表示（不含前导零）中数字 $1$ 的个数，这个量也叫做 $n$ 的**二进制位计数**（popcount）。

例如 $n = 11$，其二进制表示为 $(1011)_2$，其中共有 $3$ 个 $1$，所以答案为 $3$。

### 输入格式

一行一个整数 $n$。

### 输出格式

一行一个整数，表示 $n$ 的二进制表示中 $1$ 的个数。

### 数据范围

- $0 \le n \le 2^{63}-1$，即 $0 \le n \le 9223372036854775807$。

特别地，$n = 0$ 的二进制表示视为 `0`，答案为 $0$；$n$ 的二进制表示最多有 $63$ 位，因此答案不超过 $63$，可以放进 64 位整数。

### 样例说明

**样例 1**：$n = 11 = (1011)_2$，从低到高四个二进制位依次是 $1, 1, 0, 1$，其中 $1$ 的个数为 $3$，输出 `3`。

**样例 2**：$n = 9223372036854775807 = 2^{63}-1 = (111\cdots111)_2$，即连续 $63$ 个 $1$，输出 `63`。

### 提示

设 `lowbit(x) = x & (-x)`，它取出 $x$ 最低位的那个 $1$。反复执行

```
x = x & (x - 1)
```

每次都会恰好消去 $x$ 的最低位 $1$，循环执行的次数就是 $1$ 的个数。这样做的复杂度是 $O(\text{popcount}(n))$，最坏 $O(\log n)$。

也可以直接从低到高枚举 $0 \sim 62$ 每一位，检查 `(n >> i) & 1` 是否为 $1$。
