# 所有子集的异或和

给定 $n$ 个非负整数 $a_1, a_2, \dots, a_n$。

考虑这 $n$ 个数的**全部** $2^n$ 个子集（包括空集）。对每个子集，把它包含的所有数做**按位异或**（空集的异或和规定为 $0$），得到一个值。

请计算所有 $2^n$ 个子集的异或和之**和**，并对 $10^9+7$ 取模。

### 输入格式

- 第一行一个整数 $n$；
- 第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个用一个空格隔开。

### 输出格式

一行一个整数，表示所有子集异或和之和对 $10^9+7$ 取模的结果。

### 数据范围

- $1 \le n \le 200000$；
- $0 \le a_i \le 10^9$。

注意总和本身可能非常大（有 $2^n$ 个子集），因此只要求输出它对 $10^9+7$ 取模的结果。

### 样例说明

**样例 1**：$n = 2$，数组为 $1, 2$。全部 $4$ 个子集是：

| 子集 | 异或和 |
| --- | --- |
| $\varnothing$ | $0$ |
| $\{1\}$ | $1$ |
| $\{2\}$ | $2$ |
| $\{1, 2\}$ | $1 \oplus 2 = 3$ |

总和为 $0 + 1 + 2 + 3 = 6$，输出 `6`。

**样例 2**：$n = 3$，数组为 $5, 5, 5$。$8$ 个子集里：空集贡献 $0$，三个单元素子集贡献 $5$ 各一次，三个双元素子集贡献 $5 \oplus 5 = 0$，全集贡献 $5 \oplus 5 \oplus 5 = 5$。总和为 $5 + 5 + 5 + 5 = 20$，输出 `20`。

### 提示

**按二进制位拆分**：答案等于每一位对总和的贡献之和，而不同位之间互不影响。

考虑第 $b$ 位（权值为 $2^b$）。如果所有 $a_i$ 的第 $b$ 位都是 $0$，那么任何子集的异或和第 $b$ 位都是 $0$，贡献为 $0$。

否则，任取一个第 $b$ 位为 $1$ 的元素 $e$。把全部 $2^n$ 个子集按"是否包含 $e$"两两配对：子集 $S$ 与"把 $e$ 的选取状态取反"得到的 $S'$。同一对中两个子集的异或和只在第 $b$ 位上不同，所以每对里恰有一个子集的第 $b$ 位为 $1$，这样的子集共有 $2^{n-1}$ 个，这一位的贡献是 $2^b \cdot 2^{n-1}$。

因此

$$\text{答案} = \left(a_1 \mathrel{|} a_2 \mathrel{|} \cdots \mathrel{|} a_n\right) \cdot 2^{n-1} \bmod (10^9+7),$$

用二进制快速幂计算 $2^{n-1} \bmod (10^9+7)$ 即可，时间复杂度 $O(n + \log n)$。
