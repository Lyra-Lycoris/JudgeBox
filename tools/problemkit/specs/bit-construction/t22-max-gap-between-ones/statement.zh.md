# 二进制中相邻 1 的最大间隔

给定一个非负整数 $n$，考虑它的二进制表示（不含前导零）。设其中为 $1$ 的位从低到高依次是

$$p_1 < p_2 < \dots < p_k$$

（最低位是第 $0$ 位）。定义 $n$ 的**最大间隔**为：

- 若 $k < 2$，最大间隔为 $0$；
- 否则，最大间隔为 $\max_{1 \le i < k} \left(p_{i+1} - p_i - 1\right)$，也就是相邻两个 $1$ 之间夹着的 $0$ 的个数的最大值。

注意：二进制表示的最低位以下、最高位以上都不算"相邻两个 $1$ 之间"，它们不参与统计。

现在给定 $T$ 个非负整数，请对每个整数求出它的最大间隔。

### 输入格式

- 第一行一个整数 $T$；
- 接下来 $T$ 行，每行一个整数 $n$。

### 输出格式

输出 $T$ 行，每行一个整数，表示对应整数的最大间隔。

### 数据范围

- $1 \le T \le 200000$；
- $0 \le n \le 10^{18}$。

$10^{18} < 2^{60}$，所以每个数的二进制表示最多 $60$ 位（位编号 $0 \sim 59$），答案不超过 $58$：取 $n = 2^{59}+1$ 即可让 $1$ 分别落在第 $0$ 位和第 $59$ 位。

### 样例说明

样例输入为 $T = 3$，三个数分别是 $9, 5, 100$。

- $n = 9 = (1001)_2$：为 $1$ 的位是第 $0$ 位和第 $3$ 位，中间夹着 $3 - 0 - 1 = 2$ 个 $0$，最大间隔为 $2$。
- $n = 5 = (101)_2$：为 $1$ 的位是第 $0$ 位和第 $2$ 位，中间夹着 $1$ 个 $0$，最大间隔为 $1$。
- $n = 100 = (1100100)_2$：为 $1$ 的位是第 $2, 5, 6$ 位。相邻间隔为 $5-2-1 = 2$ 和 $6-5-1 = 0$，最大间隔为 $2$。

因此输出三行：`2`、`1`、`2`。

### 提示

从低位向高位扫描：用 `last` 记录上一个 $1$ 的位置（初始为"不存在"），用 `pos` 记录当前处理到第几位。

- 若 `n & 1` 为 $1$：如果 `last` 存在，就用 `pos - last - 1` 去更新答案，然后令 `last = pos`；
- 无论这一位是不是 $1$，都执行 `n >>= 1`、`pos += 1`。

这样每个数只需要 $60$ 次循环，总复杂度 $O(60T)$。也可以先写一个函数求单个数的答案，再对 $T$ 组数据各调用一次。
