# 只出现一次的两个数字

给定 $n$ 个整数 $a_1, a_2, \dots, a_n$。其中**恰好有两个整数各出现一次**，其余每个整数都**恰好出现两次**。

请找出这两个只出现一次的整数，并按**从小到大的顺序**输出。

### 输入格式

- 第一行一个整数 $n$；
- 第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个用一个空格隔开。

### 输出格式

一行两个整数，按从小到大排列，中间用一个空格隔开。

### 数据范围

- $2 \le n \le 200000$，且 $n$ 为偶数；
- $-10^9 \le a_i \le 10^9$，即输入中可能包含负数。

数据保证输入中恰好有两个整数各出现一次，其余每个整数都恰好出现两次，因此答案唯一。

负数在计算机中按补码存储，因此下面的位运算做法对负数同样成立。

### 样例说明

**样例 1**：$n = 6$，数组为 $1, 2, 1, 3, 2, 5$。

其中 $1$ 出现两次、$2$ 出现两次，$3$ 和 $5$ 各出现一次，所以输出 `3 5`。

**样例 2**：$n = 2$，数组为 $-4, 9$，两个数都只出现一次，按从小到大输出 `-4 9`。

### 提示

把所有数全部异或起来，出现两次的数会两两抵消，得到 $x = p \oplus q$，其中 $p, q$ 就是答案。因为 $p \ne q$，所以 $x \ne 0$。

取 `lowbit = x & (-x)`，它是 $x$ 最低位的那个 $1$。$p$ 与 $q$ 在这一位上必然不同：把数组按这一位是 $0$ 还是 $1$ 分成两组，各自整体异或，就分别得到 $p$ 和 $q$。

这样做时间复杂度 $O(n)$、额外空间 $O(1)$。用哈希表统计出现次数（$O(n)$ 空间）同样可以通过本题。
