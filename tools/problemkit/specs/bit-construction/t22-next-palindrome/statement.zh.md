# 回文数构造

如果一个整数的十进制表示（不含前导零）从左到右读与从右到左读完全相同，就称它是**回文数**。例如 $0, 7, 11, 121, 1331, 9999$ 是回文数，而 $10, 123, 1000$ 不是。

给定一个非负整数 $n$，请找出**不小于** $n$ 的最小回文数。

### 输入格式

一行一个整数 $n$。

### 输出格式

一行一个整数，表示不小于 $n$ 的最小回文数。

### 数据范围

- $0 \le n \le 10^{18}$。

答案不超过 $1000000000000000001$（$10^{18}+1$），可以放进 64 位整数。

### 样例说明

**样例 1**：$n = 1234$。

$1234$ 本身不是回文数。位数相同的回文数完全由它的前一半决定：

- 前一半为 $12$ 时，回文数是 $1221 < 1234$；
- 前一半为 $13$ 时，回文数是 $1331 \ge 1234$。

因此不小于 $1234$ 的最小回文数是 $1331$，输出 `1331`。

**样例 2**：$n = 102$。

$n$ 是三位数，前一半取到中间位，即 $10$，镜像得到 $101 < 102$；把前一半加一得到 $11$，镜像得到 $111 \ge 102$，所以输出 `111`。

### 提示

设 $n$ 有 $L$ 位，取 $n$ 的前 $\lceil L/2 \rceil$ 位（$L$ 为奇数时包含中间那位）记作 $h$。

1. 把 $h$ 反转后接在 $h$ 后面得到候选 $c$：$L$ 为偶数时拼接 $h$ 的完整反转，$L$ 为奇数时去掉反转的第一个字符（那个字符已经是中间位）。
2. 如果 $c \ge n$，那么 $c$ 就是答案。
3. 否则，位数相同的回文数中比 $n$ 大的最小者一定由 $h+1$ 镜像而成（若 $h+1$ 的位数变多，说明 $n$ 形如 $99\cdots9$，答案是 $1$ 后面接 $L-1$ 个 $0$ 再接 $1$）。

整个过程只需要 $O(L)$ 时间，其中 $L \le 19$。
