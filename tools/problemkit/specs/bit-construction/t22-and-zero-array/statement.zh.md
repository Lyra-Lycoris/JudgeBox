# 构造相邻按位与为 0 的数组

给定一个整数 $n$，请构造一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$，满足：

1. 对每个 $1 \le i \le n$，都有 $1 \le a_i \le 10^9$；
2. 对每个 $1 \le i < n$，都有 $a_i \mathrel{\&} a_{i+1} = 0$，其中 $\&$ 表示按位与。

本题使用**特殊评判（SPJ）**：只要输出的序列满足上面两条，就判为正确，不要求与参考解完全相同。

### 输入格式

一行一个整数 $n$。

### 输出格式

一行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个用一个空格隔开。

当 $n = 1$ 时，任意输出一个 $1 \le a_1 \le 10^9$ 的整数都算正确。

### 数据范围

- $1 \le n \le 200000$。

数据保证在给定的限制下一定有解。

### 样例说明

**样例 1**：$n = 4$。输出 `1 2 1 2`，检验：

- $1 \mathrel{\&} 2 = 0$；
- $2 \mathrel{\&} 1 = 0$；
- $1 \mathrel{\&} 2 = 0$。

三个相邻对都满足条件，且 $1, 2$ 都在 $[1, 10^9]$ 内，所以这是正确答案。输出 `4 8 1 6` 之类的其他合法序列也算正确。

**样例 2**：$n = 1$，输出任意一个 $[1, 10^9]$ 内的整数，例如 `1`。

### 提示

题目的限制只作用在**相邻**两项上，因此不需要考虑全局的位冲突，只要交替使用两个按位与为 $0$ 的数即可：令奇数位置放 $1$、偶数位置放 $2$。

$1 = (1)_2$、$2 = (10)_2$ 在二进制下没有任何公共的 $1$ 位，所以 $1 \mathrel{\&} 2 = 0$，于是所有相邻对都满足条件。

如果想让答案里出现更多不同的数，也可以让所有数只使用某几个固定的二进制位，例如"低 $20$ 位以内的数"与"第 $20 \sim 29$ 位上的数"交替出现，它们之间同样按位与为 $0$。
