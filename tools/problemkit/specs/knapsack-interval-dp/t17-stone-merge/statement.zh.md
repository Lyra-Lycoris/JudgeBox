# 石子合并最小代价

有 $n$ 堆石子排成一排，第 $i$ 堆有 $a_i$ 颗石子。

每次操作可以合并相邻的两堆石子：合并后的新堆石子数为这两堆石子数之和，本次操作的代价等于这个和。经过 $n - 1$ 次操作后，所有石子会合并成一堆。求总代价的最小值。

注意每次只能合并相邻的两堆，因此合并的顺序（即加括号的方式）会影响总代价。

### 输入格式

- 第一行一个整数 $n$；
- 第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，相邻两个用一个空格隔开。

### 输出格式

一行一个整数，表示把全部石子合并成一堆的最小总代价。

### 数据范围

$1 \le n \le 200$，$1 \le a_i \le 10^{9}$。答案不超过 $4 \times 10^{13}$。

### 样例说明

样例 1：$n = 4$，石子堆为 $(1, 3, 5, 2)$。

- 先合并第 $1, 2$ 堆，代价 $1 + 3 = 4$，序列变成 $(4, 5, 2)$；
- 再合并第 $2, 3$ 堆，代价 $5 + 2 = 7$，序列变成 $(4, 7)$；
- 最后合并这两堆，代价 $4 + 7 = 11$。

总代价 $4 + 7 + 11 = 22$，可以证明这是最小值。
