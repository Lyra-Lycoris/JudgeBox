# 括号方案最大表达式值

给定一个由 $m$ 个非负整数和 $m - 1$ 个运算符组成的表达式，运算符只会是 `+`、`-`、`*`。例如 $m = 3$、数字为 $(1, 2, 3)$、运算符为 `+`、`*` 时，表达式是 $1 + 2 * 3$。

你可以在表达式中任意添加括号来改变运算顺序（所有括号方案都合法），但不能改变数字与运算符的顺序。求所有合法括号方案中，表达式结果的最大值。

### 输入格式

- 第一行一个整数 $m$；
- 第二行 $m$ 个整数，依次是表达式中的数字；
- 第三行 $m - 1$ 个字符，依次是表达式中的运算符，每个字符是 `+`、`-`、`*` 之一（$m = 1$ 时没有这一行）。

数字与运算符都用空格隔开。

### 输出格式

一行一个整数，表示能得到的最大表达式值。

### 数据范围

$1 \le m \le 15$，$0 \le$ 每个数字 $\le 9$。答案的绝对值不超过 $9^{15}$，在 64 位整数范围内。

### 样例说明

样例 1：$m = 3$，数字 $(1, 2, 3)$，运算符 `+`、`*`，表达式为 $1 + 2 * 3$。两种括号方案分别是 $(1 + 2) * 3 = 9$ 和 $1 + (2 * 3) = 7$，最大值为 $9$。
