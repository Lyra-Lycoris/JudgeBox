# 分组背包：每组选一个

有 $n$ 件物品和一个容量为 $cap$ 的背包。每件物品有一个组号 $g_i$、一个重量 $w_i$ 和一个价值 $v_i$。同一个组内的物品最多只能选一件（也可以一件都不选）。求背包能够装下的物品总价值的最大值。

### 输入格式

- 第一行两个整数 $n, cap$，用一个空格隔开；
- 第二行 $n$ 个整数 $g_1, g_2, \dots, g_n$，表示每件物品所属的组号；
- 第三行 $n$ 个整数 $w_1, w_2, \dots, w_n$；
- 第四行 $n$ 个整数 $v_1, v_2, \dots, v_n$。

相邻两个整数之间都用一个空格隔开。组号相同（即 $g_i$ 相等）的物品属于同一组。

### 输出格式

一行一个整数，表示最大总价值。

### 数据范围

$1 \le n \le 300$，$1 \le cap \le 2000$，$1 \le g_i \le n$，$1 \le w_i \le 10^{9}$，$0 \le v_i \le 10^{9}$。

重量大于 $cap$ 的物品不可能被选中；答案不超过 $10^{12}$。

### 样例说明

样例 1：$n = 3$，$cap = 15$，物品为 $(g, w, v) = (1, 5, 10), (1, 6, 11), (2, 7, 20)$。第 $1$ 组只能选一件，取第 $2$ 件（重量 $6$、价值 $11$）；第 $2$ 组取唯一一件（重量 $7$、价值 $20$）。总重量 $13 \le 15$，总价值 $31$，这是最大值。
