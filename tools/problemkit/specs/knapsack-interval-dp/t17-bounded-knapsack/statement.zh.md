# 多重背包最大价值

有 $n$ 种物品和一个容量为 $cap$ 的背包。第 $i$ 种物品的重量是 $w_i$，价值是 $v_i$，一共有 $c_i$ 件。求背包能够装下的物品总价值的最大值。

### 输入格式

- 第一行两个整数 $n, cap$，用一个空格隔开；
- 第二行 $n$ 个整数 $w_1, w_2, \dots, w_n$；
- 第三行 $n$ 个整数 $v_1, v_2, \dots, v_n$；
- 第四行 $n$ 个整数 $c_1, c_2, \dots, c_n$。

相邻两个整数之间都用一个空格隔开。

### 输出格式

一行一个整数，表示最大总价值。

### 数据范围

$1 \le n \le 100$，$1 \le cap \le 1000$，$1 \le w_i \le cap$，$0 \le v_i \le 10^{9}$，$1 \le c_i \le 10^{9}$。

注意 $c_i$ 可以非常大，把每件物品拆成 $c_i$ 个单独的物品会超时。答案不超过 $10^{12}$。

### 样例说明

样例 1：$n = 2$，$cap = 10$。第 $1$ 种物品重量 $3$、价值 $4$、共 $3$ 件；第 $2$ 种物品重量 $5$、价值 $7$、共 $2$ 件。取第 $2$ 种物品 $2$ 件，总重量 $10$，总价值 $14$，这是最大值。
