# 回文分割最少次数

给定一个只含小写字母的字符串 $s$，你需要把它分割成若干个连续的子串，使得每个子串都是回文串。求最少需要分割多少次（即切多少刀）。

例如 `aab` 可以切成 `aa` 和 `b`，只需 $1$ 刀；也可以切成 `a`、`a`、`b`，需要 $2$ 刀，所以答案是 $1$。

### 输入格式

- 一行一个字符串 $s$，只含小写字母，不含空格。

### 输出格式

一行一个整数，表示最少的分割次数。如果 $s$ 本身就是回文串，答案是 $0$。

### 数据范围

$1 \le |s| \le 1500$。

### 样例说明

样例 1：$s = $ `aab`。切成 `aa` 与 `b` 时两段都是回文串，需要 $1$ 刀；只切 $0$ 刀时 `aab` 不是回文串，所以最少是 $1$。
