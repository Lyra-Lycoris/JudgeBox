# 无向图判环

给定一张 $n$ 个点、$m$ 条边的无向图（点的编号 $1 \sim n$），判断这张图里是否存在环。

保证图中没有自环，也没有重边：任意两个不同的点之间最多只有一条边。

### 输入格式

- 第一行两个整数 $n, m$，用一个空格隔开；
- 接下来 $m$ 行，每行两个整数 $u_i, v_i$，表示第 $i$ 条边连接点 $u_i$ 与点 $v_i$。

### 输出格式

如果图中存在环，输出一行 `YES`；否则输出一行 `NO`。

### 数据范围

$1 \le n \le 200000$，$0 \le m \le 200000$，$1 \le u_i, v_i \le n$，$u_i \ne v_i$。

保证任意一对点之间不会重复给出边，也不会出现 $(u, u)$ 这样的自环。

### 样例说明

样例 1：$n = 4$，$m = 4$，四条边依次是 $(1,2)$、$(2,3)$、$(3,4)$、$(4,1)$。从点 $1$ 出发可以沿着 $1 \to 2 \to 3 \to 4 \to 1$ 回到点 $1$，这条长度为 $4$ 的回路就是一个环，所以输出 `YES`。
