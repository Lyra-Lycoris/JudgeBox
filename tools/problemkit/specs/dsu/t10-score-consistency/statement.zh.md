# 分数关系是否一致

有 $n$ 个学生，编号 $1 \sim n$。每个学生有一个分数，分数可以是任意整数（可以是负数，也没有上限）。

现在给出 $k$ 条陈述，第 $i$ 条陈述是「学生 $a_i$ 比学生 $b_i$ 高 $c_i$ 分」，也就是说分数必须满足

$$score_{a_i} - score_{b_i} = c_i$$

其中 $c_i$ 可能为负数，表示 $a_i$ 反而比 $b_i$ 低 $|c_i|$ 分。

请判断是否存在一组分数，使得所有 $k$ 条陈述同时成立。

### 输入格式

- 第一行两个整数 $n, k$，用一个空格隔开；
- 接下来 $k$ 行，每行三个整数 $a_i, b_i, c_i$，表示一条陈述。

### 输出格式

如果存在满足所有陈述的分数，输出一行 `YES`；否则输出一行 `NO`。

### 数据范围

$1 \le n \le 200000$，$0 \le k \le 200000$，$1 \le a_i, b_i \le n$，$-10^9 \le c_i \le 10^9$。

允许 $a_i = b_i$（此时陈述要求 $c_i = 0$）。同一条陈述可能被给出多次。

### 样例说明

样例 1：$n = 4$，$k = 3$，三条陈述是 $score_1 - score_2 = 3$、$score_2 - score_3 = -1$、$score_1 - score_3 = 2$。

前两条相加得到 $score_1 - score_3 = 3 + (-1) = 2$，恰好与第三条一致。取 $score_3 = 0$、$score_2 = -1$、$score_1 = 2$，学生 $4$ 没有被约束，随便取 $0$，所有陈述都成立，所以输出 `YES`。

如果把第三条改成 $score_1 - score_3 = 5$，就与前两条推出的 $2$ 冲突，此时应输出 `NO`。
