# 连通块数量

给定一张 $n$ 个点、$m$ 条边的无向图，点的编号为 $1 \sim n$。图中可能含有重边，但不会出现自环。

如果两个点之间可以通过若干条边互相到达，就称它们属于同一个连通块；一个孤立的点本身也算一个连通块。请统计整张图里连通块的数量。

### 输入格式

- 第一行两个整数 $n, m$，用一个空格隔开；
- 接下来 $m$ 行，每行两个整数 $u_i, v_i$，表示有一条边连接点 $u_i$ 与点 $v_i$。

### 输出格式

一行一个整数，表示连通块的数量。

### 数据范围

$1 \le n \le 200000$，$0 \le m \le 200000$，$1 \le u_i, v_i \le n$，$u_i \ne v_i$。

图中允许存在重边，也就是说同一条边可能给出多次。

### 样例说明

样例 1：$n = 5$，$m = 2$，两条边分别是 $(1,2)$ 和 $(2,3)$。

- 点 $1, 2, 3$ 通过边连在一起，构成连通块 $\{1,2,3\}$；
- 点 $4$ 没有边，单独构成 $\{4\}$；
- 点 $5$ 没有边，单独构成 $\{5\}$。

因此一共有 $3$ 个连通块。
