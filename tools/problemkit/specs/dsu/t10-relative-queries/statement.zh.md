# 亲戚关系查询

有 $n$ 个人，编号 $1 \sim n$。已知其中 $k$ 对人是亲戚。亲戚关系是相互的，也是可以传递的：如果 $a$ 和 $b$ 是亲戚、$b$ 和 $c$ 是亲戚，那么 $a$ 和 $c$ 也是亲戚。同一个人和自己当然是亲戚。

现在给出 $q$ 个询问，每个询问问两个人是不是亲戚，请你统计有多少个询问的答案是「是」。

### 输入格式

- 第一行两个整数 $n, k$，用一个空格隔开；
- 接下来 $k$ 行，每行两个整数 $a_i, b_i$，表示 $a_i$ 与 $b_i$ 是亲戚；
- 接下来一行一个整数 $q$；
- 接下来 $q$ 行，每行两个整数 $c_i, d_i$，表示一个询问。

### 输出格式

一行一个整数，表示 $q$ 个询问中答案为「是」的询问个数。

### 数据范围

$1 \le n \le 200000$，$0 \le k \le 200000$，$1 \le q \le 200000$。

所有关系与询问中的编号都在 $1 \sim n$ 之间；$a_i$ 与 $b_i$ 可能相同，$c_i$ 与 $d_i$ 也可能相同（此时答案一定是「是」）。同一条关系可能被给出多次。

### 样例说明

样例 1：$n = 6$，$k = 2$，已知 $(1,2)$ 与 $(2,3)$ 是亲戚，所以 $1, 2, 3$ 互为亲戚。

- 询问 $(1,3)$：由传递性，答案是「是」；
- 询问 $(1,4)$：点 $4$ 没有出现在任何关系中，答案是「否」；
- 询问 $(5,5)$：同一个人，答案是「是」。

一共有 $2$ 个询问的答案是「是」，输出 `2`。
