# 最小生成树总权重

给定一张 $n$ 个点、$m$ 条边的无向带权图（点的编号 $1 \sim n$）。图中可能有重边，但不会有自环，图也不保证连通。

你需要在图中选出若干条边，使得选出的边把**所有**点连通（也就是选出一棵生成树），并且选出的边的边权之和最小。请求出这个最小的边权之和。

如果图不连通，则不存在生成树，输出 `-1`。特别地，当 $n = 1$ 时不需要选任何边，答案为 $0$。

### 输入格式

- 第一行两个整数 $n, m$，用一个空格隔开；
- 接下来 $m$ 行，每行三个整数 $u_i, v_i, w_i$，表示第 $i$ 条边连接点 $u_i$ 与点 $v_i$，边权为 $w_i$。

### 输出格式

一行一个整数，表示最小生成树的总权重；若图不连通则输出 `-1`。

### 数据范围

$1 \le n \le 200000$，$0 \le m \le 200000$，$1 \le u_i, v_i \le n$，$u_i \ne v_i$，$-10^9 \le w_i \le 10^9$。

边权可能为负数；图中允许重边；图不要求连通。

### 样例说明

样例 1：$n = 4$，$m = 5$，五条边是 $(1,2,1)$、$(2,3,2)$、$(3,4,3)$、$(1,4,5)$、$(1,3,4)$。

选择 $(1,2,1)$、$(2,3,2)$、$(3,4,3)$ 这三条边可以把 $4$ 个点全部连通，总权重为 $1 + 2 + 3 = 6$。

如果改用 $(1,4,5)$ 去替换 $(3,4,3)$，总权重会变成 $8$，更大；其余选法也不会更优。所以最小总权重是 $6$。
