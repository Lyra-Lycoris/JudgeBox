# 等式与不等式约束

有 $n$ 个整数变量 $x_1, x_2, \dots, x_n$。每个变量都可以取任意整数（可以是负数，也没有上下界）。

现在给出 $k$ 条约束，每条约束是下面两种形式之一：

- $x_u = x_v$（输入中 $t = 0$）；
- $x_u < x_v$（输入中 $t = 1$）。

请判断是否存在一组整数赋值，使得所有 $k$ 条约束同时成立。

### 输入格式

- 第一行两个整数 $n, k$，用一个空格隔开；
- 接下来 $k$ 行，每行三个整数 $t, u, v$，含义如上。$t = 0$ 表示 $x_u = x_v$，$t = 1$ 表示 $x_u < x_v$。

### 输出格式

如果存在满足全部约束的赋值，输出一行 `YES`；否则输出一行 `NO`。

### 数据范围

$1 \le n \le 200000$，$0 \le k \le 200000$，$t \in \{0, 1\}$，$1 \le u, v \le n$。

允许 $u = v$（此时 $t = 1$ 的约束要求 $x_u < x_u$，必然无解）。同一条约束可能被给出多次。

### 样例说明

样例 1：$n = 4$，四条约束是 $x_1 = x_2$、$x_2 < x_3$、$x_3 = x_4$、$x_1 < x_4$。

先把相等的变量合并：$\{x_1, x_2\}$ 取同一个值 $a$，$\{x_3, x_4\}$ 取同一个值 $b$。于是约束变成 $a < b$ 与 $a < b$，两者完全一致。取 $a = 0$、$b = 1$ 即可满足全部约束，输出 `YES`。

如果把第 $2$ 条改成 $x_3 < x_2$，约束就变成 $a < b$ 与 $b < a$，互相矛盾，此时应输出 `NO`。
