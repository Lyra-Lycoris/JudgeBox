# 相邻交换排序的最小次数

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$。一次操作可以交换序列中相邻的两个元素。请计算把整个序列变成非递减序列（即 $a_1 \le a_2 \le \dots \le a_n$）所需的最少交换次数。

当序列中存在相同的元素时，最优方案中相同元素的相对顺序不会改变（相当于稳定排序），你可以直接利用这个性质。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

### 输出

一行一个整数，表示最少的相邻交换次数。

### 数据范围

- $1 \le n \le 10^5$
- $|a_i| \le 10^9$

### 样例说明

序列为 $2, 4, 1, 3$。交换 $4$ 和 $1$ 得到 $2, 1, 4, 3$；交换 $2$ 和 $1$ 得到 $1, 2, 4, 3$；交换 $4$ 和 $3$ 得到 $1, 2, 3, 4$。共 3 次，可以证明少于 3 次无法完成排序，所以答案是 3。
