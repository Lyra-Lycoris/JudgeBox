# 最大化最小相邻差

给定 $n$ 个整数 $a_1, a_2, \dots, a_n$，请从中选出恰好 $k$ 个元素。把选出的元素按从小到大排成一列，设相邻两个元素之差的最小值为 $D$（当 $k = 1$ 时规定 $D = 0$）。求 $D$ 的最大可能值。

注意选出的元素不要求连续，只要求从原数组中挑出 $k$ 个。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

第三行一个整数 $k$。

### 输出

一行一个整数，表示 $D$ 的最大可能值。

### 数据范围

- $1 \le k \le n \le 10^5$
- $|a_i| \le 10^9$

### 样例说明

$n = 5$，数组为 $1, 5, 3, 9, 11$，$k = 3$。排序后是 $1, 3, 5, 9, 11$。选出 $1, 5, 9$，相邻差分别为 $4$ 和 $4$，所以 $D = 4$。

若想 $D \ge 5$：选 $1$ 之后下一个数至少要 $6$，只能选 $9$；再下一个至少要 $14$，数组中不存在，这样最多选出 $2$ 个，不满足 $k = 3$。所以 $D$ 不会超过 $4$，答案为 $4$。
