# 合并石子

有 $n$ 堆石子排成一排，第 $i$ 堆有 $a_i$ 个石子。一次操作可以选择**任意两堆**石子，把它们合并成一堆，本次操作的代价是这两堆石子数量之和。经过 $n-1$ 次操作后，所有石子会合并成一堆。

求完成合并的最小总代价（所有操作代价之和）。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

### 输出

一行一个整数，表示最小总代价。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $0 \le a_i \le 10^9$

### 样例说明

四堆石子数量为 $4, 3, 2, 6$。先合并 $3$ 和 $2$，代价 $5$，剩下 $4, 5, 6$；再合并 $4$ 和 $5$，代价 $9$，剩下 $6, 9$；最后合并 $6$ 和 $9$，代价 $15$。总代价 $5 + 9 + 15 = 29$，这是最小可能值。

注意：两堆石子不需要相邻，任意两堆都可以合并。每次合并的代价都会被累加，所以让数量小的堆尽早合并更划算。
