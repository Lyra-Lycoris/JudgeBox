# 加油站环路起点

在一条环形公路上有 $n$ 个加油站，第 $i$ 个加油站可以加 $gas_i$ 升油，从第 $i$ 个加油站开到第 $i+1$ 个加油站（$n-1$ 的下一个站是 $0$）需要消耗 $cost_i$ 升油。

你驾驶一辆初始油箱为空的汽车，从某个加油站出发（一开始就在该站加油），沿公路顺时针行驶。油箱容量无限。求一个可以绕行一整圈回到出发站的起点编号（编号从 $0$ 开始）。如果无解，输出 $-1$。数据保证有解时答案唯一。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $gas_0, gas_1, \dots, gas_{n-1}$。

第三行 $n$ 个整数 $cost_0, cost_1, \dots, cost_{n-1}$。

### 输出

一行一个整数，表示可行的起点编号（$0$ 到 $n-1$）；无解输出 $-1$。

### 数据范围

- $1 \le n \le 10^5$
- $0 \le gas_i, cost_i \le 10^4$

### 样例说明

$n=5$，各站加油量为 $1,2,3,4,5$，各段耗油为 $3,4,5,1,2$。总加油量等于总耗油量，所以一定存在解。从 $0$ 出发油箱马上见底（$1-3<0$），从 $1$、$2$ 出发同样马上见底；从 $3$ 出发，依次到达 $4,0,1,2$ 站后的油量为 $3, 6, 4, 2, 0$，全程没有出现负数，可以绕行一圈回到 $3$，所以答案是 3。
