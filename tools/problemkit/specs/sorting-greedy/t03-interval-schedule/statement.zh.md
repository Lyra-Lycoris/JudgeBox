# 区间调度：最多不重叠区间

数轴上有 $n$ 个闭区间，第 $i$ 个区间是 $[l_i, r_i]$。你要从中选出尽量多的区间，使得任意两个被选中的区间都不重叠：只有满足 $r \le l'$ 时，区间 $[l, r]$ 与 $[l', r']$ 才算不重叠（端点相接是允许的）。

求最多能选出的区间个数。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $l_1, l_2, \dots, l_n$。

第三行 $n$ 个整数 $r_1, r_2, \dots, r_n$。

保证 $l_i \le r_i$。

### 输出

一行一个整数，表示最多能选出的区间个数。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $-10^9 \le l_i \le r_i \le 10^9$

### 样例说明

样例中有 4 个区间：$[1,3]$、$[2,4]$、$[3,5]$、$[0,1]$。把所有区间按右端点从小到大排序得到 $[0,1], [1,3], [2,4], [3,5]$，依次选取 $[0,1]$、$[1,3]$、$[3,5]$，它们两两不重叠，共 3 个。显然不可能选出 4 个，所以答案是 3。
