# 与 m 互素的整数个数

给定两个正整数 $n$ 和 $m$，求 $1 \le x \le n$ 且 $\gcd(x, m) = 1$ 的整数 $x$ 的个数。

例如 $n = 10$，$m = 6$ 时，与 $6$ 互素的数是 $1, 5, 7$，共 $3$ 个。

### 输入格式

一行两个整数 $n$ 和 $m$，用一个空格隔开。

### 输出格式

一行一个整数，表示满足条件的整数个数。

### 数据范围

- $1 \le n \le 10^{18}$
- $1 \le m \le 10^{12}$
- $m = 1$ 时所有数都与 $m$ 互素，答案是 $n$

### 样例说明

样例 1：$n = 10$，$m = 6 = 2 \times 3$。在 $1, 2, \dots, 10$ 中，$2$ 的倍数有 $5$ 个，$3$ 的倍数有 $3$ 个，$6$ 的倍数有 $1$ 个，由容斥原理，与 $6$ 不互素的数有 $5 + 3 - 1 = 7$ 个，所以与 $6$ 互素的有 $10 - 7 = 3$ 个，即 $1, 5, 7$。

样例 2：$n = 100$，$m = 12 = 2^2 \times 3$，只有质因子 $2, 3$ 起作用。与 $12$ 互素的整数每 $12$ 个中有 $\varphi(12) = 4$ 个，$100 = 8 \times 12 + 4$，前 $96$ 个数中有 $32$ 个，$97, 98, 99, 100$ 中只有 $97$ 与 $12$ 互素，所以答案是 $33$。
