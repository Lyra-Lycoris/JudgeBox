# 随机交换后的逆序对期望

给定一个长度为 $n$ 的整数数组 $a_1, a_2, \dots, a_n$。若 $i < j$ 且 $a_i > a_j$，则称下标对 $(i, j)$ 是一个**逆序对**。

现在从所有满足 $i < j$ 的下标对中等概率随机选出一对，交换 $a_i$ 与 $a_j$，得到一个**新数组**。求新数组中逆序对个数的期望。

由于期望可能是分数，本题采用「分数取模」的方式输出：

> 设答案为最简分数 $p/q$（$q$ 与 $10^9+7$ 互质），请输出
> $$p \cdot q^{-1} \bmod (10^9+7),$$
> 其中 $q^{-1}$ 是 $q$ 在模 $10^9+7$ 意义下的乘法逆元。

注意：如果交换后数组没有变化（例如两个位置上的数相同），仍然算作一次有效的交换，逆序对数不变。

### 输入格式

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，用空格隔开。

### 输出格式

一行一个整数，表示期望对 $10^9+7$ 取模的结果，取值范围是 $[0, 10^9+6]$。

### 数据范围

- $1 \le n \le 200000$
- $|a_i| \le 10^9$
- $n = 1$ 时不存在下标对，规定答案为 $0$

### 样例说明

样例 1：$n = 3$，数组为 $3, 1, 2$，共有 $\binom{3}{2} = 3$ 对下标：

- 交换 $(1, 2)$ 得到 $1, 3, 2$，逆序对 $1$ 个；
- 交换 $(1, 3)$ 得到 $2, 1, 3$，逆序对 $1$ 个；
- 交换 $(2, 3)$ 得到 $3, 2, 1$，逆序对 $3$ 个。

三种情况等概率，期望为 $(1 + 1 + 3)/3 = 5/3$。因为 $3^{-1} \equiv 333333336$，所以 $5 \times 333333336 \bmod (10^9+7) = 666666673$，输出 `666666673`。

样例 2：$n = 1$，没有任何下标对可选，规定答案为 $0$。
