# 多重集排列数

给定 $n$ 个整数（可能重复）。把这 $n$ 个数看成一个多重集，求它们**不同**的排列个数，对 $10^9+7$ 取模。

两个排列不同，当且仅当存在某个位置上的数不同；相同的数互换位置不算新的排列。

例如 $n = 3$，数组为 $1, 1, 2$ 时，不同的排列只有 $1,1,2$、$1,2,1$、$2,1,1$ 共 $3$ 个。

设不同取值的出现次数分别为 $c_1, c_2, \dots, c_m$，则答案为

$$\frac{n!}{c_1!\, c_2! \cdots c_m!}.$$

### 输入格式

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，用空格隔开。

### 输出格式

一行一个整数，表示不同排列的个数对 $10^9+7$ 取模的结果。

### 数据范围

- $1 \le n \le 200000$
- $|a_i| \le 10^9$

### 样例说明

样例 1：$n = 3$，数组为 $1, 1, 2$。两个 $1$ 互换得到的是同一个排列，所以不同排列共 $3! / 2! = 3$ 个，答案是 $3$。

样例 2：$n = 1$，数组为 $-5$，只有一种排列，答案是 $1$。
