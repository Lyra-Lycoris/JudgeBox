# 掷骰子凑出目标和

反复掷一枚均匀的六面骰子，点数分别为 $1, 2, 3, 4, 5, 6$，每个点数出现的概率都是 $1/6$。每次把点数累加，问：总和**恰好**等于 $n$ 的概率是多少？

由于概率是一个分数，本题采用「分数取模」的方式输出：

> 设答案为最简分数 $p/q$（$q$ 与 $10^9+7$ 互质），请输出
> $$p \cdot q^{-1} \bmod (10^9+7),$$
> 其中 $q^{-1}$ 是 $q$ 在模 $10^9+7$ 意义下的乘法逆元。

请求出无数种可能的掷法中，总和恰好等于 $n$ 的总概率。注意掷骰子的次数不限，因此答案是所有「掷 $k$ 次、和为 $n$」的概率之和（$k \ge 1$）。

### 输入格式

一行一个整数 $n$。

### 输出格式

一行一个整数，表示概率对 $10^9+7$ 取模的结果，取值范围是 $[0, 10^9+6]$。

### 数据范围

- $1 \le n \le 200000$

### 样例说明

样例 1：$n = 2$，有两种可能：一次掷出 $2$（概率 $1/6$），或者两次各掷出 $1$（概率 $1/36$）。总概率是 $1/6 + 1/36 = 7/36$。因为 $36^{-1} \equiv 27777778$，所以 $7 \times 27777778 \bmod (10^9+7) = 194444446$，输出 `194444446`。

样例 2：$n = 1$，只有一次掷出 $1$ 这一种可能，概率是 $1/6$。因为 $6^{-1} \equiv 166666668$，所以输出 `166666668`。
