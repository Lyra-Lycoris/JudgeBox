# 凑齐连续 n 次正面的期望抛掷次数

一枚均匀的硬币，每次抛掷出现正面的概率是 $1/2$。不断地抛掷，直到**首次**出现连续 $n$ 次正面为止。

求总共需要抛掷次数的期望 $E_n$。可以证明 $E_n$ 一定是整数，请输出

$$E_n \bmod (10^9+7).$$

例如 $n = 1$ 时，平均抛 $2$ 次就会出现一次正面；$n = 2$ 时 $E_2 = 6$；$n = 3$ 时 $E_3 = 14$。

### 输入格式

一行一个整数 $n$。

### 输出格式

一行一个整数，表示 $E_n$ 对 $10^9+7$ 取模的结果，取值范围是 $[0, 10^9+6]$。

### 数据范围

- $1 \le n \le 10^{18}$

### 样例说明

样例 1：$n = 2$。用 $E_k$ 表示「当前已经连续出现 $k$ 次正面，还要抛多少次才能凑齐 $n$ 次」的期望，则 $E_2 = 0$，$E_1 = 1 + \frac{1}{2}E_2 + \frac{1}{2}E_0$，$E_0 = 1 + \frac{1}{2}E_1 + \frac{1}{2}E_0$，解得 $E_0 = 6$，所以答案是 $6$。

样例 2：$n = 1$，平均抛 $2$ 次出现第一次正面，所以答案是 $2$。
