# 从 n 个物品中选 k 个

从 $n$ 个互不相同的物品中选出 $k$ 个，有多少种不同的选法？由于结果可能很大，请输出它对 $10^9+7$ 取模的结果。

形式化地说，求组合数

$$\binom{n}{k} = \frac{n!}{k!\,(n-k)!} \bmod (10^9+7).$$

选出的 $k$ 个物品之间没有顺序，例如从 $\{1,2,3\}$ 中选 $2$ 个，只有 $\{1,2\}, \{1,3\}, \{2,3\}$ 三种选法。

### 输入格式

一行两个整数 $n$ 和 $k$，用一个空格隔开。

### 输出格式

一行一个整数，表示 $\binom{n}{k} \bmod (10^9+7)$，取值范围是 $[0, 10^9+6]$。

### 数据范围

- $0 \le k \le n \le 200000$
- 取模的数 $10^9+7$ 是质数，所以 $k!$ 和 $(n-k)!$ 在模 $10^9+7$ 下都有逆元

### 样例说明

样例 1：$n = 5$，$k = 2$，$\binom{5}{2} = \dfrac{5 \times 4}{2 \times 1} = 10$，对 $10^9+7$ 取模后仍是 $10$。

样例 2：$n = 0$，$k = 0$，从空集中选 $0$ 个只有一种选法，答案是 $1$。
