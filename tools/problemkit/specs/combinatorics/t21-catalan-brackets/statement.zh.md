# 合法括号序列计数

用 $n$ 对括号可以拼成长度为 $2n$ 的括号串。一个括号串是**合法**的，当且仅当：从左往右扫描时，任意时刻左括号的数量都不少于右括号的数量；并且扫描结束时左右括号数量相等。

求长度为 $2n$ 的合法括号串个数，对 $10^9+7$ 取模。

例如 $n = 3$ 时共有 $5$ 个合法括号串：

```
((()))  (()())  (())()  ()(())  ()()()
```

### 输入格式

一行一个整数 $n$。

### 输出格式

一行一个整数，表示合法括号串的个数对 $10^9+7$ 取模的结果。

### 数据范围

- $0 \le n \le 200000$
- $n = 0$ 时只有空串一种方案，答案是 $1$

### 样例说明

样例 1：$n = 3$，合法的括号串共 $5$ 个，即上面列出的 $5$ 个，答案是 $5$。

样例 2：$n = 0$，空串是唯一的方案，答案是 $1$。
