# 任务调度最小总耗时

有一台处理器和 $n$ 个任务，每个任务都只需要 $1$ 个单位时间。任务按类型区分：为了散热，**两个同类型任务之间至少要间隔 $c$ 个单位时间**，也就是说如果两个同类型任务分别在时刻 $x$ 和 $y$ 开始，则必须有 $|x - y| \ge c + 1$。处理器在等待时可以空闲。

任务可以按任意顺序执行。求执行完所有任务所需的**最少总时间**（从时刻 $0$ 开始计时，最后一个任务结束的时刻即为总时间）。

### 输入格式

第一行两个整数 $n$ 和 $c$。

第二行 $n$ 个整数，表示每个任务的类型编号。

### 输出格式

一行一个整数，表示最少总时间。

### 数据范围

- $1 \le n \le 200000$
- $0 \le c \le 10^9$
- $1 \le$ 任务类型编号 $\le 10^9$

### 样例说明

任务类型为 $1,1,1,2,2,2$，$c=2$。一种最优安排是 $1,2,\text{空闲},1,2,\text{空闲},1,2$，总时间为 $8$。
