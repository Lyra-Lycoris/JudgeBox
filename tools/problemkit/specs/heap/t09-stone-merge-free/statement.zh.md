# 合并石子（一次免费合并）

有 $n$ 堆石子，第 $i$ 堆有 $a_i$ 个石子。一次操作可以任选两堆，把它们合并成一堆，本次操作的代价是这两堆石子数之和。

你需要进行 $n-1$ 次操作，把所有石子合并成一堆。其中有**至多一次**操作的代价按 $0$ 计算（相当于这一次合并不花钱），其余操作的代价正常累加。求完成合并的**最小总代价**。

当 $n = 1$ 时不需要任何操作，总代价为 $0$。

### 输入格式

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

### 输出格式

一行一个整数，表示最小总代价。

### 数据范围

- $1 \le n \le 200000$
- $0 \le a_i \le 10^9$

### 样例说明

石子数分别为 $4, 3, 2, 6$。先合并 $3$ 与 $2$，代价 $5$，剩下 $4, 5, 6$；再合并 $4$ 与 $5$，代价 $9$，剩下 $6, 9$；最后一次合并 $6$ 与 $9$ 使用免费机会，代价记作 $0$。总代价为 $5 + 9 = 14$。
