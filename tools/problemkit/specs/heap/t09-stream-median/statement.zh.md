# 数据流中位数

有一个整数数据流，数据一个接一个地到来。定义：插入第 $i$ 个数之后，当前数据流的**中位数**是这 $i$ 个数中第 $\lceil i / 2 \rceil$ 小的数（即当 $i$ 为偶数时取中间两个数里较小的那个）。

给定 $T$ 组数据，对每组数据依次插入它的每个数，输出每次插入后的中位数。

### 输入格式

第一行一个整数 $T$，表示数据组数。

接下来 $T$ 组数据，每组两行：

- 第一行一个整数 $n$；
- 第二行 $n$ 个整数，按到达顺序给出。

### 输出格式

对每组数据输出一行，包含 $n$ 个整数，依次为插入第 $1, 2, \dots, n$ 个数后的中位数，用空格分隔。

### 数据范围

- $1 \le T \le 10$
- $1 \le n \le 200000$，且所有组数据的 $n$ 之和不超 $200000$
- $|a_i| \le 10^9$

### 样例说明

第一组数据 $[1,2,3]$ 的中位数依次是 $1, 1, 2$；第二组数据 $[5,4,3,2]$ 的中位数依次是 $5, 4, 4, 3$。
