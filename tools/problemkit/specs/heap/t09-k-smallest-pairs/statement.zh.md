# 最小 k 对和

给定两个**非降序**整数序列 $a_1 \le a_2 \le \dots \le a_n$ 和 $b_1 \le b_2 \le \dots \le b_m$。考虑所有 $n \times m$ 个下标对 $(i, j)$ 对应的和 $a_i + b_j$，求其中最小的 $k$ 个和，按非降序输出（相同的和分别计入）。

### 输入格式

第一行三个整数 $n$、$m$ 和 $k$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$（非降序）。

第三行 $m$ 个整数 $b_1, b_2, \dots, b_m$（非降序）。

### 输出格式

一行 $k$ 个整数，即最小的 $k$ 个和，按非降序排列，用空格分隔。

### 数据范围

- $1 \le n, m \le 100000$
- $1 \le k \le \min(n \times m,\ 100000)$
- $|a_i|, |b_j| \le 10^9$
- 保证两个序列都按非降序给出

### 样例说明

$a = [1, 7, 11]$，$b = [2, 4, 6]$。最小的几个和依次是 $1+2=3$、$1+4=5$、$1+6=7$、$7+2=9$，所以 $k=3$ 时输出 `3 5 7`。
