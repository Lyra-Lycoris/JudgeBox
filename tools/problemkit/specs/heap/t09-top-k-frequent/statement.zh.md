# 出现频率前 k 高的元素

给定 $n$ 个整数，请找出其中出现次数最多的 $k$ 个**不同**元素。输出顺序为：出现次数多的在前；出现次数相同时，数值小的在前。

### 输入格式

第一行两个整数 $n$ 和 $k$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

### 输出格式

一行 $k$ 个整数，按题目要求的顺序排列，用空格分隔。

### 数据范围

- $1 \le n \le 200000$
- $1 \le k \le$ 数组中不同元素的个数
- $|a_i| \le 10^9$

### 样例说明

数组为 $[1, 1, 1, 2, 2, 3]$：$1$ 出现 $3$ 次，$2$ 出现 $2$ 次，$3$ 出现 $1$ 次。取前 $2$ 多，得到 $1$ 和 $2$，所以输出 `1 2`。
