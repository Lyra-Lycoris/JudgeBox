# 带障碍的路径计数

给定一个 $n$ 行 $m$ 列的网格 $g$，其中 $g_{i,j} = 1$ 表示该格子是障碍，$g_{i,j} = 0$ 表示该格子可以通行。

一个机器人从左上角 $(1, 1)$ 出发，每一步只能**向右**或**向下**走一格，目标是走到右下角 $(n, m)$，且途中不能进入障碍格。求不同的路径条数对 $10^9+7$ 取模的结果。

### 输入

第一行两个整数 $n$ 和 $m$。

接下来 $n$ 行，每行 $m$ 个整数（$0$ 或 $1$），描述网格。

### 输出

一行一个整数，表示路径条数对 $10^9+7$ 取模的结果。若无法到达则输出 $0$。

### 数据范围

- $1 \le n, m \le 500$
- $g_{i,j} \in \{0, 1\}$

### 样例说明

$3 \times 3$ 的网格，中心格 $(2,2)$ 是障碍。从 $(1,1)$ 到 $(3,3)$ 一共需要走 $2$ 次向右、$2$ 次向下，共 $\binom{4}{2} = 6$ 条路径；其中经过中心的路径有 $2 \times 2 = 4$ 条，都不合法，所以答案是 $6 - 4 = 2$。

### 提示

设 $dp_{i,j}$ 为走到 $(i,j)$ 的路径数：若 $(i,j)$ 是障碍则 $dp_{i,j} = 0$；否则 $dp_{i,j} = dp_{i-1,j} + dp_{i,j-1}$，起点 $dp_{1,1} = 1$（起点是障碍时答案自然为 $0$）。逐行从左到右递推即可，空间上只需要保留一维数组：处理到格子 $(i,j)$ 时，$dp_j$ 里存的正是上一行的值，而 $dp_{j-1}$ 已经是本行更新后的值。时间复杂度 $O(nm)$。
