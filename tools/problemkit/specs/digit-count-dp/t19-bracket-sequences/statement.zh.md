# 合法括号序列计数

只由 `(` 和 `)` 组成的字符串是**合法括号序列**，当且仅当它可以通过不断删去相邻的一对 `()` 变成空串。等价地说：任意前缀中 `(` 的个数不少于 `)` 的个数，且整个串中两者个数相等。

给定 $n$，求长度为 $2n$（即 $n$ 对括号）的合法括号序列个数对 $10^9+7$ 取模的结果。

### 输入

一行一个整数 $n$。

### 输出

一行一个整数，表示长度为 $2n$ 的合法括号序列个数对 $10^9+7$ 取模的结果。

### 数据范围

- $1 \le n \le 10^6$

### 样例说明

$n = 3$ 时长度为 $6$ 的合法括号序列有 `((()))`、`(()())`、`(())()`、`()(())`、`()()()`，共 $5$ 个，因此输出 $5$。

### 提示

答案就是第 $n$ 个卡特兰数

$$C_n = \frac{1}{n+1}\binom{2n}{n} = \frac{(2n)!}{(n+1)!\,n!}$$

直接算阶乘再取模会溢出，必须用模 $10^9+7$ 下的乘法逆元。因为 $10^9+7$ 是质数且 $n+1 < 10^9+7$，由费马小定理有 $a^{-1} \equiv a^{10^9+5} \pmod{10^9+7}$，用快速幂求逆元即可。

具体做法：先算出 $n!$ 与 $\prod_{i=n+1}^{2n} i$（它们相乘得 $(2n)!/n!$），于是 $\binom{2n}{n} = \left(\prod_{i=n+1}^{2n} i\right) \cdot (n!)^{-1}$，最后再乘上 $(n+1)^{-1}$。总复杂度 $O(n + \log 10^9)$。
