# 区间数位和

记 $s(x)$ 为整数 $x$ 的十进制各位数字之和（例如 $s(2024) = 2 + 0 + 2 + 4 = 8$）。

给定两个正整数 $l$ 和 $r$，求

$$\sum_{x=l}^{r} s(x)$$

即区间 $[l, r]$ 中所有整数的数位之和的总和。

### 输入

一行两个整数 $l$ 和 $r$，用空格分隔。

### 输出

一行一个整数，表示区间内所有整数数位之和的总和。

### 数据范围

- $1 \le l \le r \le 10^{15}$

### 样例说明

$s(1) + s(2) + \dots + s(9) + s(10) = 1 + 2 + \dots + 9 + 1 = 46$，所以输出 $46$。

### 提示

枚举每个数太慢，需要对**数位**做动态规划。记 $f(x) = \sum_{v=0}^{x} s(v)$，答案就是 $f(r) - f(l-1)$。

从高位向低位扫描 $x$ 的每一位。设当前处理到第 $p$ 位（后面还有 $p$ 位），高位已经确定的数字之和为 `prefix`。如果当前位取 $v$（小于 $x$ 的这一位），那么：

- 高位与当前位对总和的贡献是 $(prefix + v) \times 10^{p}$，因为后面 $p$ 位共有 $10^{p}$ 种取值，每种取值都会继承这个前缀和；
- 后面 $p$ 位的数字之和在全部 $10^{p}$ 种取值上一共贡献 $p \times 45 \times 10^{p-1}$，因为每一位在全部组合中恰好各取 $0 \sim 9$ 各 $10^{p-1}$ 次。

最后不要漏掉 $x$ 本身的数位和。总复杂度 $O(\log_{10} r)$。
