# 不同子序列个数

给定一个长度为 $n$ 的、只含小写英文字母的字符串 $s$。

子序列是指从 $s$ 中删去若干（可以删 $0$ 个）字符后，保持剩余字符相对顺序得到的字符串。两个子序列只要内容相同就算同一种，即使它们由不同的位置组合得到。求 $s$ 的**不同非空子序列**个数对 $10^9+7$ 取模的结果。

### 输入

第一行一个整数 $n$。

第二行一个长度为 $n$ 的字符串 $s$（只含小写英文字母，不含空格）。

### 输出

一行一个整数，表示不同非空子序列的个数对 $10^9+7$ 取模的结果。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $s$ 只含小写英文字母 `a`~`z`

### 样例说明

$s = \texttt{aba}$ 的非空子序列按字典序为 `a`、`b`、`ab`、`aa`、`ba`、`aba`，一共 $6$ 种，因此输出 $6$。注意第一个 `a` 和最后一个 `a` 各自单独构成的 `a` 算同一种。

### 提示

先考虑允许空串。设 $dp[i]$ 为 $s$ 的长度为 $i$ 的前缀的不同子序列个数（含空串），$dp[0] = 1$。若在第 $i$ 个字符 $c$ 处不做去重，方案数是 $2\,dp[i-1]$（每个旧子序列后面接 $c$ 或者不接）。但这个字符之前可能已经出现过：如果上一次出现 $c$ 是在位置 $p$（$1$ 起编号），那么"在 $p$ 处接上 $c$"得到的那些子序列会被重复计数，重复的个数恰好是 $dp[p-1]$。于是

$$dp[i] = 2\,dp[i-1] - [\,c \text{ 之前出现过}\,] \cdot dp[p-1]$$

用长度为 $26$ 的数组记录每个字母上一次出现的下标即可，时间复杂度 $O(n)$，空间复杂度 $O(n)$。最后减去空串，即答案为 $dp[n] - 1$。

注意取模后相减可能为负数，需要先加 $10^9+7$ 再取模。
