# 不含数字 4 的整数个数

给定两个正整数 $l$ 和 $r$，请统计闭区间 $[l, r]$ 中共有多少个整数的十进制表示中**不包含**数字 $4$。

### 输入

一行两个整数 $l$ 和 $r$，用空格分隔。

### 输出

一行一个整数，表示区间内不含数字 $4$ 的整数个数。

### 数据范围

- $1 \le l \le r \le 10^{18}$

### 样例说明

$[1, 10]$ 中不含数字 $4$ 的整数依次是 $1, 2, 3, 5, 6, 7, 8, 9, 10$，共 $9$ 个，因此输出 $9$。

如果把区间拆成 $[1, x]$ 的前缀形式，记 $f(x)$ 为 $[0, x]$ 中不含数字 $4$ 的整数个数，则答案就是 $f(r) - f(l-1)$。从高位到低位逐位确定：当前位取比原数该位小的数字时，后面所有位都可以任意取 $0 \sim 9$ 中除 $4$ 以外的 $9$ 种，方案数为 $9^{\text{剩余位数}}$；当前位一旦等于 $4$，后面的数都不合法，可以直接结束。这样一次统计的复杂度是 $O(\log_{10} r)$。
