# 二进制中 1 的个数恰好为 k

给定 $l, r, k$，统计闭区间 $[l, r]$ 中有多少个整数的二进制表示中恰好含有 $k$ 个 $1$。

### 输入

一行三个整数 $l, r, k$，用空格分隔。

### 输出

一行一个整数，表示区间内满足条件的整数个数。

### 数据范围

- $1 \le l \le r \le 10^{18}$
- $0 \le k \le 60$

### 样例说明

$[1, 16]$ 中二进制恰好只有一个 $1$ 的整数是 $1 = 1_2$、$2 = 10_2$、$4 = 100_2$、$8 = 1000_2$、$16 = 10000_2$，共 $5$ 个，因此输出 $5$。

### 提示

这是二进制版本的数位 DP。记 $f(x)$ 为 $[0, x]$ 中二进制恰好含 $k$ 个 $1$ 的整数个数，答案是 $f(r) - f(l-1)$。

从高位到低位扫描 $x$ 的二进制位，同时记录已经确定的 $1$ 的个数 `used`。当扫描到第 $b$ 位（其下还有 $b$ 个低位）且 $x$ 的这一位是 $1$ 时：我们可以把这一位取 $0$，剩下的 $b$ 个低位任意，其中还需要放 $k - used$ 个 $1$，方案数为 $\binom{b}{k - used}$；累加之后，再按 $x$ 的这一位取 $1$，把 `used` 加一。若某一步 `used` 超过 $k$，说明更长的前缀已经不可能合法，直接结束。所有位走完后，如果恰好 $used = k$，说明 $x$ 本身也合法，答案再加一。

组合数 $\binom{b}{j}$ 可以用杨辉三角预处理（$b \le 60$，最大约 $1.18 \times 10^{17}$，在 64 位整数范围内）。总复杂度 $O(60)$。
