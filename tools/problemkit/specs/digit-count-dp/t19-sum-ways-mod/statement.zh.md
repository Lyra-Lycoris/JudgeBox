# 和为 n 的拆分方案数

把正整数 $n$ 写成若干个正整数之和，每个加数都不超过 $m$，**加数的顺序不同视为不同方案**。求方案数对 $10^9+7$ 取模的结果。

例如 $n = 4, m = 2$ 时，合法写法为 $1+1+1+1$、$1+1+2$、$1+2+1$、$2+1+1$、$2+2$，共 $5$ 种。

### 输入

一行两个整数 $n$ 和 $m$，用空格分隔。

### 输出

一行一个整数，表示方案数对 $10^9+7$ 取模的结果。

### 数据范围

- $1 \le n \le 10^6$
- $1 \le m \le 10^6$

### 样例说明

$n = 4, m = 2$ 的 5 种方案见题意，因此输出 $5$。

### 提示

设 $dp[i]$ 为把 $i$ 拆分的方案数，$dp[0] = 1$。最后一步放的加数可以是 $1 \sim m$ 中任意一个，于是

$$dp[i] = \sum_{j=1}^{m} dp[i-j] \quad (i \ge 1)$$

直接按这个式子做是 $O(nm)$ 的，会超时。注意 $dp[i]$ 只依赖前面连续 $m$ 项的和，用一个滑动窗口维护 $\sum_{j=1}^{m} dp[i-j]$，每步加上 $dp[i]$、减去 $dp[i-m]$，复杂度降到 $O(n)$。所有运算都在模 $10^9+7$ 下进行。
