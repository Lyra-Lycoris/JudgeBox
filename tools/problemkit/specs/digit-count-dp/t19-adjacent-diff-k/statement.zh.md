# 相邻数位差不超过 k

一个整数的数位按十进制书写，最高位不能是 $0$。我们称这个整数是**光滑的**，当且仅当它的任意两个相邻数位之差的绝对值都不超过 $k$。单独一位的整数总是光滑的。

给定 $l, r, k$，求闭区间 $[l, r]$ 中光滑整数的个数。

### 输入

一行三个整数 $l, r, k$，用空格分隔。

### 输出

一行一个整数，表示区间内光滑整数的个数。

### 数据范围

- $1 \le l \le r \le 10^{18}$
- $0 \le k \le 9$

### 样例说明

$[1, 20]$ 中光滑整数（$k = 1$）为 $1 \sim 9$、$10, 11, 12$，共 $9 + 3 = 12$ 个；其中 $13$ 因为 $|1-3| = 2 > 1$ 不合法，$20$ 因为 $|2-0| = 2 > 1$ 也不合法。

### 提示

记 $f(x)$ 为 $[1, x]$ 中光滑整数的个数，答案是 $f(r) - f(l-1)$。先用一个简单的 DP 预处理计数表：

$$\text{cnt}[rem][last] = \text{在最后一位是 } last \text{ 之后再接 } rem \text{ 位、且处处光滑的接法数}$$

其中 $\text{cnt}[0][last] = 1$，$\text{cnt}[rem][last] = \sum_{|v - last| \le k} \text{cnt}[rem-1][v]$。

统计 $f(x)$ 时从高位到低位枚举：先数所有位数比 $x$ 短的光滑数（首位置 $1 \sim 9$），再沿 $x$ 的前缀走，遇到某一位可以取更小的数字时用计数表累加，一旦前缀自身已经违反条件就立即停止。单次统计 $O(\log_{10} x \cdot 10)$。
