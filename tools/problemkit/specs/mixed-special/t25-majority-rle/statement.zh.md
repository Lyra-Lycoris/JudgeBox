# 游程编码数组的多数元素

给定一个用**游程编码**（run-length encoding）描述的整数数组。

编码由 $k$ 段组成，第 $i$ 段表示「数值 $v_i$ 连续出现 $c_i$ 次」。各段首尾相接，拼成的整个数组长度为 $N = c_1 + c_2 + \dots + c_k$。

**保证**整个数组中存在一个数，它的出现次数**严格大于** $N/2$（这样的数显然至多一个）。

请找出这个数。

### 输入格式

- 第一行一个整数 $k$；
- 第二行 $k$ 个整数 $v_1, \dots, v_k$；
- 第三行 $k$ 个整数 $c_1, \dots, c_k$。

### 输出格式

一行一个整数，表示出现次数严格大于 $N/2$ 的那个数。

### 数据范围

$1 \le k \le 200000$，$0 \le v_i \le 10^9$，$1 \le c_i \le 10^9$，$N = \sum c_i \le 2 \times 10^{14}$。

由于 $N$ 最大可达 $2 \times 10^{14}$，把数组真正展开是不可能的，必须在编码上直接处理。

### 样例说明

样例 1：$k = 4$，各段为「$1$ 出现 $2$ 次」「$2$ 出现 $1$ 次」「$1$ 出现 $3$ 次」「$3$ 出现 $1$ 次」，展开后数组为 $1, 1, 2, 1, 1, 1, 3$，长度 $N = 7$。数字 $1$ 出现了 $5$ 次，$5 > 7/2 = 3.5$，所以输出 `1`。

### 提示

摩尔投票法的核心是「不同元素两两抵消」。设候选数为 $\text{cand}$、剩余票数为 $\text{balance}$，处理一段「$v_i$ 出现 $c_i$ 次」时：

- 若 $\text{balance} = 0$：令 $\text{cand} = v_i$，$\text{balance} = c_i$；
- 若 $v_i = \text{cand}$：$\text{balance} \mathrel{+}= c_i$；
- 否则这一段与候选数抵消：$\text{balance}$ 与 $c_i$ 中较小的那个被消掉，即 $\text{balance} = |\text{balance} - c_i|$，并在 $c_i > \text{balance}$ 时把 $\text{cand}$ 换成 $v_i$。

因为多数元素出现次数超过一半，抵消到最后一定还剩下它，所以最终的 $\text{cand}$ 就是答案，时间复杂度 $O(k)$。
