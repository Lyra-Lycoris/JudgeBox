# 构造和为 s 的 k 个正整数

给定两个整数 $s$ 与 $k$。

请构造 $k$ 个**正整数**，使它们的和恰好等于 $s$。

本题使用**特殊评判**（SPJ）：只要输出任意一组满足条件的正整数即可，不要求与参考输出相同。

### 输入格式

一行两个整数 $s$ 和 $k$，用一个空格隔开。

### 输出格式

输出 $k$ 个正整数，表示你构造的这组数。数字之间可以用空格或换行分隔。必须恰好输出 $k$ 个数，且每个数都至少为 $1$。

### 数据范围

$1 \le k \le s \le 10^9$，同时 $k \le 200000$。

### 样例说明

样例 1：$s = 10$，$k = 3$。输出 `1 1 8` 是一组合法答案：三个数都是正整数，且 $1 + 1 + 8 = 10$。

其他合法答案还有 `2 3 5`、`3 3 4`、`1 4 5` 等；而 `1 2 6` 的和是 $9$、`0 5 5` 含非正整数，都不合法。

### 提示

先让前 $k-1$ 个数都取最小值 $1$，这样它们的和是 $k-1$，把剩下的 $s-(k-1)$ 全部放到最后一个数上。由于 $s \ge k$，最后一个数至少为 $1$。
