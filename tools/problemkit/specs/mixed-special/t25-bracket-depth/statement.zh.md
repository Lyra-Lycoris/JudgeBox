# 构造最大嵌套深度为 k 的括号序列

给定两个整数 $n$ 与 $k$（$n$ 保证是偶数，且 $1 \le k \le n/2$）。

请构造一个长度为 $n$ 的**合法括号序列**，并且它的**最大嵌套深度**恰好为 $k$。

一个长度为 $n$ 的字符串被称为合法括号序列，当且仅当：它只由 `(` 和 `)` 组成，从左往右读时任意前缀中 `(` 的个数不少于 `)` 的个数，且整个串中两种括号数量相等。

序列的嵌套深度定义为「任意前缀中 `(` 个数减去 `)` 个数的差」的最大值。

本题使用**特殊评判**（SPJ）：只要输出任意一个满足条件的括号序列即可。

### 输入格式

一行两个整数 $n$ 和 $k$，用一个空格隔开。

### 输出格式

输出一个长度为 $n$ 的字符串（只含 `(` 和 `)`），表示你构造的括号序列。字符串中不能有空格。

### 数据范围

$2 \le n \le 200000$，$n$ 是偶数，$1 \le k \le n/2$。

### 样例说明

样例 1：$n = 6$，$k = 2$。输出 `(())()` 是合法括号序列，各前缀的深度依次为 $1, 2, 1, 0, 1, 0$，最大深度为 $2$，满足要求。

`()()()` 的最大深度只有 $1$，`((()))` 的最大深度是 $3$，都不满足 $k = 2$。

### 提示

先连续放 $k$ 个 `(`，再连续放 $k$ 个 `)`，这时深度达到 $k$；剩下的 $n-2k$ 个字符用 `()` 成对追加到末尾，深度不会超过 $1$，因此最大深度仍然是 $k$。
