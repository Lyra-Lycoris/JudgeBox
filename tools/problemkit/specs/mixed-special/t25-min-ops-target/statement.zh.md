# 变成目标数组的最少操作

给定两个长度为 $n$ 的整数数组 $a_1, \dots, a_n$ 和 $b_1, \dots, b_n$。

一次操作可以任选一段**连续子数组** $[l, r]$（$1 \le l \le r \le n$），然后：

- 把 $a_l, a_{l+1}, \dots, a_r$ 全部加 $1$；或者
- 把 $a_l, a_{l+1}, \dots, a_r$ 全部减 $1$。

请你求出：至少需要多少次操作，才能把数组 $a$ 变成数组 $b$（即最终对每个 $i$ 都有 $a_i = b_i$）。

### 输入格式

- 第一行一个整数 $n$；
- 第二行 $n$ 个整数 $a_1, \dots, a_n$；
- 第三行 $n$ 个整数 $b_1, \dots, b_n$。

### 输出格式

一行一个整数，表示最少操作次数。

### 数据范围

$1 \le n \le 200000$，$-10^9 \le a_i, b_i \le 10^9$。

### 样例说明

样例 1：$n = 3$，$a = (1, 2, 3)$，$b = (3, 2, 1)$。差值 $d_i = b_i - a_i$ 为 $(2, 0, -2)$：需要把 $a_1$ 加 $2$ 次、把 $a_3$ 减 $2$ 次，由于位置 $2$ 不能变化，两个位置不能放在同一次操作里，因此至少 $4$ 次操作，而 $4$ 次确实可以做到（例如对 $[1,1]$ 加两次、对 $[3,3]$ 减两次）。

### 提示

记 $d_i = b_i - a_i$，并把正负部分分开：$p_i = \max(d_i, 0)$，$q_i = \max(-d_i, 0)$。

- 正的部分只能靠「加 $1$」操作完成，负的部分只能靠「减 $1$」操作完成，二者互不干扰；
- 对正的层来说，每次「加 $1$」操作最多同时满足一段连续位置的一层需求。设 $p_0 = 0$，则恰好需要 $\sum_i \max(0, p_i - p_{i-1})$ 次「加 $1$」操作（高度上升时必须新开一次操作，高度下降时可以随时结束操作）；
- 同理，「减 $1$」操作的次数是 $\sum_i \max(0, q_i - q_{i-1})$，其中 $q_0 = 0$。

答案为两者之和，时间复杂度 $O(n)$。注意答案可能很大（最大约 $2 \times 10^{14}$），需要用 64 位整数。
