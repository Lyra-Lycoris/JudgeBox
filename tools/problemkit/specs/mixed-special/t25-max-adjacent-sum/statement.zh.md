# 构造相邻差之和最大的排列

给定一个整数 $n$。

请构造一个 $1$ 到 $n$ 的排列 $p_1, p_2, \dots, p_n$，使得

$$\sum_{i=1}^{n-1} \lvert p_i - p_{i+1} \rvert$$

尽可能大。你只需要输出任意一个**达到最大值**的排列。

本题使用**特殊评判**（SPJ）：任何达到最大值的排列都会被接受。

### 输入格式

一行一个整数 $n$。

### 输出格式

输出 $n$ 个整数，构成一个 $1$ 到 $n$ 的排列。数字之间可以用空格或换行分隔，必须恰好输出 $n$ 个数。

### 数据范围

$1 \le n \le 200000$。

### 样例说明

样例 1：$n = 5$。输出 `3 5 1 4 2` 对应的相邻差为 $\lvert 3-5 \rvert = 2$、$\lvert 5-1 \rvert = 4$、$\lvert 1-4 \rvert = 3$、$\lvert 4-2 \rvert = 2$，总和为 $11$。可以证明 $n = 5$ 时最大值就是 $11$（例如 `1 2 3 4 5` 的总和只有 $4$）。

### 提示

把和式展开成每个元素带系数的形式：两端元素的系数是 $\pm 1$，中间元素的系数是 $\pm 2$。为了让总和最大，应当让较大的数拿到 $+2$、较小的数拿到 $-2$，由此可以推出最大值为 $\lfloor n^2/2 \rfloor - 1$（$n \ge 2$；$n = 1$ 时为 $0$）。

构造上一大一小交替即可：先输出 $\lceil n/2 \rceil$，接下来依次交替输出「当前最大的数、当前最小的数」，即 $n, 1, n-1, 2, n-2, 3, \dots$，直到排列被填满。
