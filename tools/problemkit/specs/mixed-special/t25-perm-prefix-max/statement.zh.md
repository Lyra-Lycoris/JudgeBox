# 构造前缀最大值个数为 k 的排列

给定两个整数 $n$ 与 $k$。

请构造一个 $1$ 到 $n$ 的排列 $p_1, p_2, \dots, p_n$（每个整数 $1 \sim n$ 恰好出现一次），使得它的**前缀最大值个数**恰好为 $k$。

一个位置 $i$ 是前缀最大值，当且仅当 $p_i$ 严格大于它前面的所有元素，即 $p_i > \max(p_1, \dots, p_{i-1})$（约定 $p_0 = 0$）。因此第 $1$ 个位置一定是前缀最大值。

本题使用**特殊评判**（SPJ）：只要输出任意一个满足条件的排列即可，不要求与参考输出相同。

### 输入格式

一行两个整数 $n$ 和 $k$，用一个空格隔开。

### 输出格式

输出 $n$ 个整数，表示你构造的排列。数字之间可以用空格或换行分隔，但相对顺序不能改变。必须恰好输出 $n$ 个数。

### 数据范围

$1 \le k \le n \le 200000$。

### 样例说明

样例 1：$n = 5$，$k = 3$。输出 `1 2 5 4 3` 是一个合法答案：前缀最大值依次出现在位置 $1, 2, 3$（值分别为 $1, 2, 5$），位置 $4, 5$ 的值 $4, 3$ 都比 $5$ 小，所以前缀最大值恰好有 $3$ 个。

反例：`1 5 2 3 4` 只有 $2$ 个前缀最大值（$1$ 和 $5$）；`5 4 3 2 1` 只有 $1$ 个；`1 2 3 4 5` 有 $5$ 个。所以 $k = 3$ 时必须认真构造。

### 提示

先从小到大放 $1, 2, \dots, k-1$，这一步贡献了 $k-1$ 个前缀最大值；再把 $n, n-1, \dots, k$ 依次接在后面，其中只有开头的 $n$ 会成为新的前缀最大值，后面每个数都比 $n$ 小。总共恰好 $k$ 个。
