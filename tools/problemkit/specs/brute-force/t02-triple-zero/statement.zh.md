# 和为零的三元组计数

给定一个长度为 $n$ 的整数序列 $a_1, a_2, \dots, a_n$，请统计有多少个下标三元组 $(i, j, k)$ 满足：

- $1 \le i < j < k \le n$；
- $a_i + a_j + a_k = 0$。

注意下标必须严格递增，因此同一个数值组合如果出现了多次，要按出现位置分别计数。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，用空格分隔。

### 输出

输出一行一个整数，表示满足条件的三元组个数。

### 数据范围

- $1 \le n \le 300$
- $-10^9 \le a_i \le 10^9$
- 答案不超过 $10^{18}$，请使用 64 位整数保存
- 时间限制 2000 ms，空间限制 256 MB

### 样例

**输入**

```
3
-1 0 1
```

**输出**

```
1
```

### 样例说明

样例中 $a = \{-1, 0, 1\}$，只有一个三元组 $(-1, 0, 1)$ 满足和为 $0$，所以输出 `1`。

如果输入是 `3` 与 `0 0 0`，则三元组 $(1, 2, 3)$ 也满足条件，输出同样是 `1`。
