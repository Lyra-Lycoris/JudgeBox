# 猜数字：根据提示枚举答案

有一个长度为 $n$ 的密码，每一位都是 $0 \sim 9$ 的数字，数字可以重复，也允许前导零。

你得到了 $k$ 条猜测记录，每条记录包含一个猜测序列以及两个提示：

- $A$：数字与位置都正确的位数；
- $B$：数字正确但位置不对的位数。具体规则是：把密码与猜测都看成数字的多重集合，公共数字的总个数（同一个数字按出现次数的较小值计算）减去 $A$，就是 $B$。

数据保证恰好只有一个 $n$ 位密码满足所有提示。请找出这个密码。

### 输入

第一行两个整数 $n$ 与 $k$，用空格分隔。

第二行 $k$ 个猜测，每个猜测是一个 $n$ 位数字串（可能以 `0` 开头），用空格分隔。

第三行 $k$ 个整数 $A_1, \dots, A_k$，用空格分隔。

第四行 $k$ 个整数 $B_1, \dots, B_k$，用空格分隔。

### 输出

输出一行 $n$ 个整数，表示密码的每一位，相邻两个数之间用一个空格分隔。

### 数据范围

- $1 \le n \le 4$
- $1 \le k \le 20$
- $0 \le A_i, B_i \le n$，且 $A_i + B_i \le n$
- 保证满足全部提示的密码恰好有一个
- 时间限制 2000 ms，空间限制 256 MB

### 样例

**输入**

```
3 3
123 720 247
1 1 1
0 1 2
```

**输出**

```
4 2 7
```

### 样例说明

样例中 $n = 3$，三条记录如下：

| 猜测 | $A$ | $B$ | 说明 |
|---|---|---|---|
| `123` | 1 | 0 | 第 2 位的 `2` 位置正确；`1`、`3` 都不在密码中 |
| `720` | 1 | 1 | 第 2 位的 `2` 位置正确；`7` 在密码中但位置不对 |
| `247` | 1 | 2 | 第 3 位的 `7` 位置正确；`2` 与 `4` 都在密码中但位置都不对 |

唯一满足全部提示的密码是 `4 2 7`，所以输出 `4 2 7`。
