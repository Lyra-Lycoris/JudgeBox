# 最大全 1 子矩形

给定一个 $n$ 行 $m$ 列的 01 矩阵，请找出一个只由 `1` 组成的子矩形（由连续的行区间与连续的列区间确定），使它的面积（格子数）最大。

如果矩阵中没有任何 `1`，答案为 $0$。

### 输入

第一行两个整数 $n$ 与 $m$，用空格分隔。

接下来 $n$ 行，每行 $m$ 个整数，取值为 `0` 或 `1`，用空格分隔。

### 输出

输出一行一个整数，表示最大全 1 子矩形的面积。

### 数据范围

- $1 \le n, m \le 60$
- 矩阵中每个元素只能是 $0$ 或 $1$
- 时间限制 2000 ms，空间限制 256 MB

### 样例

**输入**

```
3 4
1 0 1 1
1 0 1 1
1 1 1 1
```

**输出**

```
6
```

### 样例说明

样例矩阵为

```
1 0 1 1
1 0 1 1
1 1 1 1
```

第 $2$、$3$ 列的三行全部是 `1`，构成一个 $3 \times 2$ 的全 1 子矩形，面积为 $6$；不存在面积更大的全 1 子矩形，所以输出 `6`。
