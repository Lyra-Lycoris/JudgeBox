# 最大异或对

给定一个长度为 $n$ 的非负整数序列 $a_1, a_2, \dots, a_n$，请找出所有数对中按位异或的最大值，即

$$\max_{1 \le i < j \le n} \left(a_i \oplus a_j\right)$$

其中 $\oplus$ 表示按位异或。

### 输入

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，用空格分隔。

### 输出

输出一行一个整数，表示最大的异或值。若 $n < 2$，输出 `0`。

### 数据范围

- $1 \le n \le 2000$
- $0 \le a_i \le 10^9$
- 时间限制 2000 ms，空间限制 256 MB

### 样例

**输入**

```
3
1 2 3
```

**输出**

```
3
```

### 样例说明

样例中 $a = \{1, 2, 3\}$，三个数对的异或值分别是 $1 \oplus 2 = 3$、$1 \oplus 3 = 2$、$2 \oplus 3 = 1$，最大值为 $3$，所以输出 `3`。
