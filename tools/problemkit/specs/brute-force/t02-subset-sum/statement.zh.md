# 子集和可达性

给定 $n$ 个整数 $a_1, a_2, \dots, a_n$ 和一个整数 $target$，判断能否从中选出若干个（可以一个都不选）数，使它们的和恰好等于 $target$。

注意：空集的和规定为 $0$，因此 $target = 0$ 时答案一定是 `YES`。

### 输入

第一行两个整数 $target$ 与 $n$，用空格分隔。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$，用空格分隔。

### 输出

如果存在这样的子集，输出一行 `YES`，否则输出一行 `NO`。

### 数据范围

- $1 \le n \le 20$
- $-10^9 \le a_i \le 10^9$
- $-10^{10} \le target \le 10^{10}$
- 保证 $n$ 个数的任意子集之和都不会超出 64 位有符号整数范围
- 时间限制 2000 ms，空间限制 256 MB

### 样例

**输入**

```
6 4
1 2 3 4
```

**输出**

```
YES
```

### 样例说明

样例输入为 $target = 6$、$n = 4$、$a = \{1, 2, 3, 4\}$。

子集 $\{1, 2, 3\}$ 的和为 $1 + 2 + 3 = 6$，子集 $\{2, 4\}$ 的和也为 $6$，所以答案是 `YES`。
