# 第 k 个全排列

给定整数 $n$，把 $1, 2, \dots, n$ 的所有全排列按字典序从小到大排序，请输出其中的第 $k$ 个排列（排名从 $1$ 开始）。

例如 $n = 3$ 时，排列依次为

$$123,\ 132,\ 213,\ 231,\ 312,\ 321$$

其中第 $3$ 个是 $213$。

### 输入

一行两个整数 $n$ 与 $k$，用空格分隔。

### 输出

输出一行 $n$ 个整数，表示第 $k$ 个排列，相邻两个数之间用一个空格分隔。

### 数据范围

- $1 \le n \le 9$
- $1 \le k \le n!$（$n!$ 表示 $n$ 的阶乘，$9! = 362880$）
- 时间限制 2000 ms，空间限制 256 MB

### 样例

**输入**

```
3 3
```

**输出**

```
2 1 3
```

### 样例说明

$n = 3$ 的全部排列按字典序为 $123, 132, 213, 231, 312, 321$，第 $3$ 个是 $213$，所以输出 `2 1 3`。
