# 换根 DP 求每个点的最远距离

给定一棵 $n$ 个节点的树，节点编号 $1 \sim n$，$1$ 号节点是根，每条边的长度都是 $1$。

对每个节点 $v$，定义

$$e(v) = \max_{1 \le u \le n} \operatorname{dist}(v, u),$$

即 $v$ 到所有节点（包括它自己，距离为 $0$）的最大距离。请求出 $e(1), e(2), \dots, e(n)$。

### 输入格式

第一行一个整数 $n$。

第二行 $n-1$ 个整数 $p_2, p_3, \dots, p_n$，其中 $p_i$ 表示节点 $i$ 的父亲，保证 $1 \le p_i < i$。当 $n=1$ 时这一行为空（不需要读入任何数）。

### 输出格式

一行 $n$ 个整数，第 $i$ 个整数为 $e(i)$，数与数之间用一个空格分隔。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- 对每个 $2 \le i \le n$，$1 \le p_i < i$（因此输入一定构成一棵以 $1$ 为根的树）
- 时间限制 2000 ms，空间限制 256 MB

### 样例说明

样例 1：$n=5$，树的结构是：$1$ 的儿子为 $2, 3$；$3$ 的儿子为 $4, 5$。

- $e(1) = 2$（到 $4$ 或 $5$）；
- $e(2) = 3$（到 $4$ 或 $5$）；
- $e(3) = 2$（到 $2$）；
- $e(4) = 3$（到 $2$）；
- $e(5) = 3$（到 $2$）。

所以输出 `2 3 2 3 3`。

### 提示

一次 DFS 只能求出「向下」的最远距离 $\mathrm{down}(v)$。要得到每个点的答案，还需要「向上」的部分：

- 先自底向上求出每个点的 $\mathrm{down}(v)$，以及它所有儿子中 $\mathrm{down}(c)+1$ 的最大值和次大值；
- 再自顶向下换根：设 $v$ 的父亲是 $f$，则
  $$\mathrm{up}(v) = 1 + \max\left(\mathrm{up}(f),\ \text{兄弟子树中最大的 } \mathrm{down}(c)+1\right),$$
  其中「兄弟子树的最大值」用父亲的最大值/次大值在 $O(1)$ 内取出。
- 最终 $e(v) = \max(\mathrm{down}(v), \mathrm{up}(v))$，总复杂度 $O(n)$。
