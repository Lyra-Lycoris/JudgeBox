# 状压 DP：棋盘放王方案数

有一个 $n$ 行 $m$ 列的棋盘。棋盘上的一些格子是坏的，不能放棋子。

你要在棋盘上放置**若干个王**（可以一个都不放），使得任意两个王都不能互相攻击。王可以攻击它周围 $8$ 个格子（上、下、左、右以及四个斜对角）。

请求出放置方案数对 $10^9+7$ 取模的结果。

### 输入格式

第一行两个整数 $n, m$。

第二行 $n$ 个整数 $b_1, b_2, \dots, b_n$，其中 $b_i$ 的第 $j$ 个二进制位（$0 \le j < m$，最低位是第 $0$ 位）为 $1$ 表示第 $i$ 行第 $j+1$ 列的格子是坏的，为 $0$ 表示是好的。

### 输出格式

一行一个整数，表示方案数对 $10^9+7$ 取模的结果。

### 数据范围

- $1 \le n \le 200$
- $1 \le m \le 9$
- $0 \le b_i < 2^m$
- 时间限制 2000 ms，空间限制 256 MB

### 样例说明

样例 1：$n=2,\ m=2$，棋盘上没有坏格子，即

```
. .
. .
```

在 $2 \times 2$ 的棋盘上，任意两个格子都互相攻击（横向、纵向或斜向相邻），所以最多只能放一个王：

- 不放王：$1$ 种方案；
- 放一个王：$4$ 种方案（$4$ 个格子任选其一）。

共 $1 + 4 = 5$ 种，输出 `5`。

### 提示

按行做状态压缩 DP。用 $m$ 位的二进制数表示一行的放王情况，先预处理**行内合法**的状态：一行内不能有两个王横向相邻，即

$$s \ \&\ (s \ll 1) = 0 .$$

对 $m \le 9$ 来说合法状态只有 $89$ 个。两个相邻行 $s$（上一行）、$t$（当前行）能共存，当且仅当

$$s \ \&\ t = 0,\qquad (s \ll 1) \ \&\ t = 0,\qquad (s \gg 1) \ \&\ t = 0,$$

分别对应「上下相邻」「右上斜」「左上斜」三种攻击。此外本行的状态还必须与坏格子集合 $b_i$ 不冲突：$s \ \&\ b_i = 0$。

于是 $dp[s]$ 表示处理到当前行、本行状态为 $s$ 的方案数，逐行转移即可，复杂度 $O(n \cdot V^2)$，其中 $V \le 89$。
