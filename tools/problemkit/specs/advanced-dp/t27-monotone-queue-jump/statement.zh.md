# 单调队列优化跳跃代价

有 $n$ 块石头排成一行，编号 $1, 2, \dots, n$，第 $i$ 块石头的重量为 $a_i$。重量可以是负数，表示站在这块石头上不但没有代价，反而会得到 $-a_i$ 的收益。

你一开始站在 $1$ 号石头上，最终必须停在 $n$ 号石头上。站在石头 $i$ 上需要付出 $a_i$ 的代价（起点和终点也各要付出一次）。每次你可以从当前石头 $i$ 跳到 $i+1, i+2, \dots, i+k$ 中的任意一块石头，但不能跳出 $n$ 号石头。

请求出从 $1$ 号石头走到 $n$ 号石头的最小总代价。

### 输入格式

第一行两个整数 $n, k$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

### 输出格式

一行一个整数，表示最小总代价。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $1 \le k \le n$
- $-10^9 \le a_i \le 10^9$
- 答案的绝对值不超过 $2 \times 10^{14}$，64 位整数可以存下
- 时间限制 2000 ms，空间限制 256 MB

### 样例说明

样例 1：$n=6,\ k=2$，石头重量为 $1, 3, 2, 5, 4, 1$。

最优路线是 $1 \to 3 \to 5 \to 6$，总代价为 $a_1 + a_3 + a_5 + a_6 = 1 + 2 + 4 + 1 = 8$。

直接按转移方程 $\mathrm{dp}[i] = a_i + \min\limits_{i-k \le j < i} \mathrm{dp}[j]$ 计算是 $O(nk)$ 的。注意到窗口 $[i-k, i-1]$ 的左端点单调右移，用一个单调队列维护窗口内 $\mathrm{dp}$ 的最小值，即可把复杂度降到 $O(n)$：队列中 $\mathrm{dp}$ 值严格递增，队首就是当前窗口的最小值。
