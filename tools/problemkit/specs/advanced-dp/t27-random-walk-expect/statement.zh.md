# 随机游走的期望步数

数轴上有位置 $0, 1, 2, \dots$。你一开始站在位置 $0$。

每一步，你会以概率 $p = \dfrac{P}{P+Q}$ 向前走 $1$ 格，以概率 $q = \dfrac{Q}{P+Q}$ 向前走 $2$ 格，其中 $P, Q$ 是非负整数且 $P + Q > 0$。

当你的位置第一次**大于等于** $n$ 时停止。请求出停下时经过的步数的期望值。

由于期望值可能是一个有理数，请把它写成最简分数 $\dfrac{A}{B}$（$B > 0$，$\gcd(A,B)=1$），输出

$$A \cdot B^{-1} \bmod (10^9+7),$$

其中 $B^{-1}$ 是 $B$ 在模 $10^9+7$ 意义下的乘法逆元。可以证明在本题的数据范围内 $B$ 一定不是 $10^9+7$ 的倍数。

### 输入格式

一行三个整数 $n, P, Q$。

### 输出格式

一行一个整数，表示期望步数对 $10^9+7$ 取模的结果。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $0 \le P, Q \le 10^9$
- $1 \le P + Q \le 10^9$
- 时间限制 2000 ms，空间限制 256 MB

### 样例说明

样例 1：$n=5,\ P=Q=1$，所以 $p=q=\frac12$。

设 $E_i$ 表示从位置 $i$ 出发还需要走的期望步数，则 $E_i = 0\ (i \ge 5)$，且 $E_i = 1 + \frac12 E_{i+1} + \frac12 E_{i+2}\ (i < 5)$。

倒着算：

- $E_4 = 1$；
- $E_3 = 1 + \frac12 E_4 = \frac32$；
- $E_2 = 1 + \frac12 E_3 + \frac12 E_4 = \frac94$；
- $E_1 = 1 + \frac12 E_2 + \frac12 E_3 = \frac{23}{8}$；
- $E_0 = 1 + \frac12 E_1 + \frac12 E_2 = \frac{57}{16}$。

所以答案是 $57 \cdot 16^{-1} \bmod (10^9+7) = 62500004$。

### 提示

设 $E_i$ 为从位置 $i$ 出发的期望步数。由于一旦走到 $\ge n$ 就停止，有 $E_i = 0$（$i \ge n$）；对 $0 \le i < n$：

$$E_i = 1 + p\,E_{i+1} + q\,E_{i+2}.$$

从 $i = n-1$ 倒推到 $i = 0$ 即可，时间复杂度 $O(n)$。所有运算都在模 $10^9+7$ 下进行：$p = P \cdot (P+Q)^{-1}$，$q = Q \cdot (P+Q)^{-1}$，其中逆元用快速幂求出。
