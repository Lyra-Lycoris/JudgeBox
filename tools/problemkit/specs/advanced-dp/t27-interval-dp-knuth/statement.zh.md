# 石子合并的决策单调性优化

有 $n$ 堆石子排成一排，第 $i$ 堆有 $a_i$ 颗石子。

每次操作可以选择**相邻的两堆**石子，把它们合并成一堆，本次操作的代价等于合并后这一堆的石子总数。经过 $n-1$ 次操作后，所有石子会合并成一堆。

请求出总代价的最小值。

### 输入格式

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

### 输出格式

一行一个整数，表示最小总代价。

### 数据范围

- $1 \le n \le 1500$
- $1 \le a_i \le 10^9$
- 最小总代价不超过 $2.3 \times 10^{15}$，64 位整数可以存下
- 时间限制 2000 ms，空间限制 256 MB

### 样例说明

样例 1：$n=4$，石子堆为 $1, 2, 3, 4$。

- 先合并前两堆（$1+2$），代价 $3$，变成 $3, 3, 4$；
- 再合并前两堆（$3+3$），代价 $6$，变成 $6, 4$；
- 最后合并（$6+4$），代价 $10$。

总代价为 $3 + 6 + 10 = 19$，这也是最小值。

### 提示

设 $dp[l][r]$ 表示把区间 $[l, r]$ 合并成一堆的最小代价，$S$ 为前缀和，则

$$dp[l][r] = \min_{l \le k < r}\left(dp[l][k] + dp[k+1][r]\right) + S_r - S_{l-1}.$$

直接做是 $O(n^3)$，在 $n = 1500$ 时无法通过。记 $opt[l][r]$ 为取到最小值的决策点 $k$，由于区间代价（区间和）满足四边形不等式，有**决策单调性**：

$$opt[l][r-1] \le opt[l][r] \le opt[l+1][r].$$

于是枚举 $k$ 时只需在 $[opt[l][r-1],\, opt[l+1][r]]$ 内枚举，总复杂度降为 $O(n^2)$（Knuth 优化）。实现时注意 $opt[l+1][r]$ 可能等于 $r$，需要把它限制到 $r-1$。
