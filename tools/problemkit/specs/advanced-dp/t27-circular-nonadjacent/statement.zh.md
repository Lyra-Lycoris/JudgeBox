# 环形数组的最大不邻取和

给定一个长度为 $n$ 的环形数组 $a_1, a_2, \dots, a_n$：下标是循环的，$a_n$ 与 $a_1$ 也相邻。

你要选出一些位置组成集合 $S \subseteq \{1, 2, \dots, n\}$，要求 $S$ 中任意两个位置都**不相邻**（在环形意义下，$1$ 和 $n$ 也算相邻），使得

$$\sum_{i \in S} a_i$$

尽可能大。允许选出空集 $S = \varnothing$（和为 $0$），所以答案一定非负。

### 输入格式

第一行一个整数 $n$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

### 输出格式

一行一个整数，表示最大的和。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $-10^9 \le a_i \le 10^9$
- 答案的绝对值不超过 $10^{14}$
- 时间限制 2000 ms，空间限制 256 MB

### 样例说明

样例 1：$n=4$，数组为 $5, 1, 1, 5$。

- 选 $\{1, 3\}$：$5 + 1 = 6$；
- 选 $\{2, 4\}$：$1 + 5 = 6$；
- 选 $\{1, 4\}$ 不合法，因为 $a_4$ 与 $a_1$ 相邻。

所以答案是 $6$。

### 提示

由于 $a_1$ 与 $a_n$ 相邻，合法的集合不可能同时包含 $1$ 和 $n$。因此答案只有两类情况：

1. 不选 $a_n$：在链 $a_1, a_2, \dots, a_{n-1}$ 上做「相邻不能同时选」的线性 DP；
2. 不选 $a_1$：在链 $a_2, a_3, \dots, a_n$ 上做同样的 DP。

线性 DP 的转移是：设 $f_i$ 表示前 $i$ 个数的最优值，则

$$f_i = \max(f_{i-1},\ f_{i-2} + a_i),\qquad f_0 = f_{-1} = 0 .$$

两种情况的较大值即为答案，总复杂度 $O(n)$。注意 $n=1$ 和 $n=2$ 时环的相邻关系，以及允许空集。
