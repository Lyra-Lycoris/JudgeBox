# 斜率优化分段最小代价

给定长度为 $n$ 的正整数序列 $a_1, a_2, \dots, a_n$，以及一个非负整数 $C$。

你需要把序列划分成若干个**连续非空段**。如果某一段的下标区间是 $[l, r]$，则这一段要付出的代价为

$$\left(\sum_{k=l}^{r} a_k\right)^2 + C .$$

请求出所有合法划分方案中最小的总代价。

### 输入格式

第一行两个整数 $n, C$。

第二行 $n$ 个整数 $a_1, a_2, \dots, a_n$。

### 输出格式

一行一个整数，表示最小总代价。

### 数据范围

- $1 \le n \le 2 \times 10^5$
- $1 \le a_i \le 1000$
- $0 \le C \le 10^6$
- 最小总代价不超过 $4 \times 10^{16}$，64 位整数可以存下
- 时间限制 2000 ms，空间限制 256 MB

### 样例说明

样例 1：$n=3,\ C=10,\ a = (1,2,3)$。

- 划分 $[1,2,3]$：代价 $6^2 + 10 = 46$；
- 划分 $[1][2,3]$：代价 $(1+10) + (25+10) = 46$；
- 划分 $[1,2][3]$：代价 $(9+10) + (9+10) = 38$；
- 划分 $[1][2][3]$：代价 $11 + 14 + 19 = 44$。

最小值为 $38$。

### 提示

记前缀和 $S_i = a_1 + \dots + a_i$，设 $dp[i]$ 为前 $i$ 个数的最小代价，则

$$dp[i] = \min_{0 \le j < i}\left(dp[j] + (S_i - S_j)^2 + C\right)
       = S_i^2 + C + \min_{0 \le j < i}\left(dp[j] + S_j^2 - 2 S_i S_j\right).$$

把每个 $j$ 看成一个点：斜率 $m_j = S_j$，截距 $b_j = dp[j] + S_j^2$，询问的横坐标是 $x = -2S_i$。由于 $a_i \ge 1$，$S_j$ 与 $b_j$ 都严格递增，而 $x$ 随 $i$ 单调递减，可以用单调凸包（斜率优化）在 $O(n)$ 时间内完成所有转移。

注意凸包的合法性判断需要比较 $\Delta b \cdot \Delta m$ 这样的乘积，最大约 $10^{25}$，**超出 64 位整数范围**，C++ 需要 `__int128`，Java 需要 `BigInteger`，仓颉需要手动实现 128 位比较，Python 的大整数天然支持。
