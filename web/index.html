快速上手
使用说明
01手动测试
点击「新建测试用例」，填写输入和预期输出。勾选“比较答案”时，空文本也是有效答案；取消勾选则只运行，状态为 RUN。源程序编辑区会按语言高亮，并在停顿后检查语法错误。
02生成测试
选择模板，调整数据规模与数值范围，预览格式。可以批量运行观察实际输出，或把预览数据加入手动测试并填写答案。
03随机对拍
贴入正确的参考程序，自动为相同输入运行两个程序。首次发现差异或待测程序异常时停止，保留反例。参考程序失败会明确显示为判题错误。
自定义输入格式
模板会展示可编辑的 JSON。int 定义变量；array 的 count 可以引用 n；line 拼接一行多个值；repeat 重复嵌套步骤。复杂约束用 Python 脚本生成，CYaRon 可在安装后导入。
状态与复现
AC 正确 / WA 答案错误 / TLE 超时 / MLE 内存超限 / RE 运行异常 / CE 编译失败 / OLE 输出过量 / JE 工具、参考程序或生成器错误。保留规则、随机种子和序号即可复现同一组数据。
阅读答案差异
WA 详情会逐行对照预期与实际输出。空格显示为 ·，Tab 显示为 →，行尾显示为 ¶；字符差异会额外标红。下载文件仍保留原始内容。
编辑器键位
可在编辑器右上角切换 VS Code 或 Vim。VS Code 支持 Ctrl+D 多选、Ctrl+/ 注释、Alt+↑/↓ 移动行等常用键位；Vim 支持普通、插入、可视模式及常用移动、删除、复制和粘贴命令。拖动左右分栏的分割线即可调整宽度，刷新后仍会保留。
本地运行约定
源码、草稿与运行记录保存在本机。请只运行可信代码；资源限制不提供文件与网络隔离。关闭浏览器不会结束引擎，可用右上角“退出”或终端 Ctrl+C 停止。
